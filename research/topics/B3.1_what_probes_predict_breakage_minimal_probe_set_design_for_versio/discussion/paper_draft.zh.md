# 轴选择性破坏：测量哪类行为探针能预测 LLM 版本漂移故障

> 由 `pipeline.md` 中六个已确认的阶段产出组装而成，经过审计（`taste_audit.md`：🟢），并于 2026-08-21 应用了 `review_2026-08.md` 的 [major]/[moderate] 修订。状态：**规格说明 / 论文草稿 —— 尚未运行任何实验。** 下文所有数字均为预注册的设计目标，而非实验结果。

## 摘要（Abstract）

构建在托管或自部署大语言模型（Large Language Model, LLM）之上的团队，每当新版本发布时都必须决定重新测试什么——然而一个廉价的按版本探针（probe）能否真正预报实际破坏，取决于它探测的是哪一条行为轴（behavioral axis），而不是这次更新总体变化了多少。我们证明这一问题的决定性部分仍然悬而未决：近期的黑盒变更检测（black-box change detection）研究线已经能够判断模型在一个版本对（version pair）之间*是否*发生了变化，而单轴测量工具也能在单一时间点上精确测量拒答边界（refusal boundary）、校准（calibration）或安全范围（safety scope）——但它们都没有把按轴分解的漂移与下游任务的破坏真值（breakage ground truth）联系起来，因此都无法回答哪条轴（如果有的话）值得持续监测。我们构建了一条回顾式审计流水线：将五个行为探针族（probe family）——能力（capability）、拒答边界、格式偏好（format preference）、校准与安全行为（safety behavior）——以完全相同的方式施加于已发布版本对的两个版本；将功能性定义的下游破坏对全部五个漂移分数做联合回归，以识别哪条轴（如果有的话）在扣除其他轴之后主导故障；通过偏相关（partial correlation）解缠各行为轴共享的方差；将每个报告的漂移分数与版本内噪声下限（noise floor）及改写集（paraphrase set）排名稳定性做门控校验；并向最小的探针族子集消融，使其在预注册的容差内保留完整探针组的绝大部分预测力。我们在回顾式的开放权重与带日期 API 版本对上评估该设计，对照一组健全性基线——包括无探针的基准率预测器与不区分族的总漂移标量——并报告哪条轴（如果有的话）值得在每次版本升级后持续审计。

## 引言（Introduction）

大语言模型提供商会例行发布新版本，而每个在其上构建了下游集成的团队每次都面临同样的实际抉择：要么重新测试一切，要么信任一个更廉价的信号，认为新版本大概率仍会像旧版本那样运行。第二种选择之所以有吸引力，是因为全面重测代价高昂，且随每个版本、每个提供商、每个集成而重复——因此，每个版本只运行一次的小型快速探针，而非完整的下游重测，是唯一能随模型实际变更频率扩展的审计策略。

然而关于这一实践的一个核心问题仍未被检验：探针只有在它测量的轴恰好是决定下游集成是否破坏的那条轴时才有用，而这一点目前团队没有任何证据。一个团队可能因为能力基准最熟悉而重测原始能力，但真正弄坏其流水线的更新，移动的却是能力探针根本触及不到的拒答边界或安全范围决策。现有测量工具能以相当高的精度使每条轴各自可测，但没有一个能说明在若干候选轴中哪条才值得监测——更糟的是，多条轴往往一起漂移，因此即使一个团队探测了不止一条轴，也没有原则性的方法判断哪条轴在做真正的预测工作。

与此空白最近的已有工作分属两条新近的研究线，而本文的问题正处于两者之间。黑盒变更检测线已经能够在不访问权重的情况下跨版本对比较模型行为：托管模型行为随带日期快照显著漂移的纵向证据 [ChenDrift2307]；检测已部署端点行为偏移或静默修改的统计审计 [AuditBehaviorShift2410; YouveChanged2504; RankUniformity2506; ModelEquality2410; LogProbTracking2512; ModelSubstitution2504]；端点稳定性与身份的多行为指纹（behavioral fingerprint）[BehavioralFingerprints2603]；以及构念特定的跨发布审计，例如偏见相似性签名 [BiasSimBSM2607]。但这条线的估计对象（estimand）是*模型是否变了*——这些审计都没有将其变更信号与下游破坏真值做验证，也没有问哪条行为轴承载着预测信号。更新治理（update governance）线则从另一端回答破坏问题：在每次更新时重新运行直接的下游测试 [TestBeforeDeploy2604; SkillDriftContract2605]——这恰恰是廉价探针协议存在的意义所要避免的按次升级成本，且不含任何廉价探针预测层。互补的测量工具使各条轴分别精确可测：秩不变的拒答度量 [RefusalIndex2607]、原生适用于自由生成的语义校准概念 [BCalibration2607]、检验智能体是否停留在预期范围内的接受/拒绝测试 [OffTopicEval2607]，以及对无害请求系统性误拒的文档化记录 [ProSafePrune2607]。每一个都是在单一时间点评估的强单轴诊断工具；没有一个曾跨版本对与另一条轴、或与真实下游任务结果做过比较。一条相关的工作线选取基准题项的最小子集，使其在一个固定指标下保持分数或排名 [EssenceBench2607]——与本文所问的"充分集可以多小"是同一问题，但用于保持对既有分数的保真度，而非预测一个独立的下游目标。还有一项关于改写敏感性的研究表明，逐点的、单一措辞的测量脆弱到足以翻转一个已报告的结果 [TARE2607]——这是本文必须对自己的漂移测量、而不仅是对其他论文所优化的提示词认真对待的警告。

把这一空白转化为可测量的问题会暴露出真正的困难。一个版本对可以同时在多条行为轴上漂移，而没有任何真值先验地说明哪条轴决定了某个具体的下游故障，任何把功劳记给某条轴的尝试都可能只是记给了它恰好与某条相关轴共享的部分。下游"破坏"本身也不是一个单一的良定义量：同样的原始输出差异对一个任务可能是无害的改写，对另一个任务却是致命的结构性违规，因此不检查任务特定功能后果的定义会混淆两者。回顾式设计需要能随时可靠查询的版本对，但提供商不保证稳定的历史访问，因此仅靠尽力收集组建的语料会悄然缩水，只剩下恰好仍可访问的版本。而任何报告的漂移—破坏相关，其可信度都不超过计算它所用的探针题项——在一种措辞下出现、在另一种措辞下消失的相关，说明的是测量工具的选择问题，而非被审计模型的性质。

本文把上述每个障碍都转化为一个具体的设计决策。与其计算五个独立的相关并读取看起来最大的那个，五个族的漂移分数一次性进入同一个联合模型，使"哪条轴决定破坏"与"是否有任何轴携带真实信号"这两个问题来自同一个共享拟合，而不是五个互不协调的检验。下游破坏按任务定义，来自该任务实际依赖的功能检查，然后才做跨任务合并——因此无害的改写与破坏性的输出绝不会仅因移动了相同数量的字符而被计为等价。回顾式语料围绕显式的可达性门（reachability gate）构建而非尽力收集，研究期间因下线而丢失的版本对会被直接检验是否与存留下来的对存在系统性差异。每个族自身的边际贡献通过共线性检查的偏相关，与它仅仅与其他四个族共享的部分分离开来，使相关成束的轴不会被误认为一条轴在做全部工作。并且每个报告的漂移都必须先越过版本内噪声下限、并在独立改写的探针集之间保持相同的族排名，才会被信任。

我们在跨越不可变开放权重检查点接续与带日期 API 快照的回顾式版本对上评估该设计，将所得的族级预测与一组健全性对照——无探针的基准率预测器、查询预算相同的不区分族总漂移标量、单族预测器，以及仅限能力族的题项子集压缩基线——进行比较，以确立的不只是一个排名，而是该排名是否真实、是否与混杂因素隔离、以及是否小到可以持续运行。

概括而言，我们的贡献是：
- 一个回顾式测量设计：从一个联合模型（而非五个互不协调的相关）中识别哪一个行为探针族的漂移（如果有的话）能预测 LLM 版本对上的真实下游破坏，并附带对探针漂移是否携带任何信号的显式检验。
- 一个功能性落地的下游破坏定义：按任务由模式有效性（schema validity）与可执行性（executability）检查计算，然后再做跨任务合并，使无害的改写不会与结构性故障计为相同分数。
- 一个经共线性检查的归因程序：将一个族对破坏预测的自身边际贡献与它仅仅与其他四个族共享的部分分离，外加一个成对的噪声下限与改写门控，任何报告的漂移—破坏相关必须先通过它才算数。
- 一个围绕显式可达性门构建的回顾式语料，并直接检验研究期间因提供商侧下线而丢失的版本对是否与始终可查询的对存在系统性差异。
- 一份经验性报告：哪个探针族、或族的最小子集，值得作为 LLM 后端集成的版本漂移审计协议持续运行。

## 问题定义（Problem Definition）

**形式化设定。** 考虑版本对 p = (v_old, v_new)，p ∈ P，取自已经发生的模型更新。探针组横跨五个行为族 F = {cap, ref, fmt, cal, saf}——能力、拒答边界、格式偏好、校准与安全行为——每族有题项集 I_f，对每个对的两个版本以完全相同的方式施加。下游任务套件 T 中每个任务 t ∈ T 有共享输入集 X_t，同样通过两个版本运行。分析单元是单元格 (p, t)。对每个族 f 与对 p，D_f(p) 表示由 I_f 在 v_old 与 v_new 下的输出计算的带符号漂移幅度分数。对每个单元格 (p, t)，B(p, t) ∈ [0, 1] 表示下游破坏，B̄(p) = mean_t B(p, t) 为对级破坏平均。研究对象是 π_f，即 D_f(p) 对 B̄(p) 在 P 上的**样本外**（out-of-sample）预测力——通过分组留一对（grouped leave-one-pair-out）评估估计，同一模型谱系（lineage）的对始终分入同一折，使任何对都不会被一个在其谱系同伴的更新事件上拟合出的模型打分——以及最小充分子集 S* ⊆ F，使得在 S* 的漂移特征上训练的破坏分类器达到留出 AUC(S*) ≥ AUC(F) − δ（δ 为预先指定的容差），且两个 AUC 均在同一分组方案下的留出对上计算。样本内拟合只是诊断，绝不是估计对象：从用于拟合模型并选择 S* 的同一批对上读出的 π_f，等于在它声称要预测的那些漂移事件上验证自己。

**为什么这很难。** 一个版本对的漂移并不局限于一条轴：多个族可以在同一次更新中一起移动，因此某一族的漂移与 B̄(p) 之间的原始相关无法区分该族自身的贡献与它仅仅与相关族共享的部分——归因预测力需要隔离每个族的边际信号，而不只是观察到信号存在于这一束轴的某处。下游破坏 B(p, t) 也不是一个单一的良态量：同样幅度的输出差异可以让一个任务的功能行为毫发无损，却直接弄坏另一个任务，因此基于原始输出距离而非任务特定功能后果的定义会把本质不同的结果混在一个分数里。由于 P 是回顾式的，每个纳入对的两个版本都必须在完整的 I_f ∪ X_t 输入集上、在相同解码设置下保持可查询——提供商并不保证这一条件，因此尽力收集的语料可能悄然丢失恰恰对某个族最有信息量的对，在任何分析开始之前就使 P 本身产生偏倚。并且由于 D_f(p) 由特定的探针题项与解码样本选择计算而来，任何测得的 D_f(p) 与 B̄(p) 之间的相关，其可信度都不超过该选择的稳定性——在同样有效的改写下重新排序的族排名，反映的是测量工具选择的伪影，而非被审计版本的性质。

## 方法概览（Method Overview）

在概念层面，本研究是一条由五个协作部分组成的单一测量流水线，围绕一个核心动作构建：不是计算五个独立的族漂移—破坏相关然后读取看起来最大的那个，而是让每个族的漂移分数一次性进入同一个共享分析，使"哪条轴重要"、"是否有任何轴重要"、以及"报告的相关是真实的还是共线性、噪声、措辞或语料流失的伪影"这些问题全部由同一个协调的测量工具回答，而非五个互不协调的临时检查。

**联合族漂移回归**（joint family-drift regression）取五个族的按对漂移分数，将下游破坏平均值同时回归到它们全部之上，同时读出哪个族的系数最大、以及是否有任何系数与零可区分。**功能性下游真值**模块取每个对在共享下游任务套件上的输出，用各任务特定的功能检查将其转化为按任务、按对的破坏分数，然后才做跨任务合并。**流失门控回顾式语料**模块决定哪些版本对可以进入研究，要求任何对在贡献数据之前先通过可达性检查，并直接检验后来因下线丢失的对是否与存留的对不同。**共线性感知偏归因**模块取同样五个漂移分数，计算每个族扣除其他四个之后的贡献，并在某族的原始相关与其解缠贡献不一致时发出标记。**噪声与改写稳定性门**要求每个报告的漂移分数越过版本内噪声下限、并在独立改写的探针集之间保持相同的族排名，否则该分数不得进入其他四个模块的结论。这些模块产出的所有主结论还额外在**留出对评估与轴匹配防护**（Methodology 末小节）下打分：预测性断言绝不从拟合它们的同一批对上读出，也绝不从与之共享同一行为轴的探针—任务单元格上读出。

## 方法论（Methodology）

### 联合族漂移回归

**挑战。** 一个版本对可以同时在多条行为轴上漂移，而一次一族的原始相关无法判断该族是在做真正的预测工作，还是仅仅搭了某条相关轴的便车。

**洞察。** 将五个族的漂移分数放入一个回归而非运行五个独立的单变量检验，把两个原本需要各自临时程序的问题变成从同一个共享拟合中读出的两个估计对象：哪个族的系数最大，以及是否有任何系数与无信号零假设可区分。

**方法。** 对每个版本对 p，五个漂移分数 D_cap(p), ..., D_saf(p) 联合回归到对级破坏平均 B̄(p)。比较所得标准化系数以识别最大者，并将每个系数的自助法（bootstrap）置信区间与零比对，判断该族是否携带统计上可区分的预测力。同一个拟合因此同时回答排名问题与信号存在性问题，无需为每个问题单设程序。

### 功能性下游真值

**挑战。** 两个版本之间同样幅度的原始输出差异，对一个下游任务可能功能上无害，对另一个却是致命的，因此基于无差别输出距离的破坏定义会混淆本质不同的结果。

**洞察。** 把破坏锚定在任务实际依赖的功能检查上——而非文本变化了多少——才能使无害的改写不与损坏的模式计为相同分数；按任务先计算该检查再合并，才能让异质的任务敏感性显现出来而不是被平均掉。

**方法。** 对每个（对，任务）单元格，破坏 B(p, t) 计算为一减去该任务共享输入集中通过确定性功能等价检查（模式有效性、工具调用可执行性）并结合该任务特定语义差异阈值的比例。按任务破坏分数先单独报告，再平均为上文回归所用的对级 B̄(p)，因此占主导的任务无法悄然淹没敏感性不同的任务的信号。

### 流失门控回顾式语料

**挑战。** 尽力收集组建的回顾式语料会悄然缩水或偏向恰好仍可访问的版本对，因为提供商不保证稳定的历史访问——使普通的提供商侧下线变成一个未被检验的样本偏倚来源。

**洞察。** 以显式可达性检查作为对的准入门槛，然后直接将后来变得不可访问的对与始终可访问的对比较，把隐藏的幸存者风险转化为语料的一个可检验性质，而非关于语料的假设。

**方法。** 版本对仅在其两个版本被确认可在完整的探针加下游输入集上以相同解码查询之后才被准入语料。开放权重检查点接续（其检查点被不可变地存档）构成语料的骨干；带日期的闭源 API 快照作为次级层被纳入，正因为它们是研究中途最可能变得不可访问的对。研究期间确实变得不可访问的对，会在各族平均漂移幅度上与始终可访问的对比较，直接检验系统性流失偏倚，而非假设留存样本具有代表性。

### 共线性感知偏归因

**挑战。** 行为轴在统计上并不独立——安全行为的移动常与拒答边界的移动同时出现——因此一个族与破坏的原始相关可能只是借用了相关族的信号，而非反映其自身贡献。

**洞察。** 只有在计入一个族与其他四个族共享的方差之后，其自身边际贡献才可见；单独看原始成对相关，无法区分一个族的独立信号与另一个族信号的共线回声。

**方法。** 对每个族，在方差膨胀因子（Variance Inflation Factor, VIF）检查确认偏相关本身不是病态的之后，计算其扣除其他四个族之后与下游破坏的偏相关。将每个族的原始成对相关与偏相关做秩序一致性比较；不一致即标记该族在上文联合回归中的表面预测力至少部分是从相关族借来的，而非独立属于它自己。

### 噪声与改写稳定性门

**挑战。** 漂移—破坏相关的可信度不超过计算它所用的探针题项与解码样本；如果相关在一种措辞下出现、在另一种下消失，它反映的是测量工具选择而非被审计版本的性质。

**洞察。** 一个报告的漂移分数在被证明超过普通版本内解码噪声之前不应被当作信号信任；一个报告的族排名在被证明经得起同一批探针的独立改写之前不应被信任——两者都是测量工具的可检验性质，而非关于它的假设。

**方法。** 对每个族，通过在固定与重采样解码下重复查询同一版本来估计版本内零分布；跨版本漂移分数仅在超过该零分布第 95 百分位时才计入排名。另外，完整的族预测力排名在至少三个独立改写的同题项探针集下重算，仅当排名在这些集之间保持稳定（以 Kendall 秩相关衡量）时才被信任。只有同时通过两道门的漂移分数与排名才被允许进入上文的联合回归与偏归因模块。

### 留出对评估与轴匹配防护

**挑战。** 探针组是在它本应预测的同一批已发生漂移事件上验证的。这一基底在两个具体方面是循环的：在用于拟合模型并选择 S* 的对上以样本内方式打分的预测力估计，对前瞻性使用毫无证明力；而一个结构上就是微缩下游任务的探针族——由 IFEval/JSON 模式题项构建的格式偏好探针对阵提取到 JSON 的下游任务——会靠自相似而非迁移来"预测"该任务的破坏。

**洞察。** 两种循环都可以通过构造来检验，而不必事后争辩：预测性断言可以只在拟合之外的留出对上打分；测量工具与目标共享同一行为轴的探针—任务单元格可以事先标注并从主断言中隔离，而不是事后才发现。

**方法。** 所有主预测力估计——每个 π_f 与每个子集 AUC——均由按模型谱系分组的留一对交叉验证计算，使共享更新事件的对绝不跨越折边界；样本内拟合仅作为诊断报告。每个（探针族，下游任务）单元格预先标注为*同轴*（same-axis）或*跨轴*（cross-axis）；同轴对角单元格（如格式偏好探针对阵格式敏感的提取任务、安全行为探针对阵内容审核任务）为完整性而报告，但被排除在主预测断言之外——主断言必须由跨轴迁移承载。作为构造约束，探针题库与下游任务输入集取自不相交的来源，不共享任何题项或生成模板。最后，时间前向检验（见实验设置）从披露升格为门：如果前向拟合子集的留出表现远低于分组交叉验证估计，前瞻性使用断言即被作废，而不只是加注说明。

## 实验（Experiments）

### 实验设置（Experimental Setup）

**数据集。** 开放权重版本对语料（诸如 Llama-2→Llama-3、Qwen1.5→2→2.5、Mistral v0.1→v0.2→v0.3 的接续检查点）构成研究骨干，因为这些检查点被不可变地存档，天然满足可达性门。带日期的闭源 API 快照对——仅限研究开始时仍在服务的带日期快照——被特别纳入为最可能在研究期间因提供商侧下线而不可达的层，使语料流失偏倚检验有真实的高危对可测，而不只有不可变的对。（更早的快照世代，如 gpt-3.5-turbo-0301/0613/1106 与 gpt-4-0314/0613，已于 2024 年中之前退役，无法再通过可达性门；此处提及仅作为流失风险*类别*的示例而非可准入的对——退役快照只能经由此前发布的缓存输出语料进入，而后者不满足该门的相同解码重查询要求，因此被排除。）探针题库每族取一：能力（MMLU / GSM8K / BIG-Bench-Hard）、拒答边界（XSTest / OR-Bench 风格的边界请求）、格式偏好（IFEval 风格约束加 JSON 模式合规集）、校准（带已知正确性标签的语义校准题集）、安全行为（借鉴既有过度拒答与操作范围基准风格的近危害与超范围提示）。约二十个真实任务的下游套件（提取到 JSON、分类、检索增强问答、工具调用参数填充、内容审核）提供用于计算功能破坏的共享输入集，特意选择横跨格式敏感、校准敏感与安全敏感任务，使任务异质性（见下）可检验而非被假定。

**计算预算。** 在确证下限 |P| = 60 对时，完整设计的成本约为 60 对 × (约 1,500 探针题项 + 约 4,000 下游输入) × 2 版本 × ≥3 次解码重复 ≈ 200 万次生成——比试点档高一个数量级——预算为开放权重骨干上的多 GPU 数周加上数千美元级的带日期 API 层。试点（3–5 对、约 500 探针、约 10 任务、≥3 次重复）约 2–5 万次生成，作为投入上述开销之前的通过/中止门。

**安慰剂，在任何研究问题之前检验。** 在下文任何 RQ 被评分之前，先将一个构造为零的安慰剂（P0）通过与 RQ1/RQ2 完全相同的预测器与交叉验证流水线：将族漂移特征向量 D(p) 与破坏目标 B̄(p) 在对之间随机置换（破坏对级对应关系但保留两个边缘分布），并在打乱的数据上重新拟合同样的联合回归与分组交叉验证子集搜索。由于对应关系被构造性破坏，P0 的预测力*必须*为零：每个族的打乱系数置信区间必须包含 0，打乱 AUC 的 95% 置信区间必须包含 0.5，至少 1,000 次打乱。此处出现非零结果并不意味着某个探针族能预测破坏——而是意味着流水线本身泄漏（例如交叉验证分组泄漏，或 D 与 B̄ 共享的按对干扰量如提示长度、解码温度），该轮运行无效：随之而来的是诊断并从最小可行框架重跑，而不是对任何 RQ 打出评分。

**基线**（健全性对照，不是要击败的竞争者——这是一项测量研究，此处没有任何研究问题被表述为"我们的程序击败基线 X"）。单探针族预测器（每族漂移单独使用）是任何"哪个族在联合模型中占主导"断言的必要对照。不使用任何探针特征的常数基准率预测器（B0）是证明问题存在的对照臂：如果没有任何族或子集击败它，就没有探针携带可用信号——注意 B0 是要击败的性能下限而非安慰剂，因为它不会像上文 P0 那样因流水线伪影而出现非零结果。不区分族的总漂移标量（B-alt）——在相同查询预算下对整个探针库计算的原始输出差异，忽略族结构——是"任何观察到的预测其实只是在跟踪更新总体幅度而非移动了哪条轴"这一对立解释；下文的轴归因断言只有在族结构化预测器击败该标量时才名副其实。仅限能力族、仿照既有基准压缩设计的题项子集压缩基线 [EssenceBench2607]，检验更廉价的族内选择是否已捕获能力族自身信号的大部分。随机/均匀漂移分数基线锚定比较的下端。

**指标。** 标准化回归系数及其自助法 95% 置信区间；偏相关与方差膨胀因子；跨版本漂移与版本内噪声下限之比；族排名在改写集之间的 Kendall 秩相关（取所有改写集两两比较的最小值而非平均值，使单个不稳定的配对不会被平均掉）；子集消融准则的交叉验证 AUC；以及将留存与流失对之间漂移幅度与 ±0.5 SD 容限比较的 TOST 等价检验统计量。

**前向验证（对前瞻性使用断言的门）与成本核算。** 由于审计协议的预期用途是前瞻性的——每次版本升级运行一次最小子集——而族排名与子集是在已发生的对上、以谱系分组交叉验证估计的，因此额外运行一个时间切分前向验证检验：族排名与最小子集在时间上较早的版本对上拟合，并在最新的留出对上评估（子集 AUC 与排名 Kendall τ），前向数字与分组交叉验证数字并列报告。该检验是**对前瞻性使用断言的门**，而不只是披露的稳健性维度：如果前向评估的子集 AUC 低于分组交叉验证估计超过预注册的充分性容差 δ，前瞻性使用断言即被作废，协议只报告为回顾式验证——薄的时间折（对数少）会降低该门的灵敏度，这一降低本身也会被报告，但不降低该门的约束力。与所有结果一起，一张确定性成本核算表报告所选最小子集相对完整下游重测在每次版本升级中的查询数、货币成本与墙钟时间，量化最小化论证所依赖的审计开销节省。

**研究问题：**
1. RQ1 —— 五族联合考虑时，哪个探针族的漂移（如果有的话）是下游破坏的最强预测器？
2. RQ2 —— 是否至少有一个探针族携带统计上可区分的预测力？
3. RQ3 —— 下游破坏是否在敏感性不同的任务之间有意义地变化，而非在下游套件中均匀分布？
4. RQ4 —— 研究期间因语料流失而丢失的版本对，其漂移幅度是否与始终可访问的对存在系统性差异？
5. RQ5 —— 一个族的解缠（偏）贡献与其原始相关在秩序上是否不一致，从而揭示共线性驱动的错误归因？
6. RQ6 —— 跨版本漂移是否超过版本内噪声，并在独立改写的探针集之间保持排名稳定？

#### RQ1：五族联合考虑时，哪个探针族的漂移（如果有的话）是下游破坏的最强预测器？

**设置。** 试点阶段：3–5 个带不可变检查点的开放权重版本对，约 500 题项横跨五族的探针库，约 10 个任务的下游套件。扩展目标：**至少 60 个版本对**，横跨开放权重与闭源 API 两层（更多已存档的开放权重接续加带日期 API 快照，以配置变更方式加入，绝不以缩减每对任务覆盖为代价），约 1,500 题项的探针库与约 20 个任务的下游套件——该下限由下文功效分析设定，并非为方便而选。联合回归：B̄ ~ Σ_f D_f，对版本对做自助重采样（10,000 次）构建每个系数的置信区间；系数两两差异经配对自助法在 α = 0.05 下检验，并对十个族对做 Holm 校正。

**功效门。** 该检验的有效样本量是版本对数 |P|，而非约 400 个（对，任务）单元格——单元格在回归之前坍缩为每对一个 B̄(p)，因此不是独立重复。按 Fisher-z 在双侧 α=0.05 下，检出真实 ρ = 0.30（下文的效应下限）在 |P|=20 时功效约 0.25，|P|=40 时约 0.47，仅在 |P|≈85 时达到 0.80；对 π_top − π_cap 的确证配对自助检验（对 10 个族对做 Holm 校正）需要的对更多。因此：|P| < 40 时 RQ1 仅报告为**探索性**（仅点估计与置信区间，不给确证判定）；40 ≤ |P| < 60 时排名预先声明为**不确定**，绝不作为触发回退的失败；下文的确证通过/失败判定仅在 |P| ≥ 60（功效 ≥0.65）时评分。进一步的修正：同一谱系内的版本对（如跨多个规模的 Qwen1.5→2→2.5）共享更新事件、并不独立——因此所有自助重采样与交叉验证折均按谱系分组，且当谱系贡献多个对时，上述功效算术以谱系分组的更新事件数而非原始对数解读，使有效样本量绝不因谱系重复而被高估。

**预期结果。** 在 |P| ≥ 60 时：自助中位标准化系数最高的族是拒答边界或安全行为，而非能力，且 π_top ≥ 0.30，最强族减能力族的系数差 95% 置信区间严格大于零。

**证伪条件。** 在 |P| ≥ 60 时：若能力族的标准化系数最大，或最强族对能力族的置信区间包含零，则被驳斥——两者任一都意味着政策/行为漂移事实上并不比原始能力回退更能决定下游破坏，与"熟悉的能力重测覆盖不了真实风险"这一动机前提相反。低于 |P|=60 时，未命中报告为功效不足下的不确定，而非假设被证伪。

**假设（通俗表述）。** 团队最可能已经在重测的行为轴（能力），并不是真正决定其集成是否破坏的那条轴。

**指标。** 每族标准化回归系数及自助 95% 置信区间；最强族与能力族的配对自助差异。

#### RQ2：是否至少有一个探针族携带统计上可区分的预测力？

**设置。** 与 RQ1 相同的联合回归拟合；每族系数置信区间分别与零比对，五族做 Holm 校正。

**预期结果。** 至少一个族的系数 95% 置信区间不含零，确立探针漂移对下游破坏携带真实预测信号，而非五族都与无信号零假设不可区分。

**证伪条件。** 若每个族的系数置信区间都包含零，则被驳斥——那意味着五条行为轴无论单独还是在此联合设定中都不预测下游破坏，动摇"任何可观测探针都值得运行"的前提（此时本研究自身设置中的 B0 比较也应显示没有探针击败基准率）。

**假设（通俗表述）。** 可观测的行为探针漂移携带关于下游破坏的真实信息，而不是打扮成排名的噪声。

**指标。** 每族系数置信区间；不含零的族数。

#### RQ3：下游破坏是否在敏感性不同的任务之间有意义地变化，而非在下游套件中均匀分布？

**设置。** 在合并之前为每个（对，任务）单元格计算按任务破坏分数 B(p, t)；在两个预先声明、检视而非事后搜索的任务敏感性对比上比较各族漂移—破坏相关 ρ_f(t) = Spearman ρ(D_f(p), B(p,t))：(i) 格式敏感任务（如提取到 JSON）对阵校准敏感任务（如答案置信任务），(ii) 安全敏感任务（如内容审核）对阵能力敏感任务（如推理任务），跨全部对计算，并对所检视的两个对比做 Holm 校正。

**预期结果。** 两个预声明对比中至少一个，其按任务相关在绝对 Spearman ρ 上相差至少 0.15，且差值的配对自助 95% 置信区间不含零——即它们在幅度上或在哪个族相关最强上有意义地不同，而非跟踪同一个与任务无关的共享模式。

**证伪条件。** 若两个预声明对比都未达到 ≥0.15 的标准，则被驳斥——那意味着单一合并破坏分数相对按任务打分损失的信息很少，削弱先按任务定义破坏再聚合的理由；任何异质性都小于该设计的分辨能力，是断言的收窄而非消除。

**假设（通俗表述）。** 下游破坏是真正任务特定的，而不是恰好在二十个地方被测量的同一个标量。

**指标。** 按任务漂移—破坏相关及其置信区间；任务对之间的比较检验。

#### RQ4：研究期间因语料流失而丢失的版本对，其漂移幅度是否与始终可访问的对存在系统性差异？

**设置。** 在研究期间跟踪哪些带日期闭源 API 快照对变得不可访问；对每个族，计算流失子集与始终可访问子集之间 |D_f(p)| 的标准化均值差。此处检验的是**等价性而非未拒绝**：刻意不用普通双样本显著性检验，因为在流失的闭源 API 对很少时，不显著结果只是给功效不足的检验盖上"无偏"的橡皮章，而非来自真实证据。改用双单侧检验（Two One-Sided Tests, TOST）等价检验，检查标准化差是否落在预声明容限 Δ_eq = 0.5 SD 之内，α=0.05，五族做 Holm 校正。

**预期结果。** 五个族全部确立等价（两个单侧检验都拒绝）——流失与留存对之间 |D_f(p)| 的标准化均值差对每个族都落在 ±0.5 SD 内，支持留存语料未被"哪些对恰好保持可查询"系统性偏倚。

**证伪条件。** 若某族的 TOST 等价检验被拒绝——即标准化差超出 ±0.5 SD 容限——则该族被驳斥，意味着其留存样本存在流失偏倚；那意味着回顾式语料系统性欠采样了恰恰对该族漂移最有信息量的版本对，使涉及它的主排名有偏。若流失层的对数太少以至无法为 TOST 提供功效，则该族的 RQ4 报告为**不确定**（测量工具/功效失败，而非实质性零结果），且每个主排名都同时以合并方式与仅开放权重的无流失子集方式报告，作为稳健性检查。

**假设（通俗表述）。** 研究期间失去对一些旧 API 快照的访问，不会使语料悄然偏向"无聊的"版本对超过预声明的小效应容限。

**指标。** 每族流失对与留存对之间 |D_f(p)| 的标准化均值差；每族对 ±0.5 SD 的 TOST 等价检验统计量。

#### RQ5：一个族的解缠（偏）贡献与其原始相关在秩序上是否不一致，从而揭示共线性驱动的错误归因？

**设置。** 计算每个族与 B̄(p) 的原始成对相关及其经 VIF 检查的、扣除其他四族的偏相关；比较五族上的两个秩排序。

**预期结果。** 至少一个族的原始相关名次与偏相关名次相差至少一位，表明族间共线性不可忽略，只报告原始相关会把预测力错误归因到错误的轴上。

**证伪条件。** 若原始与偏相关排名在五族上完全一致，则被驳斥——那意味着对该语料而言五条行为轴实际上独立，共线性解缠步骤（仍是有效检查）在此没有做任何矫正工作。

**假设（通俗表述）。** 至少一个族的表面预测力部分是另一个族漂移的共线回声，而非完全属于它自己。

**指标。** 每族原始与偏相关的秩序比较；VIF 值。

#### RQ6：跨版本漂移是否超过版本内噪声，并在独立改写的探针集之间保持排名稳定？

**设置。** 通过对同一版本重复重解码查询，估计每族的版本内零分布；检验跨版本漂移是否超过该零分布第 95 百分位（单侧置换检验，各族 Holm 校正，α = 0.05）。另外，在至少三个独立改写的探针集下重算完整族预测力排名，并对改写集的每个两两比较计算排名的 Kendall 秩相关，报告**最小**两两值（而非平均值），使单个不稳定的配对不会被其他配对平均掉。

**预期结果。** 五族中至少 3 族的跨版本漂移超过版本内噪声下限，且所得族排名在改写集之间 Kendall τ ≥ 0.70。

**证伪条件。** 若少于 3 族越过噪声下限，或排名在改写集之间的 Kendall τ 低于 0.70，则被驳斥——两者任一都意味着 RQ1/RQ2/RQ5 报告的相关至少部分是解码噪声或特定探针措辞的伪影，而非被审计版本的性质。

**假设（通俗表述）。** 测得的漂移—破坏信号是被审计模型的性质，而非探测它们所用具体措辞的性质。

**指标。** 每族漂移与噪声下限之比；族排名在改写集之间的 Kendall τ。

## 相关工作（Related Work）

**跨版本变更检测与更新治理。** 最接近的已有工作是一条已经能在不访问权重的情况下跨版本对比较模型行为的黑盒变更检测线：托管模型行为随带日期快照显著漂移的纵向证据 [ChenDrift2307]；检测已部署端点行为偏移或静默修改的序贯与双样本审计 [AuditBehaviorShift2410; YouveChanged2504; RankUniformity2506]；判定 API 实际在服务哪个模型的分布等价与对数概率检验 [ModelEquality2410; LogProbTracking2512; ModelSubstitution2504]；以及端点稳定性与身份的多行为指纹 [BehavioralFingerprints2603]。这些全都在回答"模型变了吗？"——其中若干还带有本文噪声下限刻意与之呼应的模型内采样噪声零假设 [ModelEquality2410; RankUniformity2506]——但没有一个将其变更信号与功能性定义的下游破坏真值做验证、将预测力归因到行为轴、或追问多少探针才够。互补的更新治理线从相反的一端回答破坏问题：在每次更新时重新运行直接的下游测试 [TestBeforeDeploy2604]、把智能体技能漂移当作契约违背处理 [SkillDriftContract2605]、或对受监管工作流做任务级输出漂移检查 [LLMOutputDrift2511]。这些工作确证版本更新确实会弄坏集成，但代价恰恰是廉价探针协议存在的意义所要避免的按次升级成本——且没有一个追问哪条行为轴能预测它们所测量的破坏。本文主张的估计对象——样本外的、按轴分解的探针漂移到破坏的预测力，以及最小充分族子集——不为上述任何一条线所主张；反过来，本文的空白断言也刻意收窄到该估计对象，因为跨版本行为比较本身如今已被充分覆盖。

同一审计家族中一个更早的、构念特定的成员比较微调模型发布是否沿一个共享行为构念偏离其基座模型，从两者共有的提示计算多视图相似性签名——称之为跨发布行为相似性线 [BiasSimBSM2607]。它已经确立：对两个模型发布之间行为变化做严格的、无需权重的审计是可能的，不必观察任何一方的参数。但它一次只审计一个构念（公平性/偏见），止步于成对相似性分数；它从不追问测得的偏离是否预测任何下游应用真的破坏，也不比较在多条行为轴可用时哪条是更好的预测器——而这正是本文要回答的比较性、面向破坏的问题。

**基准压缩与最小子集设计。** 这一方向的工作选取基准题项的小子集，使其联合重构完整基准分数并保持跨模型排名，同时建模语义冗余与按题项排名冗余，以找到仍能讲出完整基准同样故事的最小集 [EssenceBench2607]。这是与本文"充分集可以多小"问题最近的方法论表亲，但它回答的是另一个目标：在一个固定指标下保持对既有分数的保真度，而非跨版本对预测一个独立的下游破坏结果。一条互补的线确立了能力/生成轴具体来说可以用相对较少的样例跨发布测量与监测，为能力探针为何是探针组的合理成员提供了根据 [CondGenBench0511]。

**经典先例，坦承。** 最小化问题的抽象形态——保留故障检出力的廉价测试最小子集——并不新鲜：它是软件工程中回归测试选择与测试套件最小化文献的核心 [RothermelHarrold1997; YooHarrold2012]，而"廉价监测器预测昂贵退化"同样是流学习中概念漂移检测（concept drift detection）的核心 [GamaDrift2014]。本文不主张对最小化准则本身的首创地位；该准则继承自这些经典脉络并归功于它们。移植中断裂的是那些方法的假设：确定性通过/失败判定器与白盒覆盖信息（测试套件最小化），或流式标签供给（概念漂移检测）——这些在此都不存在：这里的"故障"是在选定轴上、以黑盒方式、跨两个离散版本检查点观察到的概率性行为漂移。按轴分解、无判定器、黑盒的破坏预测是本文瞄准的剩余空白。

**单轴行为测量工具。** 一簇近期工作使各条行为轴分别精确可测：以模型拒答概率与其错误概率的相关计算的秩不变拒答度量 [RefusalIndex2607]；将完整生成坍缩为等价类而非要求单 token 置信度的语义校准概念 [BCalibration2607]；检验政策条件化智能体是否接受范围内请求同时拒绝范围外请求、并在对抗与多语言条件下压力测试的基准 [OffTopicEval2607]；以及集中于特定模型层的系统性、广泛误拒的文档化记录 [ProSafePrune2607]。每一个都是在单一时间点评估的强单轴诊断工具；没有一个曾跨版本对与另一条轴比较、或对下游破坏真值做回归——而这正是本文运行的复合比较。另有两个单轴结果从相反方向支撑同一论点：预训练语言模型的校准本身是动态的、依赖状态的，并非随规模单调改善 [PLMCalib9999]；LLM 的能力自评存在可测量的过度自信，且在更新或更大的模型中并不单调变好 [CapableOf4661]——两者都与本文"行为轴确实随模型变更漂移，而非'模型有多强'的固定属性"这一前提一致。在同一批族的构建侧，一个语言学根基的指令冲突、嵌入命令与政策歧义分类法为拒答边界与安全行为探针题项提供种子材料，其标签被设计为在模型变化时仍保持意义 [AdversarialPragmatics1153]；一个查询高效的行为诱出方法——其动机正是静态安全基准在更新的模型发布上饱和——提供了让此类题库随时间保持诊断力的路径 [ElicitBehaviorsMultiTurn3701]；两者都是本文探针题项设计可以借鉴其纪律的单快照工具，而非跨版本破坏预测器。一项同原型的单行为轴测量研究——多方压力下的智能体忠诚，带有已演示的泄漏/过度拒答权衡前沿——示范了本设计要在整个探针组上施加的轴特定严谨性 [PrincipalLoyalty0383]。

**测量工具脆弱性与模型更新的训练侧视角。** 一项提示敏感性研究表明，同一提示的语义等价改写可以引发大的行为摆动，论证从单一措辞取得的单标量测量是不可靠的优化目标 [TARE2607]——本文对自己的漂移测量、而不仅是对其他工作优化的提示认真对待这一警告。同样精神下，一个测量评估者偏好动态的标准化协议记录了专有模型静默更新——导致测量在数周内衰减——并以带版本的参照快照应对 [EvaluatorPrefDynamics0297]；它与本文共享静默版本更替的动机现象，但其估计对象是评估者胜率随版本的耦合，而非按轴分解的下游破坏。一项相关的因果干预研究表明，数学题的表面形式扰动可以独立于所需的底层推理翻转模型的正确性，是对能力探针族的互补稳健性关切 [CausalRobust6745]。从接口的另一侧，一项关于预训练模型与其微调变体参数空间差异的研究使模型更新可解释为权重空间中的结构化向量 [WeightDiff2607]——但该路径需要对两个检查点的白盒访问，而从外部审计版本升级的 API 消费者永远没有，这正说明为什么可观测的黑盒探针组是该消费者唯一可用的杠杆。最后，提供商版本升级之外的模型级修改——例如剪枝、量化或蒸馏压缩——也已被证明按技术差异化地移动特定行为轴（公平性），且内在与外在公平性指标出现分歧 [CompressFair0878]，进一步印证模型变更下的轴特定行为漂移是本文设计必须与之隔离的普遍现象，而不只是提供商侧版本更新特有的伪影。

## 结论（Conclusion）

这项工作把从业者已经依赖的一个治理假设——廉价的按版本探针可以替代完整下游重测——转化为一个带有明确可识别性结构的可测量问题，而非将任何单一探针族视为不证自明地充分。核心的方法论押注是：哪条轴决定破坏、是否有任何轴携带信号、以及观察到的相关是真实的还是共线回声或测量工具伪影，这些问题只能一起回答，来自一个带有自身噪声下限与改写稳定性门的协调联合模型——而非五个孤立运行的独立单轴检查。无论哪个族或子集通过了该门控，发现都是直接可操作的：在版本升级后选择重测内容的团队，将拥有证据而非直觉来决定监测哪条轴、以及监测清单可以安全地小到什么程度。四条局限从一开始就为该断言划界，并指向具体的后续步骤而非事后附注：回顾式设计只能刻画已经发生且保持可访问足够久的版本对，将对尚未发布版本破坏的前瞻性预测留给带有自身验证设计的后续工作；与此相关，由于探针集是在它本应预测的同一批已发生漂移事件总体上验证的，每个主预测断言都在谱系分组交叉验证下的留出对上打分、并排除同轴探针—任务单元格，且时间前向检验具有约束力——样本内与前向之间的大差距会直接作废前瞻性使用断言，而非作为附注存活；各族探针工具从被引用的单轴工作借用其拒答、校准与安全范围构造，其中基于判断的标签（例如某输出是否算拒答）不享有为下游破坏分类器保留的完整评分者间验证方案——其标签可靠性是要报告的既定假设，而非此处认证的性质；共线性解缠步骤（RQ5）本身可能揭示某些语料上多条轴携带不可分离的共享信号，此时诚实的报告是一束相关的轴而非单一主导轴——这是本设计构建来检测并报告、而非辩解掉的真实可能结果。
