## N2 Motivation (verbatim from proposal.motivation)

Recent reasoning-oriented large language models rely heavily on long chain-of-thought generation to achieve strong performance on complex tasks. This practice, often described as test-time scaling, allocates large reasoning budgets uniformly across queries regardless of their actual difficulty. However, emerging evidence suggests that this strategy leads to substantial inefficiencies. For example, @ma2025withoutthinking demonstrates that many reasoning tasks can be solved accurately without generating explicit reasoning traces, indicating that lengthy chain-of-thought generation is frequently unnecessary. Similarly, @lou2025adacot highlights that invoking chain-of-thought reasoning involves a trade-off between accuracy and computational cost, motivating adaptive strategies that selectively allocate reasoning resources.

Recent approaches have attempted to address this inefficiency through adaptive reasoning mechanisms. Methods such as @liang2025thinkswitcher and @fang2025thinkless enable models to switch between short and long reasoning modes depending on task complexity. Meanwhile, @huang2025adactrl introduces difficulty-aware reasoning budgets using reinforcement learning, and @yang2025deer proposes confidence-based early exit during generation to reduce unnecessary computation. While these approaches demonstrate the promise of adaptive reasoning, they reveal two key limitations. Training-based approaches require expensive retraining or reinforcement learning pipelines that modify the underlying model, reducing portability and increasing deployment complexity. In contrast, inference-time methods such as early exit rely on signals observed during generation, meaning that some reasoning tokens must already be produced before inefficiencies can be detected.

This gap suggests an opportunity for proactive reasoning allocation: predicting the difficulty of a query before generation begins and selecting an appropriate reasoning strategy accordingly. Such a mechanism would enable adaptive compute allocation without retraining the base LLM and without incurring unnecessary generation overhead. The core research problem, therefore, is how to estimate question difficulty using signals available at prefilling time and leverage this prediction to dynamically allocate reasoning budgets in a lightweight and generalizable manner.

## N6 Methodology (verbatim from proposal.method)

Our approach introduces DiffAdapt, a lightweight inference framework that predicts problem difficulty from an LLM’s internal representations and dynamically selects among multiple reasoning strategies with different computational budgets. Instead of relying on reinforcement learning or generation-time signals, the framework uses a small probe trained on hidden states extracted during the prefilling stage. The predicted difficulty class determines which reasoning configuration—Easy, Normal, or Hard—is executed, enabling proactive allocation of reasoning tokens while keeping the base LLM unchanged.

1. **Entropy-Guided Difficulty Characterization**: We first analyze the relationship between reasoning difficulty and generation uncertainty by measuring token-level entropy in reasoning traces. This analysis reveals a consistent U-shaped entropy pattern, where easy problems exhibit high entropy despite high correctness, medium problems show lower entropy, and hard problems again display high entropy due to uncertainty. This observation provides empirical evidence of overthinking, complementing findings from @ma2025withoutthinking, and motivates dividing tasks into three computational regimes corresponding to Easy, Normal, and Hard reasoning strategies.

2. **Self-Supervised Strategy Label Generation**: To train a difficulty predictor without manual annotation, we construct training data through proxy model sampling. For each query, the model generates multiple reasoning traces from which correctness and entropy statistics are computed. Inspired by adaptive reasoning formulations such as @lou2025adacot, heuristic rules combining entropy and correctness assign each query to an optimal strategy class (Easy, Normal, Hard), producing supervision signals for training the probe.

3. **Hidden-State Difficulty Probe**: We train a lightweight multi-layer perceptron classifier that predicts problem difficulty from the final-layer hidden state produced after prefilling the input question. Unlike RL-based approaches such as @huang2025adactrl, the base LLM remains frozen and only the probe parameters are trained. This design allows difficulty prediction to be performed with minimal computational overhead while leveraging rich semantic information already encoded in the model’s internal representations.

4. **Strategy-Based Adaptive Inference**: At inference time, the trained probe predicts the difficulty class before any reasoning tokens are generated. The prediction selects one of three predefined inference strategies: Easy prompts encourage concise answers with small token budgets, Normal strategies apply standard chain-of-thought reasoning, and Hard strategies impose fail-fast limits to avoid excessive computation on queries beyond the model’s capability. This design operationalizes the multi-mode reasoning concept explored in @liang2025thinkswitcher while avoiding auxiliary switching models.

Together, these components create a proactive adaptive reasoning system that allocates computation before generation begins. The hidden-state probe provides efficient difficulty estimation, while strategy-based execution ensures that reasoning budgets match problem complexity, reducing unnecessary token usage without sacrificing accuracy.
