## 摘要（Abstract）

诊断一条长 LLM 智能体轨迹（LLM-agent trajectory）为何失败，正日益依赖反事实重放（counterfactual replay）：从某个中间检查点（checkpoint）重新执行轨迹，并检查该任务自带的验证器（verifier）是否仍然失败。一个决定性失败（decisive failure）会腐蚀智能体与环境状态，且该状态被每一个更晚的检查点继承、却不被任何更早的检查点携带，因此这一重放结果近似于检查点序号的阶跃函数（step function）——然而现有的基于重放的归因系统，要么逐步穷举式地花费其重放预算，要么以一个未经检验的单一成本点进行启发式剪枝，却从未追问：多少次定向重放本来就已足够。我们构建了一个按位置相关重放单位（position-dependent replay units）为每次探测计费的带检查点重放框架（checkpointed replay harness）、一个在 plan / tool / execution 三层间均衡的、经重放验证的故障注入轨迹语料库（replay-verified fault-injected trajectory corpus），以及两种结构化定位策略——对检查点序号的二分搜索（bisection）与耐噪声分组测试（noise-tolerant group testing）——每种策略都通过显式的投票次数去噪，并对照"底层阶跃函数假设本身失效的经验频率"加以测量。我们在相同轨迹、相同重放单位预算下，将这两种策略与穷举式逐步扫描（exhaustive per-step scan）、预算匹配的均匀采样（uniform sampling）以及零重放的仅读日志判官（zero-replay log-only judge）进行比较，报告每种策略的成本-准确率曲线（cost-accuracy curve）而非单一点估计，使团队可以直接读出自己的重放预算究竟能买到什么。

## 引言（Introduction）

长 LLM 智能体轨迹——数十个链式衔接的 plan、tool-call、execution 步骤——如今已是智能体开发中的常态；当其中一条轨迹失败时，总得有人找出那个决定结局的步骤。传统做法是人工阅读交互日志，但随着轨迹变长，这种人工检查变得代价高昂且不一致，并且它止步于相关性：一个看起来可疑的步骤，并不等于一个真正起决定作用的步骤。因果上可靠的替代方案是反事实重放——从某个中间检查点重新执行轨迹，并检查任务自带的验证器是否仍然失败——因为只有重新执行才能表明一个被假设的失败点确实负有责任，而不仅仅是恰好在附近。

然而每一次重放都会重新调用真实的 LLM 与工具调用，因此重放次数本身就是一种稀缺、昂贵的资源，而那些生成因果验证标签的基于重放的标注系统，把它当作事后考虑而非受配给的预算。它们沿整条轨迹一步一步地重放，以构建带验证失败标签的训练语料，付出与轨迹长度成线性的重放次数，却从未追问：要回答调试时唯一要紧的问题——哪个步骤是决定性的、它发生在哪一层（plan、tool 还是 execution）——多少次重放本来就已足够。一个决定性失败会腐蚀智能体与环境状态，该状态被每个更晚的检查点继承、却不被任何更早的检查点携带，这意味着重放结果近似于检查点序号的阶跃函数；如果这一结构能被一个只探测少数几个检查点的搜索策略利用，那么经因果验证的归因就不再是昂贵的离线标注步骤，而是便宜到每次轨迹失败时都能运行。

最接近的现有工作从相邻但不同的角度触及这一空白。围绕穷举重放构建的系统（如 AgenTracer）确实通过逐步替换单个步骤并检查轨迹结局是否翻转来生成因果验证的失败标签——但这种穷举扫描被纯粹当作离线语料构建成本，任何地方都没有刻画"更聪明的搜索能节省其中多少成本"。仅读日志的归因系统（如 Who&When）让 LLM 判官读转录文本，从而完全绕开了重放成本，却在因果有效性上付出代价：其自身报告的结果显示，步级归因显著差于智能体级归因，正是因为一个从不重新执行任何东西的判官无法验证假设，只能猜测。介入驱动的系统（如 DoVer）介于两者之间：它们通过重放来验证一个假设，但假设本身来自 LLM 对故障位置的猜测，从未在检查点空间上运行任何预算最优的搜索——"结构化搜索需要多少次重放"这个问题从未真正被提出。近来的两项进展使这一空白更锐利，而非将其关闭。仪器级规模的故障注入已经到来：Who&When Pro 通过精确重放一条成功前缀并在边界处注入故障，构建了 12,326 条带黄金标签（golden labels）的注入失败轨迹——但它用这一语料来评测读日志的归因器，从未追问在检查点上搜索需要多少次重放。同时，2026 年出现了一批以效率为动机的归因系统——CHIEF 在因果图上的 oracle 引导回溯、FALAT 的依赖引导搜索（dependency-guided search）、HPFA 对照成功参考路径的超图比较、MARS 对修复空间的预算裁剪树搜索——它们把归因或修复成本当作头等关切，但每个系统只报告其自身流水线落在的单一成本工作点；没有一个给出供给决策真正需要的东西：在匹配重放开销下跨策略的成本-准确率曲线。

把这个问题变成可测量的问题，会暴露出它自身的困难。由于一次重放要重新执行整段轨迹后缀（suffix），其成本不是固定的单次探测单位，而是随轨迹剩余长度伸缩——因此任何关于节省的断言都必须以反映这一点的成本单位计费，而不是以原始探测次数计，后者会给在不同位置探测的策略错误定价。搜索策略要利用的阶跃函数结构本身只是近似成立：如果某个中间步骤能从早先的故障中部分恢复，重放信号就不再是干净的阈值，而一个为利用该阈值而构建的搜索可能在毫无预警的情况下收敛到错误的序号。每一次重放还都是一次随机抽样——在非零采样温度下把同一段后缀重放两次可能得到不同的通过/失败裁决——所以定位策略必须决定单次探测需要多少次重复重放其答案才可信，而这种去噪本身也在争夺同一份有限预算。此外，由于轨迹横跨三个步骤语义各异的异质层，一个决定性失败可能跨层显现——一个糟糕的早期 plan 决策只在后来的某次 tool 调用中才浮出水面——这使任何搜索策略如何切分其检查点空间变得复杂。

我们的方法把上述每个障碍都转化为一项具体的测量设计，而非一句托辞。每次重放都以位置相关重放单位——续算的 LLM 调用数（resumed LLM calls），而非探测次数——计费，因此节省断言反映的是重放在轨迹中任何位置的真实成本。二分搜索直接利用检查点序号阶跃函数，同时记录完整的经验重放剖面（profile），使阶跃函数假设失效的频率被测量而非被假设掉，并可作为"二分捷径在何处仍然成立"的特定预测因子加以检验。每次探测通过显式的、被扫描的重复重放次数去噪，而非一个隐藏常量，把 oracle 噪声从假设变成被测量的量。耐噪声分组测试搜索以内建冗余切分检查点空间——包括跨层切分——作为二分的补充，使归因不局限于同层连续步骤段。而一个经重放验证、按层均衡的故障注入轨迹语料库，让每一种策略——二分、分组测试、穷举重放、均匀采样、零重放仅读日志判官——都能在相同轨迹、相同重放单位预算下比较，这是所引任何系统自身评测目前都不提供的共享比较。

我们在一个确定性家务任务模拟器和一个缓存网页工具使用域中、带有程序化注入且经重放验证的失败位置（横跨 plan / tool / execution 三层）的轨迹上，外加一个人工标注的自然失败切片（natural-failure slice），评估该设计，在共享预算网格上比较每种策略的成本-准确率曲线，而非在单一预算下报告单一准确率数字。

综上，我们的贡献是：
- 对反事实重放位置相关成本的识别与直接核算——以续算 LLM 调用为单位而非原始探测次数——表明忽略探测落在轨迹何处的成本-准确率比较，有给其所比较的每一种定位策略错误定价的风险。
- 对使二分高效的假设——重放信号的单调性违背率（monotonicity-violation rate）——做出可测量、可证伪的转化：直接将其作为"二分捷径在何处成立、在何处悄然失效"的预测因子加以检验，而非留作一句未言明的风险。
- 刻画基于冗余的分组测试搜索在何种噪声区间超越投票倍增的二分搜索，以及在何种层区间，分组测试切分跨越 plan/tool/execution 边界有助于定位连续切分所遗漏的决定性失败。
- 首个在相同轨迹上、匹配预算下，将结构化重放搜索与穷举逐步重放、预算匹配均匀采样、零重放仅读日志判官正面对比的成本-准确率比较——确证序号结构与重放访问是否、以及各自在多大程度上真正起作用。

## 问题定义（Problem Definition）

**形式化设定。** 考虑一条已经失败的轨迹 τ = (s₁, ..., s_n)，其中每个步骤 sᵢ 是一次 LLM 调用连同其工具结果，每个步骤边界有一个智能体与环境状态的检查点 cᵢ。重放 oracle replay(k, seed) 从检查点 cₖ 重新执行步骤 k, ..., n——已记录前缀 1, ..., k−1 保持固定、其工具调用由缓存供给——并返回任务自带验证器的结果 g(k) ∈ {0, 1}。决定性失败步骤 d 是最早的检查点序号 k，使得携带原始动作的 replay(k, ·) 通过、而携带被观测或被注入腐蚀的重放失败——一个结局翻转的反事实（outcome-flipping counterfactual）——ℓ(d) ∈ {plan, tool, execution} 是其所在层。给定每条轨迹固定的重放单位预算 B（一个重放单位为一次续算 LLM 调用，每次探测——包括重复的去噪投票——都以该单位计费），研究对象是定位策略预测 (d, ℓ(d)) 的准确率随 B 的函数关系——以成本-准确率曲线报告，而非单一点估计。

**为何困难。** 由于 replay(k, ·) 要重新执行从 k 起的整段后缀，其以续算 LLM 调用计的成本随 n − k + 1 伸缩而非固定单位——因此任何"某策略节省了重放"的断言，只有在以这种位置相关单位而非原始探测次数计账时才有意义；后者会给在轨迹不同位置探测的策略错误定价。谓词 g(k) 只是*近似*的 k 的阶跃函数：正是状态继承性质——决定性失败腐蚀的状态被每个更晚检查点继承、不被任何更早检查点携带——赋予了 g(k) 近单调结构，但当某个中间步骤有非零概率从早先故障中恢复时，g(k) 可能违背该单调性，而建立在单调假设上的搜索策略可能收敛到错误序号且没有任何信号表明它已出错。g(k) 还是一次随机的 Bernoulli 读取而非确定性读取：在非零采样温度下把同一段后缀重放两次可能不一致，因此任何单次探测的答案都必须通过重复重放去噪，而去噪花掉的重复次数与搜索本身竞争同一份固定预算 B。最后，由于 d 与 ℓ(d) 的取值横跨三个步骤语义与检查点粒度各异的异质层，搜索策略对序号空间的切分——连续段还是跨层切分——必须在事先不知道决定性失败的原因与其可观测症状是否位于同一层的情况下选择。

## 方法概览（Method Overview）

在概念层面，本研究是一条由五个协作部分组成的单一测量流水线，围绕一个共享原语构建：带检查点的后缀重放谓词 g(k)，以位置相关重放单位诚实计费。二分直接利用 g(k) 的近单调结构，同时一个伴随诊断量测量该结构实际成立的频率。基于投票的去噪层把 oracle 噪声从假设变成被扫描的实验因子。分组测试搜索用冗余而非单调性假设，把定位扩展到跨层边界。而一个经重放验证、按层均衡的故障注入语料库，让每种策略——两种结构化搜索、穷举逐步扫描、均匀采样、零重放判官——在相同轨迹、相同预算下比较。

**位置相关重放单位核算**模块把每次探测（包括重复投票）以续算 LLM 调用为单位计费，而非把一次探测当作固定成本单位，并将探测次数与实测美元成本作为次级坐标轴并行记录。**二分定位器与单调性诊断**用 g(k) 对检查点序号做二分搜索，同时记录完整经验 g 剖面，从而可计算单调性违背率并将其作为"搜索捷径在何处成立"的预测因子加以检验。**基于投票的去噪**通过对显式、被扫描的重复重放次数取多数票来稳定每次探测，而非一个隐藏常量。**耐噪声、跨层分组测试**切分检查点序号空间——包括跨 plan/tool/execution 边界的切分——并用内建冗余容忍嘈杂的 oracle，这是仅靠二分做不到的。**匹配预算比较语料库与基线套件**提供经重放验证、按层均衡的地面真值，并在相同轨迹、相同预算网格上运行每种策略——这正是本文所指空白要求的共享比较。

## 方法论（Methodology）

### 位置相关重放单位核算（Position-Dependent Replay-Unit Accounting）

**挑战。** 一次重放的成本不是固定的单次探测单位，而是随需要重新执行的轨迹后缀长度伸缩，因此忽略探测落在轨迹何处的节省断言，有给其所比较的每种策略错误定价的风险。

**洞见。** 以续算 LLM 调用而非原始探测次数计费的成本度量，使"节省"成为一个关于实际花费算力的断言，并使该断言能对照探测次数与实测美元成本这两条独立核算轴检验其稳定性。

**方法。** 重放 oracle 的每次调用（包括重复的去噪投票）都被记录并按 (n − k + 1) 次续算 LLM 调用计费，其中 k 是重放起始检查点、n 是轨迹长度。这是排定成本（scheduled cost）：重新采样的后缀不必恰好用 n − k + 1 步终止，实测美元成本轴会捕捉排定开销与实际开销之间的任何偏差。某策略在一条轨迹上的总重放成本是其发出的所有探测的单位成本之和。每条轨迹并行记录探测次数与实测 API 美元成本；只有当策略排序在全部三条轴上都稳定时，才报告该排序为稳健。

### 二分定位器与单调性诊断（Bisection Localizer and the Monotonicity Diagnostic）

**挑战。** 二分的全部效率优势取决于 g(k) 是检查点序号的干净阶跃函数，但中间步骤可能从早先故障中部分恢复，无声地破坏该假设且没有内建警告。

**洞见。** 单调性假设无法解析地保证，但其违背率可以从二分本已发出的探测中直接测量，把一个无声的失效模式变成被报告的、可证伪的诊断量。

**方法。** 对检查点序号的二分搜索用后缀重放谓词 g(k) 在每轮迭代中收窄决定性步骤的候选区间，以对数于轨迹长度的探测次数收敛。每个被探测的 g(k) 值都保留在按轨迹的剖面中；单调性违背率计算为其经验剖面中存在任何 k < k′ 使 g(k) = 0 且 g(k′) = 1 的轨迹占比，该比率与二分的准确率并列报告，作为其承重预测因子。

### 基于投票的去噪（Vote-Based De-Noising）

**挑战。** 单次重放是对 g(k) 的随机读取——在非零采样温度下重放同一段后缀两次可能不一致——因此任何单次探测的通过/失败答案在没有重复的情况下都不可信，但重复本身消耗预算。

**洞见。** 把每次探测的重复重放次数当作显式的、被扫描的实验因子而非固定假设，把"oracle 是否噪声大到要紧"从隐藏常量变成被测量、可报告的量。

**方法。** 每次探测的 g(k) 读取取该检查点上 r 次重复重放的多数票，r 作为独立实验因子在 {1, 3, 5} 上扫描。单次重放翻转率（single-replay flip rate）——同一检查点两次独立重放不一致的概率——按轨迹估计，并与稳定该探测所需的投票次数并列报告。

### 耐噪声、跨层分组测试（Noise-Tolerant, Layer-Crossing Group Testing）

**挑战。** 局限于连续检查点段的搜索无法归因原因与可观测症状位于不同层的失败；而一个既嘈杂又位置相关的 oracle 读取需要超越单纯重复单点探测的去噪机制。

**洞见。** 跨检查点组的冗余——而非单个检查点的重复——是容忍嘈杂 oracle 的标准组合机制；把这些组定义在整个序号空间而非仅连续区段上，正是让搜索策略能跨层边界归因的关键。

**方法。** 步骤序号空间被切分为组（连续的或显式跨层的），每组通过一次多步介入测试（在可得时用已记录的正确动作替换该组步骤，否则重新采样），组设计中内建冗余以容忍嘈杂的 g(k) 读取；随后对被指认的组递归细化。固定噪声、变化切分的扫描与固定切分、变化噪声的扫描都从这一个设计中运行，使噪声交叉断言与跨层设计断言各自从同一底层机制得到检验。

### 匹配预算比较语料库与基线套件（Matched-Budget Comparison Corpus and Baseline Suite）

**挑战。** 现有任何基于重放的归因系统的自身评测，都不在相同轨迹、相同重放单位预算下比较结构化搜索策略、穷举扫描、均匀采样与零重放判官，因此目前不存在可供对照的准确率-重放预算刻画。

**洞见。** 只有当每种策略都对照独立于任何单一策略验证的地面真值、在相同轨迹、相同预算下运行时，刻画才有信息量——否则"节省"断言可能只是恰好比较了哪些轨迹或哪些预算的伪影。

**方法。** 遵循程序化故障注入实践，对一条成功轨迹的某一步做扰动（plan 层扰动子目标、tool 层扰动工具参数、execution 层扰动观测），将扰动后的运行向下游重放，仅当扰动运行失败且从注入步骤携带原始动作的重放成功时才保留该轨迹——得到每条轨迹经重放验证的决定性步骤序号与层标签，并在三层间均衡。随后每种定位策略——二分、分组测试、均匀随机采样、穷举逐步扫描、零重放仅读日志判官——都在同一语料库、同一重放单位预算网格上运行。

## 实验（Experiments）

### 实验设置（Experimental Setup）

**数据集。** ALFWorld（确定性家务任务模拟器）——用于试点阶段，因其完全确定性使重放可复现性在任何策略比较被信任之前先以 ≥95% 为门槛把关。GAIA 缓存网页子集（工具使用任务，网页内容快照化以实现确定性重放）——引入具有真实（尽管被缓存）工具调用变异性的 tool 层失败，这是 ALFWorld 合成模拟器所没有的，使跨层设计与"结构对均匀与判官"两类研究问题能在真正的工具使用环境而非仅家务模拟器下检验。Who&When 人工标注失败日志——自然失败评估切片，在可重执行处重新托管到重放框架中，暴露注入故障与自然失败定位准确率之间的任何差距。

**基线**（健全性检查与隔离比较项，不是要击败的竞争者——这是一项测量研究，此处没有任何研究问题被表述为"我们的流程击败基线 X"）。预算匹配的均匀随机检查点采样隔离出：优势究竟来自二分与分组测试所利用的序号结构，还是仅仅来自拥有重放访问并花掉一份预算。遵循当前故障注入语料实践的穷举逐步反事实扫描充当准确率天花板，而非要击败的对手。零重放仅读日志 LLM 判官（Who&When 的 all-at-once 与 step-by-step 两种配置）是无机制对照：若它与基于重放的准确率持平，整个重放事业就不成立。（Who&When 的第三种配置 binary search 二分的是呈给判官的日志上下文而非任何执行——同一仅读日志机制的上下文管理变体；此处报告两种经典配置。）DoVer 式假设-验证基线检验"LLM 提出假设 + 重放验证"是否匹敌预算盲的结构化搜索，但不采用 DoVer 自身报告的数字。与这些比较项分开的，是一个构造为零的安慰剂（B0b，`paper.md` 规定的运行有效性门槛而非研究问题分支），在任何假设之前先打分：标签重排安慰剂（label-shuffle placebo）把每种策略的预测对照跨轨迹置换后的地面真值序号打分，其准确率必须落在解析机会带内；假注入分支（sham-injection arm）在一个其腐蚀经验证不翻转结局的步骤上施加故障注入机制，基于重放的策略在其上必须读出"无故障"，判官的预测序号相对假注入位置必须处于机会水平——B0b 非零意味着流水线测量的是伪影，整个运行无效。

**指标。** 精确步定位准确率与 ±2 步容差下的步准确率；层准确率；以重放单位（续算 LLM 调用，位置加权）计的重放成本，探测次数与实测 API 美元成本作为次级轴；经验 g(k) 剖面的单调性违背率；以及共享预算网格上准确率对 log 预算曲线的归一化下面积（AUC）。

#### RQ1：以续算 LLM 调用为单位计费重放成本，是否会揭示结构化策略相对穷举扫描的节省取决于决定性步骤落在何处？

**注册状态。** 依 `paper.md` 第 6 步的正式注册，这是预注册的*描述性*成本核算分析（A7），不是验证性机制层假设——它与 H1–H4 并列报告，但自身不携带 PASS/FAIL 裁决；下方证伪条件陈述的是什么会使位置相关核算断言不再承重，而非一次假设检验的结局。

**设置。** 对试点与放大语料中的每条轨迹，计算每种策略的总重放单位成本（续算 LLM 调用）及其精确步准确率，然后按决定性步骤 d 落在轨迹的哪个四分位（早/中/晚）对"结构化策略成本 / 穷举扫描成本"之比分层。

**预期结果。** 重放单位成本比（结构化策略 / 穷举扫描）在晚位决定性步骤轨迹上最小——即节省最大——因为那里的后缀重放本来就最便宜；在早位决定性步骤轨迹上节省更小，但仍存在。

**证伪条件。** 若成本比在决定性步骤位置各处均匀（无四分位效应），或基于探测次数的核算会给出与重放单位核算不同的策略排序，则被驳斥——二者任一都意味着位置相关成本断言不承重，用更简单的探测次数度量本已足够。

**假设（通俗表述）。** 结构化搜索实际节省多少，取决于决定性步骤位于轨迹何处；只有反映真实重放开销的成本度量——而非原始探测次数——才能揭示这种依赖。

**指标。** 按决定性步骤位置四分位的重放单位成本比；策略排序在重放单位、探测次数、美元成本三种核算下的稳定性。

#### RQ2：二分是否以其重放单位成本的一小部分达到与穷举可比的定位准确率？

**设置。** 试点阶段：2 个骨干模型 × 2 个条件（二分、穷举扫描）× ALFWorld，60 条轨迹（每层 20 条）。放大阶段：≥4 个骨干模型 × 2 个域（ALFWorld、GAIA 缓存网页子集）× 300 条轨迹。*注册说明：*预注册判据（`paper.md` 第 6 步 H1——唯一有约束力的注册）在**合并**放大语料上打分，不限于单调剖面子集；本研究问题的早期草稿曾把判据限定在经验 g(k) 剖面单调的轨迹上，但 `paper.md` 的注册明确取代该限制，故此处弃用。二分与穷举扫描之间对精确步准确率（McNemar 检验）与重放单位成本（Wilcoxon 符号秩检验）做配对比较，α = 0.05，跨骨干模型与域做 Holm 校正。成本核算在两个分支间固定去噪投票次数——穷举扫描按与二分相同的单次探测投票数 r（依 RQ4 选定）计费——使成本比隔离的是搜索结构，而非两分支间的去噪不对称。

**预期结果。** 在合并放大语料上，二分达到穷举扫描精确步准确率的至少 90%，同时消耗其重放单位成本的至多 25%。

**聚合。** PASS 要求合并效应*且*在 4 个环境×LLM 家族层中至少 3 个出现同方向效应（二分处于所述准确率/成本下限之内），使合并 PASS 不能由单个有利层在其余层不一致时独自撑起；若整个环境层因框架复现率门槛而损失，规则预先承诺地退化为剩余 2 层中 2 层同方向，且断言的适用范围收窄到存活的环境。

**证伪条件。** 若二分需要达到或超过穷举扫描 50% 的重放单位预算才能进入其 5 个准确率点以内（在合并语料上），则被驳斥——那将意味着阶跃函数结构买到的远少于本设计所要利用的对数级节省。

**假设（通俗表述）。** 在重放信号确实接近检查点序号阶跃函数的地方，二分以穷举扫描成本的一小部分捕获其几乎全部准确率。

**指标。** 精确步准确率及 95% 置信区间（合并语料）；重放单位成本比（二分 / 穷举）。

#### RQ3：单调性违背率是否预测二分相对均匀采样的准确率优势在何处收缩？

**注册状态。** 依 `paper.md` 第 6 步的正式注册，这是 A3/F1 之下预注册的*描述性*机制分析，不是验证性机制层假设——它作为分层诊断报告，用于在 H1 失败时指导 H1 回退方案（F1）的措辞，而非独立按 PASS/FAIL 打分的断言。

**设置。** 从二分记录的 g(k) 剖面按轨迹计算单调性违背率；把轨迹分为违背与非违背两层；在每层内用配对 McNemar 比较二分相对预算匹配均匀采样的准确率优势，跨层 Holm 校正。

**预期结果。** 在单调性违背层中，二分相对均匀采样的准确率优势收缩到 5 个百分点以内；在非违背层中优势保持很大（与 RQ2 的预期差距一致）。

**证伪条件。** 若该优势在违背层与非违背层之间统计上不可区分，则被驳斥——那将意味着单调性违背率对二分捷径在何处成立不携带任何预测信息，与该诊断量的既定目的相矛盾。

**假设（通俗表述）。** 单调性违背率不只是一个被报告的统计量，而是二分有时表现不佳的特定、可检验的原因——不是无关的噪声源。

**指标。** 每层的准确率优势（二分 − 均匀）及 95% 置信区间；单调性违背率分布。

#### RQ4：每次探测需要多少次重复重放才能稳定二分的定位准确率？

**设置。** 在相同轨迹上以每次探测 r ∈ {1, 3, 5} 次重复重放、采样温度 ≈ 0.7 运行二分；用配对 Wilcoxon 符号秩检验比较各 r 下的精确步准确率；按轨迹估计单次重放翻转率。本研究问题承载 H4 的合取分支 (i)（`paper.md` 第 6 步）：H4 的 α = 0.05 在其两个合取分支间做 Holm 拆分（每分支 α = 0.025），本分支内三个成对 r 比较再做一层 Holm 校正。

**预期结果。** r = 3 将二分的准确率稳定到 r = 5 的 3 个百分点以内，表明超过 r = 3 后进一步去噪收益递减。

**证伪条件。** 若 r = 1 的准确率与 r = 5 统计上不可区分（oracle 实际上是确定性的，去噪本无必要——这是划定适用范围的结果，不是失败），或 r = 3 与 r = 5 之间差距超过 3 个点（所需投票比假设更多，使二分的有效成本超出 RQ2 的估计），则被驳斥。

**假设（通俗表述）。** 每次探测适度、固定次数的重复重放足以使二分的嘈杂 oracle 可信，且投票次数本身不会吃掉预算优势。

**指标。** 精确步准确率对 r；按轨迹的单次重放翻转率。

#### RQ5：是否存在一个 oracle 噪声水平，超过它后分组测试的单位重放准确率超过投票倍增的二分？

**设置。** 在固定的分组测试切分设计（连续切分）下，（通过采样温度）扫描单次重放翻转率，在整个扫描范围内比较分组测试与投票倍增二分（r 依 RQ4 选定）的单位重放准确率；用翻转率轴上的 95% 自助置信区间（bootstrap，1,000 次重采样）定位交叉点，并要求该区间排除"在观测翻转率范围内无交叉"。本研究问题承载 H4 的合取分支 (ii)（`paper.md` 第 6 步），按每分支 α = 0.025 打分（H4 的 α = 0.05 跨两个合取分支 Holm 拆分）。

**预期结果。** 存在一个翻转率（预期在 15% 附近），高于它时分组测试的单位重放准确率超过二分，因为在高噪声下，跨组冗余比单检查点重复投票更高效地摊销噪声容忍成本。

**p 轴支持前提条件。** 只有当观测到的按轨迹翻转率在所扫描采样温度下确实跨越 15% 阈值区域时，本合取分支才可打分。两个评估环境（ALFWorld、GAIA 缓存网页）都是专为确定性、可复现重放选择的（≥95% 复现门槛），所以这是一个现实风险而非形式条款：若语料中没有轨迹在任何扫描温度下达到阈值翻转率，本分支预先宣布为 **INCONCLUSIVE（噪声支持不足）**，而非 FAIL，并报告为"在此噪声区间未检验"，而非撤回的断言。

**证伪条件。** 若翻转率确实跨越阈值区域、但该范围内没有任何翻转率显示分组测试的单位重放准确率超过二分，则被驳斥——那将意味着投票倍增的二分在整个被检验且支持充分的噪声范围内占优，分组测试的噪声容忍断言不成立。

**假设（通俗表述）。** 超过某一噪声水平后，把冗余摊到一组检查点上，比在单个检查点上重复投票，是更高效的 oracle 噪声容忍方式。

**指标。** 两种策略的单位重放准确率对翻转率；交叉翻转率的自助置信区间。

#### RQ6：跨层分组测试切分是否特别在 plan 层决定性失败上优于连续切分？结构化相对均匀采样的优势是否在每一层都成立？

**设置。** 在固定噪声水平下，比较连续与显式跨层的分组测试切分设计在精确步与层准确率上的表现，按决定性步骤的真实层分层；每层内做配对比较，跨三层 Holm 校正（校正后每层 α = 0.017）。均衡语料构建保证 n=300 时每层约 90–100 条轨迹。本研究问题承载 **H3 的两个合取分支**（`paper.md` 第 6 步）：(i) ≥10 个点的"结构化对均匀"优势在每层成立；(ii) 跨层对连续的差距特别体现在 plan 层故障上。

**预期结果。** 跨层切分特别在 plan 层决定性失败上以至少 5 个百分点优于连续切分，在 tool 或 execution 层失败上差别很小或没有；独立地，≥10 个点的"结构化优于均匀"优势（RQ7 的合并效应）在每个层内成立。

**聚合。** 在所述每层功效（α=0.017 下约 65–70%，低于合并检验的 >80%）下，要求全部 3 层各自独立通过显著性，测量的主要是功效而非真相（即使真实效应处处成立，概率也仅约 0.65³–0.70³ ≈ 0.27–0.34）。因此 H3 第一合取分支 PASS 当且仅当 ≥10 点优势在至少 2 个功效充分的层中成立*且*没有任何功效充分的层出现统计显著的反转；功效不足的层对该层预先宣布为 INCONCLUSIVE 并从分母中剔除；若功效充分的层少于 2 个，整个第一合取分支为 INCONCLUSIVE。第二合取分支（plan 层故障上跨层对连续的差距）单独打分且不受此规则影响；H3 仅当两个合取分支都 PASS 时才 PASS。

**证伪条件。** 第二合取分支被驳斥，若跨层切分在 plan 层失败上不显优势，或在 tool 或 execution 层失败上显出相等或更大的优势——二者任一都意味着跨层设计的收益并非特定地系于"plan 层失败在下游显现"这一机制，与所述机制矛盾。第一合取分支被驳斥（而非仅 INCONCLUSIVE），仅当某个功效充分的层出现统计显著的反转（均匀优于结构化）。

**假设（通俗表述）。** 因为糟糕的 plan 决策是最可能只在后来的 tool 或 execution 步骤中显现的失败类型，只有 plan 层失败才特别受益于允许跨层边界的搜索切分。

**指标。** 每层的精确步与层准确率，连续对跨层切分。

#### RQ7：在共享预算下，两种结构化策略是否都击败预算匹配的均匀采样与零重放判官？

**设置。** 在一个共享的验证性重放单位预算——等于穷举扫描每条轨迹重放单位成本的四分之一，即 B = C_exh/4，其中长度为 n 的轨迹 C_exh = n(n+1)/2 次续算调用——下，将二分与分组测试同预算匹配的均匀采样及零重放仅读日志判官在精确步准确率上比较，每个比较用配对 McNemar，跨四个成对比较做 Holm 校正；放大语料 n = 300 条轨迹，规模设计为在 α = 0.05、约 20% 不一致率的假设下，有 >80% 的功效检出 10 个百分点的配对准确率差。

**注册修正（2026-08-15）。** 该预算点的早期措辞——"轨迹长度四分之一的重放预算"，即 B = n/4 个重放单位，配以描述性网格 B ∈ {2, ..., 64, 穷举} 个重放单位——在本文自己注册的位置相关核算下是不自洽的：在语料平均长度 n ≈ 30 时，B ≈ 8 次续算调用买不起哪怕一次轨迹中部探测（成本 n/2 + 1 ≈ 16），而二分自身的整轮期望成本（≈ (n/2)·log₂ n ≈ 75 单位，r = 1 时）超过原始网格的最大值 64——原始单位措辞悄然重新引入了 RQ1 正要揭露的探测次数错误定价。因此预算轴改用归一化单位重新表述：以穷举成本的分数计，描述性网格 B/C_exh ∈ {1/64, 1/32, 1/16, 1/8, 1/4, 1/2, 1}，验证性点为 B/C_exh = 1/4。这保留了注册的原意——n/4 次均匀放置的探测成本 ≈ (n/4)·(n/2) ≈ C_exh/4——同时消除了单位歧义；`paper.md` 第 6 步（H2）需要在任何 Phase B 运行前做出对应修正（已记录于 `pipeline.md`）。

**预期结果。** 二分与分组测试都以至少 15 个百分点超过预算匹配均匀采样的精确步准确率，且零重放判官比最佳结构化策略至少低 20 个百分点。

**聚合。** 与 RQ2/H1 相同，PASS 在合并 n=300 语料上、在唯一预注册预算 B=C_exh/4 处打分，并额外要求 4 个环境×LLM 家族层中至少 3 个出现同符号效应；完整预算网格曲线（B/C_exh ∈ {1/64, ..., 1/2, 1}）在每个网格点上描述性报告，但只有 B=C_exh/4 点是验证性的。

**证伪条件。** 若任一结构化策略未能以统计显著的差距击败预算匹配的均匀采样，则被驳斥（结构不增加任何东西）；若零重放判官的准确率与最佳结构化策略统计上不可区分，则被驳斥（重放毫无意义）。

**假设（通俗表述）。** 在共享的、现实的预算下，搜索策略利用的序号结构与拥有重放访问这一事实本身，各自都在做真实且各自必要的工作——单独任一都无法解释全部优势。

**指标。** B = C_exh/4 处每种策略的精确步准确率，成对准确率差距及 95% 置信区间。

## 相关工作（Related Work）

与本文最接近的先前工作是 AgenTracer 与 DoVer，在综述更广图景之前值得把差异说清楚：AgenTracer 已经通过反事实重放生成因果验证的失败标签，DoVer 已经从被假设的介入点重放以验证之——但二者都没有提出、也没有回答：对检查点序号做结构化搜索需要多少次重放才能达到同等准确率——而这正是本文要产出的预算受限刻画。有一项让步必须开门见山：Who&When Pro 此后已把经重放验证的故障注入扩展到 26 个基准上的 12,326 条黄金标签轨迹，因此本文构建的注入故障语料库不再是首个此规模的仪器——本文保留的语料差异、以及该估计量为何仍需要自己的语料，在下文精确陈述。

**基于重放的失败归因与标注。** AgenTracer 通过一次替换一步地重放失败轨迹并检查结局是否翻转来生成因果扎根的决定性错误标签，并在所得语料上训练专门的追踪器；DoVer 把归因当作可检验的因果假设，从 LLM 建议的介入点重放以检查结局是否恢复；Who&When 则用 LLM 判官读转录文本——有 all-at-once、step-by-step、binary search 三种配置——不重放任何东西；其 binary-search 变体二分的是呈给判官的日志上下文而非某次执行，因此它与判官家族共享同一因果盲区，而非预示本文研究的重放二分。三者共同确立了失败轨迹的决定性步骤原则上可以被识别，但 AgenTracer 的标注重放在构造上就是穷举的，DoVer 的重放只验证 LLM 提出的那个假设而不自己搜索检查点空间，Who&When 的仅读日志判官从不重新执行任何东西且——按其自身报告的结果——步级归因显著差于智能体级。没有一个刻画准确率-重放预算的权衡，这正是本文成本核算搜索策略要关闭的空白。一条密切相关但不同的工作线把单轨迹归因表述为因果介入估计问题而非搜索策略问题：Causal Agent Replay 把轨迹建模为结构因果模型（structural causal model），估计每步的因果量级（一个对比式承诺点定位，以及一个用于多步交互的预算受限 Monte-Carlo Shapley 估计器），对照带植入地面真值的合成数据验证。其"budget-bounded"限定词管的是其 Shapley 估计器的内部 Monte-Carlo 采样数，而非匹配重放单位预算下定位搜索策略的比较，因此它是相邻工作而非方法孪生：它问的是哪个估计器最好地归因一条固定轨迹的因果结构，而不是结构化搜索需要多少次重放才能首先找到决定性步骤。另有三个重放相关系统补全这条线。Who&When Pro 把注入路线扩展到仪器级——12,326 条带黄金标签的注入失败轨迹，每条都通过精确重放一条成功前缀并在边界处注入故障构建——但其验证止于前缀：没有"注入步骤上的原始动作仍能挽救结局"的往返核查（round-trip check），没有假注入对照，没有层均衡，也没有为后缀重放打包的逐步检查点——而这些恰是预算受限搜索估计量对其语料的要求；且其评测是在一个固定的、无预算维度的工作点上评测读日志的归因器。FAMAS 通过对多次完整执行做频谱分析（spectrum analysis）来归因——基于重放，但执行次数从未被计价或作为预算变化。AgentDebug 用反事实检验隔离根因步骤，并贡献了 AgentErrorBench——在 ALFWorld、GAIA、WebShop（与本文所用环境相同）上标注的失败轨迹——但没有刻画该隔离本身的成本-准确率权衡。

**面向失败轨迹的效率动机结构化搜索。** 一条快速增长的 2026 年工作线把归因成本本身当作动机：CHIEF 把扁平日志转成分层因果图，在反事实筛选前用 oracle 引导回溯剪枝候选原因；FALAT 把归因表述为依赖引导搜索，检查纠正候选步骤是否恢复预期结局；StepFinder 把判官蒸馏成轻量时序模型，正是为了避免反复昂贵的 LLM 调用；HPFA 点名穷举逐步反事实检验为其动机之敌，并通过对照成功参考路径比较超边来剪枝；MARS 用带部分展开（partial rollouts）的 Monte-Carlo 树搜索把归因与修复耦合以削减 token 开销，并发布了 StateMAS——1,310 条可重放失败轨迹。这些工作都通过结构买效率，且都只报告其自身流水线落在的单一成本工作点；没有一个在相同轨迹上、以匹配的按位置计价的重放预算比较定位策略，也没有一个测量预算受限序号搜索所要依赖的单调信号假设。MP-Bench 是笼罩这整个簇（包括本文）的构念层警示：真实多智能体失败常常容许多个站得住的归因，这正是本文的主结果数字只在经重放验证的单故障语料上有效、而自然失败切片单独报告的原因。

**生成或训练期间的步级信用分配与算力分配。** InT 通过参照扎根的自我验证定位推理展开的第一个错误步骤，并在所得"前缀+介入"对上微调；TRIM 把强模型 token 预算分配给风险信号标记为可能级联成错误的少数推理步骤；AttnRL 为每步的前向上下文影响打分，只在最有影响的步骤放置 Monte Carlo 展开；iStar 从轨迹偏好对导出稠密的按动作信用，不用任何重放。这些方法都是在生成、训练或展开构建*期间*介入——没有一个提供对已失败、已记录轨迹中决定性步骤的事后定位，也没有一个针对该诊断任务报告成本-准确率保证，而这正是本文重放框架与评测所为之构建的场景。

**固定预算查询理论与经典二分。** 固定采样预算下的最优臂识别（best-arm identification）分析对无状态臂、独立同分布奖励抽样的自适应查询分配，是"在固定次数的嘈杂查询下识别目标"的形式模板——但它不建模一列有因果顺序的检查点，其查询信号在序号上具有近似单调结构、且每次查询成本随检查点位置变化，因此其保证不能直接迁移到轨迹定位。经典 delta debugging 对一个廉价、确定性、可任意重复的测试递归地二分失败诱因输入，以近对数的测试次数隔离最小失败诱因配置——但 LLM 智能体重放违背这三条奠基假设的每一条（每次重放耗费真实模型与工具调用、采样下结局随机、环境可能漂移），因此其最小性保证不能原样带过来。本文不是把二分或分组测试当作新搜索算法提出；贡献在于刻画这些经典原语及其底层假设，在每一条假设都被真实 LLM 重放 oracle 违背之后如何表现。

## 结论（Conclusion）

本工作把反事实重放自身最稀缺的资源——轨迹必须被重新执行的次数——重新表述为一个可测量的刻画问题，而非被默认必要的成本。核心方法论赌注是：决定性失败的状态继承结构使重放信号足够接近检查点序号的阶跃函数，从而结构化搜索能够利用它；但"足够接近"必须被测量而非假设，因为恢复引起的结构违背恰恰是朴素搜索无声失效之处。无论当前 LLM 智能体与环境处于哪种主导区间，这一发现都与决策相关：若结构化重放以一小部分成本达到近穷举的准确率，经因果验证的归因就便宜到可以在每个开发循环中运行，而非只留给离线语料构建；若达不到，本设计所测量的单调性违背率就成为"何时应退回穷举重放"的实用信号。两项局限从一开始就框定该断言，它们是自然的后续步骤而非事后附注：此处的地面真值由程序化注入、经重放验证的单一故障构成，成对的自然失败切片可能揭示弥散、多因的真实失败会侵蚀本设计在构造性失败上取得的准确率；语料横跨两个沙盒化、可控重放的环境，留下的开放问题是所测成本-准确率曲线能否迁移到无法保证忠实、确定性重执行的真实工具生态或多智能体编排框架。
