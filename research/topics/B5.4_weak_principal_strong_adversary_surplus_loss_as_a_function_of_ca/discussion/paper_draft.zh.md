# 通道门控，而非能力门控：测量 LLM 议价中的剩余损失并检验"约束即保护"（Channel-Gated, Not Capability-Gated: Measuring Surplus Loss and Testing Constraint-as-Protection in LLM Bargaining）

> 由 `pipeline.md` 中六个已确认的阶段产出组装而成，且已通过研究品味审计（taste audit）（`taste_audit.md`：🟢）。状态：**规格说明 / 论文草稿——尚未运行任何实验。** 下文所有数字均为预注册（pre-registered）的设计目标，而非实验结果。（2026-08-21 依据 `review_2026-08.md` 完成审阅修订。）

## 摘要（Abstract）

大语言模型（LLM）智能体正日益代表委托人（principal）执行双边谈判，而部署较弱或较廉价模型的委托人，可能面对运行更强模型的对手方。随着能力差距（capability gap）拉大，弱智能体损失多少议价剩余（bargaining surplus）——以及是否存在近零成本的防御——尚未被测量。近期一批谈判基准已开始以对照博弈论参考解的连续剩余（continuous surplus）来为 LLM 对 LLM 议价打分 [TermsBench2605; SupplyChainBargain2608; BilateralTradeEnv2604]，但没有一个将有向的弱对强能力差距作为受控梯度加以操纵——其中规模最大的研究发现，厂商身份（provider identity）对剩余获取的预测力优于能力排名，使差距自身的因果贡献仍是悬而未决的问题——而弱对强的可扩展监督（scalable oversight）研究只以输赢结果或监督标签质量为对抗交互打分，且现有"协议层限制可保护弱委托人"的发现总是限制强势或不受信任的一方，从不限制弱方自身的表达通道。本文的核心主张（在此被检验而非被假定）是：剩余榨取受议价协议留给弱方的行动空间通道（action-space channel）所门控，而非仅由能力差距固定——因此收窄弱方自身的出站（outbound）通道，原则上可以移除强对手方优势转化为剩余的部分表面，而无需改变任一智能体的底层能力。我们构建了带可计算公平参考解的双边议价测试台（harness），以两种方式量化能力差距，测量弱智能体的归一化剩余损失（normalized surplus loss）如何随该差距缩放；随后删除弱智能体的自由文本通道，只保留经模式校验（schema-validated）的结构化报价，并通过同模型因果对比与跨层级替代比较，检验该限制是否降低剩余损失、或能否让较低能力层级追平较高层级。一个双边控制组与带策略标注（tactic-tagged）的对话记录，用于归因任何效应中经由修辞剥削与经由实质议价策略的份额。我们报告所得的缩放关系与"约束即保护"（constraint-as-protection）判定，以及两者对在未知或更强对手方面前部署较弱智能体的启示。

## 引言（Introduction）

自主 LLM 智能体正日益代表人类或组织委托人执行双边谈判——价格议价、资源分割、服务合同。为节省延迟或开销而部署高性价比、较低能力模型的委托人，无法保证谈判桌另一侧的对手方运行的是可比的模型；它很可能是一个强得多的模型。这种不对称既容易无意间产生（不同厂商选择不同层级），也容易被有意制造（老练的对手方有充分动机部署其能负担的最强谈判者），并由此提出了一个当前部署实践无法回答的问题。

然而，随着两者能力差距拉大，弱智能体向更强对手损失多少议价剩余仍未被测量，任何低于"追平能力"的手段能否防御也同样未知。相邻文献测量了这一问题的若干侧面，却没有回答它。近期一批谈判测量工作以对照可计算博弈论参考解的连续剩余为 LLM 对 LLM 议价打分 [TermsBench2605; SupplyChainBargain2608; BilateralTradeEnv2604]——但它们把模型能力当作"恰好插入哪些智能体"的附带属性，而非被操纵的有向梯度；事实上，规模最大的跨模型研究报告厂商身份对剩余获取的预测力优于能力排名 [SupplyChainBargain2608]，这使差距自身的因果贡献成为一个开放且被混淆的问题，而非已解决的问题。可扩展监督工作测量弱对强的对抗交互，但只通过监督博弈中的输赢结果、或弱模型训练强模型时监督质量的恢复程度——从不通过对照可计算参考解打分的议价分割这类连续经济结果。AI 控制（AI control）工作表明限制一方的协议层通道可以保护委托人免受不受信任对手方的侵害，但限制总是落在强势、不受信任的一侧或外围审计协议上；没有工作追问限制弱方自身的通道是否反而能保护它。结果是一个真实存在、尚无人回应的缺口：委托人目前既无法为"多大的能力差距可以容忍"设定安全运行阈值，也不知道对自家智能体强制施加一种廉价的自我限制是否有帮助。

最接近的现有工作从两个不同角度逼近这一缺口，且都无法独自封闭它。在现象侧，AI 控制协议研究 [AIControl] 确立了限制一方的表达通道可以保护委托人对抗更强或不受信任的对手方——但总是通过限制强势、不受信任的一侧或外围审计协议，从不把弱方自身的通道作为自我保护，也从不置于有剩余分割可打分的议价情境。在方法侧，可扩展监督研究 [ScalingLawsOversight] 表明弱对强对抗结果随能力差距可预测地缩放，并可用循环赛对局拟合缩放律——但其测量的结果是监督胜率而非连续经济量，故其技术可干净迁移而其结论不能。在结果侧，近期谈判测量浪潮恰好提供了本文所需的连续剩余对参考解打分机制 [TermsBench2605; BilateralTradeEnv2604]——其中一个测试台甚至把有约束力的报价与自由文本消息分离，尽管只是作为评测管线——但从不把能力差距或弱方通道作为处理变量（treatment）加以操纵。在这些近邻之间，正是本文所需组合的空位：受控的能力梯度、连续的剩余损失结果，以及专门针对弱方的自我限制检验。

将这一缺口转化为可测量的问题会暴露它自身的困难。能力不是单一标量，因此两个模型间的任何"差距"都是一种投影，不同度量——通用基准分数之差，或从对局中拟合的谈判专项技能评分——可能彼此不一致，且两个同层级模型可能出于与能力差异完全无关的原因表现不同。把议价结果打分为"损失的剩余"，需要一个对 LLM 智能体足够非平凡、又简单到每个实例都有闭式公平参考解的博弈，而即便可计算，参考解本身也是若干个都站得住脚的候选之间的构念选择。限制弱智能体的行动空间既移除了它暴露于修辞剥削的面，也移除了它自身正当的自卫手段，因此限制是有益、有害还是无效，无法事先判定——这正是本文提出的、刻意反直觉的核心问题。而且即使限制被证明改变了结果，仅凭对话记录也无法判断改变来自移除修辞通道还是别的什么，因为更强的模型完全可能在同一轮里既在实质上谈得更好、又在修辞上更具说服力。

我们的方法把上述每个障碍都转化为一项具体设计选择。能力差距以两种方式量化，且每个缩放主张都被要求在两种度量下同时成立，于是两者的分歧成为关于差距自身结构的、被报告的发现，而非隐藏的建模选择。每个议价实例都对照三个可独立计算的公平参考解打分，且零能力差距的自对局（self-play）条件验证当没有差距可解释损失时，度量本身读数接近零——这一存在性检查是先前任何弱对强研究都不需要的，因为它们都不为连续剩余打分。随后以尽可能最小的方式限制弱智能体的行动空间——只删除其回合中的一个字段，即自由文本消息，只留下经模式校验的结构化报价——这正是使任何观察到的效应可归因于"通道移除"本身的原因，并通过同模型对比与"对比高一个能力层级的未受限智能体"两条路径加以检验。最后，双边控制组连同带策略标注的对话记录，把任何效应中修辞的份额与实质议价技能的份额分开。

我们在取自两个既有博弈族与一个受控估值不对称合成套件的双边多议题议价情景上评估该设计，比较 LLM 能力阶梯在弱方自由文本与结构化报价两种条件下的表现，并对照零差距自对局控制、脚本化非自适应对手、以及双边皆受限控制组。

综上，我们的贡献是：
- 将"通道门控的剩余榨取"形式化为本文核心的可证伪假设——能力差距转化为损失剩余的多少，是协议留给弱方的行动空间通道的函数，而非仅由能力差距决定——通过下述预注册对比加以检验，而非假定。
- 一个能力差距受控的议价测试台，带双重差距度量与三个可独立计算的公平参考解，含零差距存在性检查，在任何因果主张建立其上之前先验证剩余损失度量本身。
- 对弱智能体的最小化、单字段行动空间限制，通过同模型因果对比与跨层级替代比较加以检验，以分离"限制能否保护弱智能体"与"限制能否替代能力"两个问题。
- 一项通道归因分析，结合条件间斜率比较与带策略标注的对话记录，把修辞剥削与实质议价技能作为观察效应的来源分离开。

## 问题定义（Problem Definition）

**形式化设定。** 考虑有向模型对 (w, s)，其中 w 是代表委托人的弱能力智能体，s 是强能力对手。该对在议价博弈实例 g 上谈判，每个实例带有私有估值、双方各自知晓但不为对方所知的保留值 r_w 与 r_s，以及 T 轮的截止期限。在实例 g 与行动空间条件 c ∈ {structured, free} 下的每个回合 e——其中 c 仅施加于 w 的回合，双边控制组除外（施加于双方）——产生一个由达成协议标志和（若达成）实际剩余分割构成的结果。因单边设计对机制主张至关重要，此处明确说明其后果：在 c = structured 下，仅移除 w 的出站消息字段；s 的自由文本通道保持开放且其消息对 w 仍然可见，因此单边限制关闭的是弱方的**出站**表达面（其自身的泄露、纠缠与可被利用的承诺），而其对对手修辞的**入站**（inbound）暴露保持原样——双边控制组才是同时关闭两个面的条件。弱方的归一化剩余损失为 L = (u_ref − u_realized) / (u_ref − r_w)，谈崩（impasse）计为 u_realized = r_w（即 L = 1）。每个有向对的能力差距以两种方式量化：外生差距 Δ_a，即在任何议价发生前固定的公开通用能力分数之差；内生差距 Δ_b，即从循环赛自由文本对局拟合的谈判专项技能评分。研究对象是 L 在各行动空间条件下如何随 Δ（在 Δ_a 与 Δ_b 两种度量下）缩放，以及在同一对、匹配的 Δ 下 E[L | c = structured] 是否低于 E[L | c = free]。

**难点所在。** 固定博弈实例 g 并不能固定 u_ref 的唯一取值：可支配剩余的均分、给定双方保留值的纳什议价解（Nash bargaining solution）、以及 Kalai–Smorodinsky 点都是各自站得住脚的候选，它们在幅度上、在不对称实例中甚至在方向上都可能不一致——因此任何剩余损失读数的意义都取决于其对照的参考解。能力差距 Δ 同样不具备观测唯一性：Δ_a 与 Δ_b 可能对同一批模型对给出不同排序，而两个同层级模型间的功能相似性（functional similarity）可以独立于任何能力差异调制结果，因此忽略这一点的缩放主张有把"配对相似性效应"错归为能力的风险。把 c 从 free 限制到 structured 会从 w 的回合中移除整个消息字段，且由于更强的对手可以通过更好的实质对局、自由文本中的修辞策略、或同一回合中两者兼施来榨取剩余，仅凭结果无法把 L 的变化归因于其中某一个通道——关于限制**为何**有效（若有效）的主张，需要总体损失比较之外的证据。最后，限制 c 的后果无法从第一性原理判定：移除 w 的自由文本字段既移除其暴露于说服性剥削的面，也移除其自身正当的自卫手段（framing、拖延、承诺性言辞），因此只测量 L 是否下降的设计，无法排除它因错误的原因下降、或不降反升。

## 方法总览（Method Overview）

在概念层面，本研究是一条由四个协作部分构成的单一测量管线。议价实例与智能体对能力阶梯进入测试台，测试台为每个实例计算公平参考解并对照零差距空值自我验证；双重能力差距度量把每个有向对变为两个候选标量，剩余损失序列对其回归以获得缩放估计；随后对弱智能体施加最小行动空间限制，同一测试台在受限与不受限条件下重新打分，得到同模型对比与跨层级替代比较；通道归因分析结合条件间斜率比较与对手自由文本消息的策略标注记录，把任何观察到的效应在修辞与实质原因之间分摊。

**双重能力差距量化**模块为每个有向模型对指派两个候选差距标量，并要求缩放主张在两者下同时成立，把分歧作为关于差距自身结构的发现来报告，而非以行政方式裁定。**带可计算参考解的议价测试台**模块实例化具有闭式帕累托前沿（Pareto frontier）的博弈实例并计算三个公平参考点，在信任任何依赖差距的主张之前，先以零能力差距自对局条件验证剩余损失度量。**结构化报价约束**模块删除弱智能体的自由文本字段，每回合只留一个经模式校验的报价对象，并把该限制下的结果分别与同一模型不受限时、以及高一个能力层级的不受限模型作比较。**通道归因**模块把任何观察到的限制效应在修辞与实质通道之间分摊，以条件间斜率比较作为粗粒度的因果界，以策略标注记录作为更细粒度但相关性的说明。

## 方法论（Methodology）

### 双重能力差距量化（Dual Capability-Gap Quantification）

**挑战。** 能力不是单一标量，因此两个模型间的任何差距都是投影，不同投影可能在同一批模型对的幅度与排序上都不一致——而配对层面的功能相似性可以独立于任何能力差异调制结果。

**洞察。** 这一歧义无法靠挑选"正确的"差距度量来解决，但可以把它变成一个显式的、可检查的稳健性条件，而非隐藏的建模选择。

**方法。** 每个有向模型对被指派两个差距度量：外生的公开通用能力分数之差，在任何议价发生前固定；以及内生的谈判专项技能评分，从循环赛自由文本对局拟合，沿用先前弱对强监督缩放工作中按角色估计评分的技术。内生评分在一个预注册的、不相交的评分估计回合集合上拟合：用于拟合 Δ_b 的回合不进入下游任何损失回归，因此回归自变量绝不是其自身结果样本的函数。归一化剩余损失通过混合效应模型（mixed-effects model，博弈实例与模型对为随机截距）对每个差距度量独立回归；只有当两种度量符号一致时才报告缩放主张，分歧则被显式报告为差距轴依赖投影的证据。

### 带可计算参考解的议价测试台（Bargaining Harness with Computable Reference Splits）

**挑战。** 把达成的分割打分为"损失的剩余"，要求议价环境对 LLM 智能体足够非平凡、又简单到每个实例都有闭式公平参考解——而即便可计算，参考解本身也是若干候选之间的构念选择。

**洞察。** 未经其自身空值条件验证的剩余损失度量，在任何非零差距处也同样不可信；若在没有能力差距可解释时度量读出大额损失，坏掉的是博弈或参考解选择——而非现象本身。

**方法。** 议价实例取自参数化博弈族，具有已知私有估值、保留值与可计算帕累托前沿，并为每个实例计算三个公平参考点：均分、纳什议价解与 Kalai–Smorodinsky 点。零能力差距自对局回合（弱对弱与强对强）提供存在性检查：若自对局下的平均归一化剩余损失在主参考解下不接近零，则先修复测试台本身——而非能力差距假设——之后才信任任何缩放主张。

### 结构化报价约束（Structured-Offer Constraint）

**挑战。** 限制弱智能体的行动空间既移除其暴露于修辞剥削的面，也移除其自身正当的自卫手段，因此限制是保护、伤害还是无效，无法从第一性原理判定。

**洞察。** 最小化的单字段删除——恰好移除弱智能体的自由文本消息、别无其他——正是使任何观察到的效应可归因于"通道移除"本身的原因，而非某个效应来源无从判断的更复杂重设计。

**方法。** 在受限条件下，弱智能体的整个回合是一个经模式校验的对象，指明其行动与报价分配，不传输任何自然语言字段，解析失败时有次数受限的重采样；自由文本条件除多一个不受限的消息字段外完全相同。同一模型对与博弈实例在匹配的能力差距下于两种条件间比较（同模型对比），并另将某一能力层级的受限弱智能体与高一层级的不受限弱智能体在同一对手面前比较（跨层级替代比较）——不仅检验限制是否有益，还检验它能否顶替一个能力层级。由于限制是单边的，它删除的恰是弱智能体的出站表达面；因此它展现的任何保护效应都经由 w 不再能说的内容（泄露、纠缠、可被利用的承诺）起作用，而非经由屏蔽 s 仍在说的内容——入站面只在双边控制组中被关闭。

### 通道归因（Channel Attribution）

**挑战。** 更强的对手既可通过更好的实质议价、也可通过自由文本中的修辞策略榨取剩余，且这两个通道无法仅凭结果分离，因为两者可在同一回合中同时起作用。

**洞察。** 条件间比较给出效应中修辞份额的粗粒度但因果的界，而对自由文本通道独立的策略级读取给出更细粒度但相关性的说明，指明哪些具体策略承载该效应——让两种读数保持其真实的、不同的证据强度，而非合并为一个数字。

**方法。** 自由文本与结构化条件间"能力差距对剩余损失"斜率的降低量，被计算为修辞通道贡献的因果界。独立地，由 LLM 评审（LLM judge）依据固定策略分类法（锚定 anchoring、价值虚报、虚假截止期或承诺、恭维或施压）标注对手的每条自由文本消息，其中一个子集由人工双重编码以验证评审可靠性，并将策略出现率与逐回合剩余损失相关联。双边控制组（双方都被限制为结构化报价）检查结构化条件下任何残余的差距依赖损失是实质性的而非修辞性的。

## 实验（Experiments）

### 实验设置（Experimental Setup）

**数据集。** GLEE 议价博弈配置 [GLEE2410]——参数化经济博弈基准，作为主博弈族，因其参数化可对剩余规模与估值不对称做直接受控扫描，让测试台在扩大规模前先低成本构建与验证。Deal-or-No-Deal 多议题分配情景 [DealOrNoDeal1706]——具有私有单品估值的真实多议题价值函数，用于检验剩余损失缩放关系是否能推广到 GLEE 参数化配置之外的第二个独立设计的博弈族。合成三议题分饼套件（生成）——让估值不对称作为受控连续参数被扫描，独立于两个固定语料所恰好包含的不对称分布，专门用于检验差距度量分歧（若出现）是否作为受设计的扫描集中于高不对称实例，而非只在事后被观察到。

**基线**（健全性检查比较项，不是要击败的竞争者——这是一项测量研究，此处没有任何研究问题以"我们的流程胜过基线 X"为框架）。零能力差距自对局（弱对弱与强对强）是每个差距依赖主张必需的存在性检查。脚本化、非自适应的 Boulware 或线性让步对手——构造上无记忆且与能力无关——检查观察到的差距-损失趋势确实反映强对手的能力本身，而非面对任何足够顽固对手时的一般性让步强度差异。双边皆受限控制格（对手也被限制为结构化报价）分离结构化条件下任何残余效应是实质性的而非修辞性的。

**指标。** 归一化剩余损失及其在每种能力差距度量下的混合效应趋势斜率；达成率与谈崩率；实际分割的帕累托效率（到前沿的距离）；约束对比中的条件主效应与条件×差距交互；对手策略出现率及其与逐回合损失的关联。

**薄格规则。** 任何有效回合数少于 30（低于额定 n = 50 目标）的差距水平×条件×博弈族格子，被预先声明为该格不可下结论（inconclusive）：其数据被报告但排除出上述主检验，绝不计为零结果或被无声丢弃。若供给某个中心检验（RQ2 的合并斜率或 RQ3 的合并条件效应）的格子超过四分之一是薄格，则整个检验被报告为不可下结论，而非零发现。

**规模与预算（设计目标）。** 完整网格约需 15,000–18,000 个回合：RQ2 扩大阶段（36 个有向对与自对局控制 × 3 个博弈族 × 50 回合 ≈ 5,400 个自由文本回合）、其 RQ3 结构化条件镜像（≈ 5,400）、三个差距水平上的双边皆受限控制（≈ 4,500）、以及脚本对手、试点、评分估计与评审校准格（≈ 2,500）。按每个多轮回合 3k–15k token 计，token 预算量级为 50–270M，主要由强侧模型的回合主导。这些数字作为可审计的预注册目标给出——它们正是薄格规则的核对对象——而非结果。

**研究问题：**
1. RQ1——当没有能力差距可解释损失时，剩余损失度量是否读数接近零？
2. RQ2——归一化剩余损失是否随能力差距缩放，两种差距度量是否一致？
3. RQ3——在匹配的能力差距下，把弱智能体限制为结构化报价是否降低其相对自由文本的剩余损失？
4. RQ4——结构化报价限制能否让较低能力层级在同一对手面前追平较高层级？
5. RQ5——任何限制效应中有多少是修辞性的、多少是实质性的？

#### RQ1：当没有能力差距可解释损失时，剩余损失度量是否读数接近零？

**设置。** 零能力差距自对局回合（弱对弱与强对强）在所有被测博弈族上以自由文本条件运行，按主参考解（纳什议价）打分。样本量：按在 95% 置信度下将自对局平均剩余损失估计到 ±0.02 单位以内确定。

**预期结果。** 自对局下的平均归一化剩余损失接近零：主参考解下 |E[L | Δ = 0]| ≤ 0.05。

**证伪条件。** 若 |E[L | Δ = 0]| 超过 0.05 则被驳倒——这将表明产生表观损失的是测试台本身（博弈设计或参考解计算）而非能力差距，且 RQ2–RQ5 中每个依赖差距的下游主张在被信任前都需重新审视。

**假设（通俗表述）。** 当确实没有东西可供能力差距解释时，测量仪器读出近零结果——这是信任其他任何非零读数的前提。

**指标。** 自对局下归一化剩余损失的均值与 95% 置信区间，按博弈族与参考解分列。

#### RQ2：归一化剩余损失是否随能力差距缩放，两种差距度量是否一致？

**设置。** 试点阶段：跨若干层级的能力阶梯对阵固定强对手，自由文本条件，一个博弈族。扩大阶段：能力阶梯的完整循环赛（有向不等对加零差距自对局控制），覆盖全部三个博弈族。混合效应模型：剩余损失 ~ 差距 + (1 | 博弈实例) + (1 | 模型对)，差距系数的双侧 Wald 检验，α = 0.05，对外生与内生差距度量分别计算。内生度量的评分估计回合与进入该回归的测量回合不相交（见方法论），因此 Δ_b 在回归前即已固定，而非从其自身结果数据中估计。

**样本量依据。** 每格回合数按在约 80% 功效下检测标准化差距斜率效应 d ≈ 0.4 确定；若试点观察到低于该值的效应，将触发预先承诺的扩大阶段样本增补，而非零主张。

**预期结果。** 归一化剩余损失在两种度量下均随能力差距上升（Wald 检验显著为正，p < 0.05，两者同号），跨差距水平呈单调趋势（Spearman ρ > 0），且效应越过预注册的实际显著性下限：从最小到最大被测差距水平的模型隐含损失增量（斜率 × 差距范围）在每种差距度量下至少 0.10 个归一化损失单位。

**证伪条件。** 若差距系数在任一度量下不显著为正，或趋势平坦或非单调（Spearman ρ ≤ 0），则向"无缩放关系"方向驳倒；若两种差距度量给出显著异号系数，则向"差距依赖投影"方向驳倒（一个独立的、同样可报告的结局，不作为零结果处理）；统计显著但在被测差距范围上隐含变化不足 0.10 归一化损失单位的斜率，报告为"检测到但低于预注册实际显著性下限"，而非通过的缩放关系——此处仅有显著性而无幅度是不够的。

**假设（通俗表述）。** 弱智能体对更强对手的剩余损失随能力差距拉大而增长，且该增长不是所用差距度量的伪影。

**指标。** 每种度量的混合效应斜率与 95% 置信区间；损失与差距水平的 Spearman 相关；两种差距度量的符号一致性。

#### RQ3：在匹配的能力差距下，把弱智能体限制为结构化报价是否降低其相对自由文本的剩余损失？

**设置。** 对每个被测模型对与差距水平，同一对在弱方自由文本与结构化报价两种条件下谈判匹配的博弈实例。双条件混合效应析因设计估计条件主效应与条件×差距交互，两项主检验做 Holm 校正，α = 0.05。

**预期结果。** 条件主效应为负——匹配差距下结构化报价条件的归一化剩余损失低于自由文本，点估计降幅至少 0.05 个归一化损失单位——且条件×差距交互为正，表明降幅随差距拉大而增长。

**证伪条件。** 若条件主效应在 Holm 校正 α = 0.05 下不显著或非负，或点估计降幅低于 0.05 单位，则被驳倒——两者任一都意味着表达自由并未使弱智能体暴露于额外损失，限制是中性到有害而非保护性的。

**假设（通俗表述）。** 删除弱智能体的自由文本通道会降低它在同一能力差距下输给更强对手的剩余，且差距越大保护效应越大。

**关于零差距格子解读的说明。** 一项使用近乎相同的"结构化报价对自由文本"操纵、在对称能力二人组之间进行的受控人类被试研究发现，两条件间的平均成交分割在统计上无差异（见相关工作）——因此本文自身零差距自对局格子中条件主效应接近零，恰是该先前结果所预测的模式，而非反对本假设的证据。本研究问题的诊断性检验是条件×差距交互，而非 Δ ≈ 0 处的边际条件效应。

**指标。** 条件主效应系数与 95% 置信区间；条件×差距交互系数与置信区间。

#### RQ4：结构化报价限制能否让较低能力层级在同一对手面前追平较高层级？

**设置。** 对每对相邻能力层级 (t, t+1)，层级 t 的受限弱智能体与层级 t+1 的不受限弱智能体在同一对手面前比较。单侧混合效应非劣性检验（non-inferiority test，α = 0.05，跨被测相邻对做 Holm 校正）评估层级 t 受限智能体的剩余损失是否不大于层级 t+1 不受限智能体的损失**加上预注册非劣性边际 δ = 0.05 归一化损失单位**——即是否 L(t, structured) ≤ L(t+1, free) + 0.05。显式边际很重要："不大于"本身若无声明的 δ，将悄然成为被误标为非劣性检验的优效性检验。

**预期结果。** 至少一对相邻层级中，受限低层级智能体的剩余损失落在不受限高层级智能体的预注册 δ = 0.05 边际之内——限制至少顶替一个能力层级。

**证伪条件。** 若在 Holm 校正 α = 0.05 下没有任何相邻层级对满足 L(t, structured) ≤ L(t+1, free) + 0.05，则被驳倒——这意味着即便限制在同模型对比（RQ3）中具有保护性，它也无法在 0.05 单位边际内补偿真实的能力层级差距，能力仍是主导杠杆。

**假设（通俗表述）。** 限制较弱模型的行动空间，至少在某些情形下可以替代赋予它更多能力。

**指标。** 每对相邻层级的跨层级平均剩余损失差与单侧置信界。

#### RQ5：任何限制效应中有多少是修辞性的、多少是实质性的？

**设置。** 自由文本与结构化条件间混合效应差距-损失斜率的降低量，被计算为条件间斜率移除比（slope-removal ratio）。由于单边结构化条件只关闭弱智能体的出站面，而双边控制组还关闭对手的自由文本通道，free/structured/bilateral 三格组把两个修辞面分离开：free 对 structured 的斜率差为出站与纠缠成分定界，structured 对 bilateral 的差为残余的入站说服成分定界。独立地，对手自由文本消息由 LLM 评审依据固定策略分类法标注，一个子集由人工双重编码以确立评审可靠性，并以计数结果回归将策略出现率与逐回合剩余损失相关联。双边皆受限控制组对结构化条件残余损失是否为实质性提供额外检查。

**预期结果。** 斜率移除比超过二分之一（结构化条件移除自由文本差距斜率的一半以上），且对手策略出现率与逐回合剩余损失正相关（p < 0.05）。

**证伪条件。** 若斜率移除比接近零——即结构化条件的差距斜率几乎与自由文本一样陡——则被驳倒（剥削是实质性的而非修辞性的），无论自由文本条件内策略出现率是否与损失相关；这将意味着 RQ3 中发现的任何保护效应经由决策简化（decision-simplification）而非通道关闭起作用，即便 RQ3 与 RQ4 成立，也需修正限制即保护背后的机制解释。

**假设（通俗表述，探索性——非验证性主张）。** 更强对手从更宽能力差距中榨取的剩余，主要经由自由文本中的修辞策略流动，而非更好的实质报价策略。

**指标。** 带自助法（bootstrap）置信区间的斜率移除比；每份对话记录的策略出现率；损失对策略计数的回归系数。

**结果。** *[占位——实验运行后填写]*

**进一步评估。** 若时间更充裕，一个自然扩展是检验"约束即保护"在带伙伴选择的多对多市场中是否成立，而非固定双边对——此处明确划出范围之外，因为它把分析单元从一个二人组的剩余损失变为一个群体的，需要自己的可识别性设计，而非同模型与跨层级对比的直接延伸。

## 相关工作（Related Work）

与本文最近的先前工作分属三条线，任何一条都无法独自封闭缺口。在现象侧，AI 控制协议研究 [AIControl] 确立了限制一方的表达通道可以保护委托人对抗更强或不受信任的对手方——但总是通过限制强势、不受信任的一侧或外围审计协议，从不把弱方自身的通道作为自我保护，也从不置于有剩余分割可打分的议价情境。在方法侧，可扩展监督研究 [ScalingLawsOversight] 表明弱对强对抗结果经由循环赛拟合的缩放律随能力差距可预测地缩放——但其结果是监督胜率而非连续经济量，故其技术可干净迁移到本文的内生差距度量，而其自身发现不能。在被操纵变量本身上最接近的，是一项受控人类被试议价实验 [LanguageOfBargaining2023]：对比交替结构化报价条件与不受限自然语言议价，发现两条件间平均成交分割在统计上无差异，尽管自然语言条件达成更快、方差更低——与本文自身结构化报价约束近乎相同的干预，在此被让渡（concede）为本文自身零差距安慰剂的对手预测（对称能力下也应无分割层面效应），但它运行于对称能力的人类二人组，无参考解/剩余损失框架，也无对抗剥削问题，因此无法回答一旦能力差距张开、同一约束是否保护弱方。在这些近邻之间，正是本文为之构建的组合空位：受控能力梯度、连续剩余损失结果、以及专门针对弱方的自我限制检验。

**弱对强能力差距测量。** 可扩展监督工作 [ScalingLawsOversight] 把不匹配的对抗交互建模为二人博弈，拟合联结通用能力与角色专项结果评分的缩放律；弱到强泛化（weak-to-strong generalization）工作 [WeakToStrong] 在微调管线中把能力差距作为受控变量操纵，并引入差距恢复程度的度量。另有评审-模型功能相似性工作 [GreatModelsThinkAlike] 表明弱到强的结果被模型对的相似程度调制，独立于两者间任何能力差异。三者共同确立了依赖能力差距的结果是真实、可测且可能被配对相似性混淆的——但没有一个为议价剩余这类连续经济结果对照可计算参考解打分，也没有一个置于对抗性议价交互中；议价侧的补集——无受操纵差距的连续剩余——即接下来讨论的测量浪潮。

**连续剩余谈判测量。** 近期一批基准提供了本文所依托的结果机制，却不带本文所需的处理轴。TERMS-Bench [TermsBench2605] 让环境本身充当验证器（verifier）：贝叶斯谈判博弈中对手方的私有状态对智能体隐藏、对评测器可见，产出覆盖十三个 LLM 智能体的连续最优性差距与剩余诊断。一项供应链议价研究 [SupplyChainBargain2608] 将九个 LLM 对照经验证的完美贝叶斯均衡（Perfect Bayesian Equilibrium）在 9,840 场 LLM 对 LLM 谈判中做基准测试，发现虽然能力决定价值创造与合同可靠性，但厂商身份对谁获取剩余的预测力优于能力排名——这是并行工作（concurrent work），也是"差距的因果贡献需要一个操纵它的设计"这一点最强的单一理由：本文的双重差距度量与配对层面随机效应，正是为把差距从配对身份中分离而设——该研究报告了这一混淆却无法解决它。一个双边贸易训练环境 [BilateralTradeEnv2604] 对五个前沿模型运行 15,000 场谈判的循环赛并以剩余份额为结果，其测试台甚至把有约束力的报价与自然语言消息分离——但只作为评测管线，从不作为被操纵的处理变量，且它只观察到较弱模型仅在宽 ZOPA（可成交区间）实例上存活，而未拟合任何损失对差距的关系。三者都没有操纵有向能力梯度、没有在零差距处验证其剩余度量、也没有检验对弱方通道的限制；三者都留下了本文的估计对象（estimand），同时提供了其打分机制。

**协议层限制即保护。** AI 控制协议工作 [AIControl] 在"最有能力的一方是对抗性的"假设下评估安全规程，表明限制该方通道——或外围监视与审计协议——可以防止灾难性结果；相关工作 [ControlTax] 以资源计价此类保护性限制的开销。两者都确立了协议层限制可以保护较弱或受信任的委托人，但限制总是落在强势、不受信任的一侧；两者都没有追问限制弱方自身通道是否提供可比的保护，也都不为连续剩余分割而非灾难概率打分。在被防御方本身上最接近的，是 EQ-Negotiator [EQNegotiator2511]：通过**添加**策略脚手架——带 HMM 追踪情绪人格的博弈论推理层——在对抗性催收谈判中保护小模型，表明无需更多原始能力也能防御弱智能体；它是本文减法式问题（删除一个通道，而非外挂一套推理系统）的加法式补集，且既不把能力差距作为处理变量变化，也不对照可计算参考解为剩余打分。

**策略性沟通与自由形式行动空间。** 策略性说服的形式化处理 [StrategicPersuasion] 把沟通转化为带显式效用的发送者-接收者博弈，为发送者仅凭语言能移动固定接收者行动的程度打分——恰好操作化了结构化报价约束将删除的修辞通道，但只针对固定接收者，从不改变接收者相对发送者的能力、也不检验接收者侧的结构性防御。情绪表达策略的进化搜索 [EvoEmo2509] 以实证方式强化了同一论点：优化后的修辞与情绪施压在多轮价格谈判中从对手 LLM 处榨取可测得更高的收益——修辞通道能够变现的直接证据，尽管未归因**能力差距的**效应中有多少经由该通道流动，而后者正是 RQ5 的估计对象。另有谈判语言智能体训练工作 [ARIA] 把指数级的自由形式行动空间当作训练期信用分配问题来压缩以提高样本效率，而非部署期的剥削面，且从不在已具备能力的一对之间在对抗压力下比较受限与自由形式行动空间。来自另一剥削面的证据强化了"智能体自身的交互通道——而不仅是其原始能力——才是对手所剥削之物"的可信性：网页智能体被证明会被界面层暗模式（dark patterns）系统性操纵 [Decepticon2512]，另一基准测量说服性语言使网页智能体偏离既定任务的频率 [TRAP2512]；两者都是领域特定（网页导航而非议价）且结果特定（任务重定向而非剩余分割）的，但都在未检验的情况下支持本文结构化报价约束所要直接检验的同一"通道可剥削性"前提。通道归因分析所用的四标签对手策略分类法，扎根于既有谈判策略清单与同一文献中对抗性对话行为的形式词汇 [BEDA2512]，而非临时发明，并在冻结用于规模化之前经人工评审试点与混淆检查。

**LLM 智能体经济交互与谈判对话基础。** 持续多智能体竞争框架 [CompeteAI] 研究资源受限市场中 LLM 智能体的累积优势与策略适应，但智能体能力大体同质且无闭式参考解，故无法把每次交互的剩余损失归因于能力驱动的剥削。经典多议题谈判对话任务 [DealOrNoDeal1706] 与参数化议价博弈配置套件 [GLEE2410] 各自提供了本文测试台直接借用的真实博弈族与价值函数设计，但都没有把能力差距作为受控自变量操纵、也没有把行动空间限制作为保护性干预检验——它们评估的是恰好被插入的模型、在其恰好具有的能力水平上。在关系结构上最接近的，是一条并行工作线 [PrincipalLoyalty2606]：研究几乎相同的三角色设定——委托人、代表它的智能体、对抗性对手方——并测量对话压力下的忠诚失败（信息泄露、屈从让步）；它与本文共享核心的委托人/智能体/对手框架，但没有能力差距轴、也没有经济参考解，因此无法回答每单位能力差距损失多少剩余、或限制智能体自身通道是有益还是有害。

## 结论（Conclusion）

本工作把一个部署假设——弱委托人的谈判智能体只能任凭它恰好面对的能力差距摆布——重构为一个可测量且部分可应对的问题。核心方法论赌注是：能力不对称下的剩余损失并非仅由差距固定，而是被议价协议留给弱方的行动空间通道门控；且只有当剩余损失度量在零差距处得到验证、差距本身在两种独立度量下核查、限制的任何保护效应同时经同模型对比与跨层级替代检验而非单一比较断言时，这一通道门控主张才可信。无论"约束即保护"的检验以何种方式落定，发现都具有决策相关性：若限制保护弱智能体且能顶替一个能力层级，那是今天即可用的近零成本部署缓解；若不能，则能力本身仍是唯一杠杆，委托人需要的答案不是"限制弱方的消息"。两项局限从一开始就框定该主张，且是自然的后续步骤而非事后补记：设计的适用范围是可沙箱化、有可计算估值的两方议价，把带伙伴选择的多对多市场与不可沙箱化的真实部署留给后续工作；双重差距度量核查（RQ2）本身也可能在高不对称情景中揭示两种能力投影间的真实分歧，本设计将其作为关于差距自身结构的发现来报告，而非钦定一种度量为权威——指向一个更丰富的多维能力构念作为下一个方法论目标。
