# 停止的遗憾：在测试时推理中用重建的 oracle 度量在线停止规则

## 摘要

测试时推理（test-time reasoning）让语言模型用额外的推理算力换取更好答案的机会，但它的每一次部署都隐藏着一个未解决的问题：生成应当在何时停止？我们指出，现有的停止规则——基于置信度的提前退出（early exit）、基于验证器的裁剪、自洽度（self-consistency）一致性阈值——只用最终准确率和 token 节省量来验证，从不度量它们距离"能看见轨迹自身未来的规则"所能达到的水平还差多远。我们把这个不可观测的未来变成可度量的量：在可机械验证的推理任务上，我们在推理转折检查点（checkpoint）处对每条轨迹进行探针（probe）采样，用验证器为每个探针打标签，并在一条扫过的准确率–算力汇率（exchange rate）网格上重建每个实例的 oracle 停止点，且在信任该重建之前先证明其自身的精度。随后度量每条停止规则的*遗憾*（regret）——它相对该 oracle 所放弃的"准确率减算力"效用——并将其分解为过早停止与过晚停止两部分，跟踪其随任务难度与汇率的变化。一个读取运行中信号历史的学习型估计器以同样的方式被评估：既与单信号启发式规则比较，也与一个容量匹配的对照比较，后者用于把真正的轨迹中段价值与解码前难度预测区分开。我们报告当今停止规则实际付出的遗憾有多大、遗憾集中在哪里，以及是否存在任何规则的排序足够稳定，可以独立于部署者自身的汇率给出推荐。

## 引言

测试时推理让语言模型用额外的推理算力换取更好答案的机会，而这一交换如今已是常规的部署选择而非研究珍玩：思维链（chain-of-thought）推理、自洽采样、以及重反思的解码方式都允许系统在预算许可的范围内持续生成。由此引出的实际问题不是更多推理是否平均而言有帮助，而是对给定实例来说，它何时不再有帮助——每个在测试时推理的系统都必须用某条规则回答这个问题，无论这条规则是固定 token 预算、置信度阈值，还是跨样本的一致性检查。

然而，没有任何现行停止规则被拿来与其自身轨迹的未来所能告知的信息相比较。原因在于一个每次测试时推理部署都在忽略的结构性不对称：**效用最优的停止时刻是轨迹未观测未来的泛函（functional），而每个可部署的停止信号只能读取过去。** 一条依置信度阈值退出、或依重采样答案一致性退出的规则，今天的验证方式是报告它达到的准确率与 token 成本——从不报告这个结果距离"事后知道继续在何时不再值得其成本"的部署者所能达到的最优还有多远。这不是一个表面上的疏漏：单一的报告工作点无法区分一条近乎最优的规则与一条把大部分可达空间留在桌上的规则；而哪条规则看起来更好，会随部署者自身的准确率–算力汇率彻底翻转——算力充裕的实验室和按量计费的 API 用户拿到同一张准确率/token 节省表，可以合理地对采用哪条规则产生分歧，而表中没有任何信息能告诉他们这种分歧是意料之中，还是某个不具代表性比较的伪影。

最接近的现有工作从相邻但不同的角度逼近这个缺口，其中最近的两个是 DEER [DEER2607] 与 TrimR [TrimR2607]：二者都是免训练、基于检查点的退出规则——DEER [DEER2607] 在检测到的推理转折点处依单轨迹置信度阈值退出，TrimR [TrimR2607] 在相邻片段的答案趋于稳定时退出——并且二者直接启发了本文仪器所复用的检查点架构，但它们都从未被拿来与重建的 oracle 对照打分，因此都无法说明其规则实际收回了可达准确率–算力前沿的多大部分。CaTS [CaTS2607] 最接近点出底层问题：其自身动机部分承认一致性阈值判据"不是正确性的直接估计，且未必能跨任务与跨模型干净地迁移"，但它的回应是把一致性蒸馏成一个训练出的置信度头，而不是量化到 oracle 的剩余差距。Best-of-Infinity [BestOfInfinity2607] 刻画的是一个相关但不同的量——为多数投票抽取更多并行样本的价值——其自身的参照点（无穷样本投票）本身也可能是错的，而非一个逐实例、顺序轨迹的 oracle。Adaptive Thinking [AdaptiveThinking2607] 则提出了一个本文必须直接面对的真实对抗解释：它从解码前的隐藏状态预测查询的期望自洽度，在任何 token 生成之前就分配算力，这引出一种可能——轨迹中段规则看似增加的价值，其实只是对一个解码前就已可得的难度估计的隐式重推导。更年轻的一族学习型退出预测器——Thought Calibration [ThoughtCalib2505] 通过探测模型隐藏表征判断思考何时可以终止，TERMINATOR [TERMINATOR2603] 从最终答案首次出现的位置学习逐实例退出点——与本文共享"正确的停止点是逐实例、可预测的"这一前提，但它们的验证方式与 DEER、TrimR 完全相同：以达到的准确率与 token 数为准，从不度量与可达前沿的距离。

把这个缺口变成可度量的量，会浮现四个不同的障碍。oracle 停止点是轨迹未观测未来的泛函，因此任何对它的离线重建——由有限个探针构建——都携带自身的估计噪声，必须先度量该噪声，规则的遗憾才可信地不只是仪器噪声。规则在检查点可用的每个在线信号都是正确性的代理（proxy），且已知会在关键之处与正确性脱钩——在其他模型类别中，置信度类信号被记录为随训练持续上升而与正确性无关 [Chen2023Close]——因此单一的聚合遗憾数字无法区分"处处轻微失准"的信号与"在某个特定、集中的区域自信地出错"的信号。继续推理的边际效用（marginal utility）符号并不固定——继续可能造成实际伤害，通过无益的过度推理把正确答案翻成错误答案，这一失败模式已被独立追溯到一个因果性的内部偏置机制 [FirstImpression2607]，并在预算层面被记录为过度思考（overthinking）：延长的推理会放弃先前已正确的答案 [MoreThinkingHurts2604]——因此在任何单一信号上的固定阈值都不可能跨任务、跨难度、跨轨迹位置最优。最后，准确率–算力汇率是评估者的自由参数，不是现象本身的属性，因此在一个汇率下算出的规则排序，本身说明不了这个排序在另一个同样站得住脚的汇率选择下是否成立。

我们的方法把每个障碍变成一件角色具体、可证伪的仪器，而不是一条单体流水线。检查点探针仪器离线重建 oracle 停止点，并通过比较由同一批探针的两个不相交半集重建出的 oracle 来证明自身的重建噪声，使每个下游遗憾数字在被归因于规则之前都能先检查其中有多少是仪器噪声。随后同一份记录数据被回放（replay）通过每条候选停止规则，把它们的遗憾分解为过早停止与过晚停止的质量，精确定位每个在线信号在哪里失去对正确性的把握，而不是报告一个混淆所有失败模式的数字。一个学习型估计器读取运行中的信号历史——而非单个检查点的快照——以跟踪一个可在轨迹内变号的边际效用，应对固定阈值无法应对的非平稳性。汇率本身在网格上扫过而非固定于一点，把"这个排序稳定吗"从假设变成被测得的秩一致性统计量。并且由于实际轨迹行为可以在两个方向上偏离解码前的难度估计——被预测为难的实例可能很快解决，被预测为易的实例可能滑入无益的持续生成——一个容量匹配、仅用解码前信息的对照隔离出轨迹中段信号是否做了任何一个便宜得多的静态预测器做不到的工作。

我们在答案可被机械验证的任务上评估该设计——小学与竞赛数学、多选科学问答、可执行代码——跨多个模型家族，将在完全相同的记录轨迹上回放的停止规则与重建的 oracle、固定预算对照、以及上述仅解码前的对抗解释对照进行比较。

总结起来，我们的贡献是：
- 一件检查点探针仪器：从可机械验证轨迹自身的未来离线重建逐实例的 oracle 停止点，并附带一个认证程序（对半重建，split-half reconstruction），在任何遗憾断言被信任之前先度量仪器自身的噪声底（noise floor）。
- 一种遗憾分解方法：把过早停止与过晚停止的质量分开，精确定位每个在线停止信号在哪里与验证器核对的正确性脱钩，而不是报告单一混淆的遗憾数字。
- 一个学习型边际效用估计器：从运行中的信号历史跟踪非平稳、可变号的继续价值，与单信号启发式规则比较，也与一个容量匹配、仅解码前的对照比较，后者把真正的轨迹中段价值与解码前难度预测隔离开。
- 一次汇率扫描：把规则排序稳定性从假设变成被测得的量，报告关于"哪条停止规则最好"的任何推荐是否可以独立于部署者自身的准确率–算力权衡给出。

## 问题定义

**形式化设定。** 考虑可机械验证任务的实例 x，验证器 v(·) ∈ {0,1}。x 的一条推理轨迹被切分为检查点 k = 1, ..., K。在每个检查点，可得探针估计的准确率 â_k ∈ [0,1] 与累计 token 成本 c_k。给定准确率–算力汇率 λ（每单位成本的准确率点数），定义在检查点 k 停止的效用为 U_λ(k) = â_k − λ·c_k。oracle 停止检查点为 t*(x, λ) = argmax_k U_λ(k)——一个能看到整条轨迹未来的决策者会选择的检查点。停止规则 r 只观测其所选检查点或之前可用的信号，停在 t_r(x)；其遗憾为 R_λ(r, x) = U_λ(t*) − U_λ(t_r) ≥ 0，以跨实例均值报告，并归一化为"oracle 与从不提前停止之间差距"的比例。研究对象是 R_λ(r, x) 在实例上的分布、它对任务难度与 λ 的依赖，以及——关键地——它在被归因于规则之前是否超过了重建自身的噪声底。

**为何困难。** oracle t*(x, λ) 定义在轨迹的反事实未来之上，因此任何由有限探针对它的重建都携带自身的估计噪声；一个与该噪声无法区分的遗憾值不构成规则失败的证据。规则在检查点 k 可用的每个信号——置信度、熵、重采样探针间的一致性——都是验证器核对正确性的代理，且已知以特定、非均匀的方式与之脱钩，因此只报告平均遗憾会把"处处无信息"与"有信息但在一个集中、可识别的区域出错"混为一谈。效用 U_λ(k) 在 k 上不单调：因为无益的继续可以把正确答案翻成错误答案，边际效用 U_λ(k+1) − U_λ(k) 可为负，所以任何单一信号上的固定阈值都无法保证跨检查点、任务与难度最优。最后，λ 是评估者的自由参数而非 x 或其轨迹的属性，因此"规则 A 的遗憾低于规则 B"这类断言隐含地以其测量时的 λ 为条件，该条件必须被检验而非假设掉，此后该断言才能被当作一般性推荐。

## 方法概览

概念上，本研究是一条由五个协作部件构成的测量流水线，全部作用于同一批已记录、按检查点切分的轨迹。检查点探针仪器把原本不可观测的未来变成一个经认证的、可计算的参照；分解程序把同一批记录数据（回放通过每条候选规则）变成一份定位化的遗憾账目而非单一聚合数字；学习型估计器把非平稳、可变号的边际效用信号变成可跟踪的预测；汇率扫描把排序稳定性从假设变成被测得的统计量；容量匹配对照把"轨迹中段信号有用"从断言变成对最强替代解释的检验。

**检查点探针仪器**在推理转折标记处切分每条轨迹，在每个检查点分支出反事实探针、用验证器打标签，并在 λ 网格上重建 oracle t*(x, λ)——同时由不相交探针子集的对半重建认证任何下游遗憾数字中有多少是仪器自身的噪声。**分解式遗憾归因**在完全相同的记录轨迹上回放每条候选停止规则，计算每条规则的遗憾并按 (t_r − t*) 的符号将其拆分为过早停止与过晚停止的质量，同时分别度量每个信号在每个检查点对正确性的判别力。**学习型历史估计器**从运行中的信号历史——而非单个检查点的快照——预测带符号的继续增益，并在预测增益非正时停止。**汇率扫描**在若干 λ 网格点上重算每条规则的遗憾与排序，度量相邻取值间的秩一致性，并跟踪过早/过晚停止的拆分随 λ 的移动。**解码前对照**训练一个容量匹配、仅限生成开始前可得特征的预测器，在匹配 token 开销下与完整的历史估计器比较——隔离出轨迹中段信号是否做了静态解码前难度估计做不到的工作。

## 方法论

### 检查点探针仪器

**挑战。** oracle 停止点是轨迹未观测未来的泛函，无法从任何在线信号直接读出——并且任何由有限探针对它的重建都携带自身的采样噪声，必须被度量而非假设掉，下游的遗憾断言才有意义。

**洞见。** 不可观测是关于决策时刻的事实，不是关于离线记录的事实：一旦轨迹的未来被事后探测并由验证器打了标签，oracle 就成了一个普通的、可核对的统计量——而重建它的同一探测程序也能认证自身的精度：比较由同一批探针的两个不相交半集重建出的 oracle。

**方法。** 每条轨迹在推理转折检查点 k = 1, ..., K 处切分。在每个检查点分支出 N 个反事实探针得到试答案并由验证器打标签，得到 â_k 与累计成本 c_k。对对数间隔网格上的每个 λ，直接从这些记录值计算 oracle t*(x, λ) = argmax_k U_λ(k)。用同一批 N 个探针的两个不相交半集在每个检查点独立重建 t*，得到对半噪声底：两个半重建之间的分歧界定了任何规则测得的遗憾中有多少可能来自仪器本身而非规则。

### 分解式遗憾归因

**挑战。** 单一聚合遗憾数字无法区分"均匀地弱信息"的在线信号与"除一个特定集中失败区域外处处高信息"的信号——而只有后者对理解或修复一条规则是可行动的。

**洞见。** 在完全相同的记录轨迹上回放每条候选规则，把除规则本身外的一切都保持不变，这正是能把结果差异归因于规则而非运行间偶然变化的原因——而按 (t_r − t*) 的符号拆分遗憾，把"这条规则何时失败"变成一个定位化、量化的答案，而非聚合的症状。

**方法。** 规则库中的每条候选规则（固定预算、置信度阈值、熵阈值、自洽投票份额阈值、答案稳定性）在同一批记录检查点上回放，确定其停止索引 t_r(x) 与相应遗憾 R_λ(r, x)。遗憾被划分为过早停止质量（t_r < t* 的实例）与过晚停止质量（t_r > t*）。每个信号在每个检查点对验证器核对正确性的判别力另行以 AUROC（对照该检查点自身的验证器标签）度量。

### 学习型历史估计器

**挑战。** 因为继续推理的边际效用可在单条轨迹内变号——继续有时有益，有时造成实际伤害——作用在单个检查点信号值上的固定阈值无法跟踪它；估计器需要看到信号在如何移动，而不只是它当前处在哪里。

**洞见。** 以信号历史的趋势（而非瞬时值）为条件的预测器，可以表示一个有方向、可变号的量，这是单一全局阈值在结构上做不到的。

**方法。** 在每个检查点，一个轻量预测器（逻辑回归或浅层 MLP）把运行中的信号历史——当前与近期的置信度、熵、投票份额读数、它们的短窗差分、以及累计成本——映射为预测的带符号继续增益。诱导出的规则在预测增益非正时停止。估计器在记录轨迹的一个划分上训练，并在留一基准（leave-one-benchmark-out）与留一模型（leave-one-model-out）划分下评估，检验其学到的映射是迁移的，而非记住了特定基准或骨干模型。

### 汇率扫描与排序稳定性

**挑战。** 准确率–算力汇率 λ 是评估者选择的自由参数，不是任务或轨迹的属性——所以在一个 λ 值下算出的规则排序，本身说明不了另一个同样站得住脚的 λ 是否会给出同样的排序。

**洞见。** 跨 λ 的排序稳定性是一个关于遗憾曲面作为 λ 的函数形状的独立经验问题，只能通过实际扫描 λ 并度量秩一致性来回答——不能通过审视单一（无论测得多精确的）切片来回答。

**方法。** 在若干对数间隔的 λ 网格点上重算每条规则的遗憾与相应排序。在相邻网格点的规则排序之间计算 Kendall's τ，并把可归于过晚停止的遗憾份额作为 λ 的函数跟踪，检验主导失败模式是否随 λ 从低到高由过早停止移向过度思考。

### 解码前对照

**挑战。** 任务难度与轨迹中段信号内容天然相关——更难的实例也倾向于产生更嘈杂的中段读数——因此规则价值与实例难度的朴素相关，无法说明该规则做了任何"解码开始前就能算出的难度估计"做不到的事。

**洞见。** 解码前难度是生成开始前固定的静态逐实例估计，但实际轨迹行为可在两个方向上偏离它——被预测为难的实例可能很快解决，被预测为易的实例可能滑入无益的持续生成——只有读取实际展开轨迹的信号才能捕捉这种偏离；容量匹配对照正是把这一点从假设变成可证伪比较的工具。

**方法。** 一个与学习型历史估计器容量相同、但仅限解码前与首检查点特征的预测器，以相同方式训练，并在匹配平均 token 开销下与完整的历史估计器比较。该比较隔离出完整估计器的轨迹中段信号是否贡献了最佳静态解码前预测器已捕获之外的价值。

## 实验

### 实验设置

**数据集。** GSM8K（测试集，精确匹配数值验证器）——规模大、判分无歧义、试点仪器最便宜的领域。MATH-500（表达式等价验证器）——更难的多步数学；检验超出算术级难度的泛化。AIME 2024 + 2025（整数答案验证器，合计约 60 题）——竞赛难度；仅作描述性报告并排除在假设检验之外，以避免在小样本上抬高假发现风险，用于在难度极端尾部核对难度–遗憾关系。GPQA-Diamond（多选验证器）——检验向不同验证器类型与不同推理形态的泛化。LiveCodeBench（单元测试执行验证器；仅第二阶段扩大规模）——检验向一个推理转折检查点结构上不同于散文式数学/问答轨迹的领域的泛化。

**语料质量与污染控制。** 由于发布的检查点级轨迹语料本身是本研究的次级贡献，其构建受显式质量门控约束而非假设其可靠：对每个基准人工审计 50 个验证器判决以核查机械判分器自身的错误率，任何基准若判分错误超过 2%，须先修复判分器，其试点结果方可被信任。每个基准已知的训练/预训练重叠状况（凡有公开记录者）随发布语料一并报告，任何有已披露污染风险的基准在语料元数据中被标记，而非与无污染基准在聚合统计中静默混合。

**探针预算与仪器成本。** 仪器的预注册探针预算为每检查点 N = 8 个验证器打标探针——在支撑 RQ2 噪声底的两个半重建之间按 4/4 拆分，N = 8 时 â_k 的二项噪声至多 ±0.17（一个标准误）——外加在 100 个实例上的 N = 32 重探，核查 N = 8 的估计本身不是约束瓶颈。轨迹约有 K ≈ 20 个转折检查点，因此探测朴素地把生成成本放大约 K × N ≈ 160 倍；两项预注册的缓解措施约束它：同一检查点分支出的探针间复用前缀 KV（prefix-KV reuse），以及一道试点门控——要求 N = 4 的投票份额与 N = 8 的相关性高于 0.95，扩大规模阶段才承诺更大的预算。探针 token 属于仪器开销，不计入策略成本 c_k。在这些缓解下，试点（200 条轨迹，约 3.2 万个短探针）的预算约为 10–25 个 A100 GPU 小时。

**基线**（健全性检查与对抗解释比较项，不是要击败的竞争者——这是一项测量研究，没有任何研究问题被表述为"我们的程序击败基线 X"）。固定预算停止（在留出的开发集上选出的每基准最佳固定检查点索引或 token 预算）是必要的"自适应到底值不值"对照。oracle t* 是每条规则被对照度量的上界，构造上遗憾为零。仅前缀分配器——一个容量匹配、仅用解码前与首检查点特征的预测器，以与完整历史估计器相同的方式训练，并在匹配平均 token 开销下评估——排除一个特定的对抗解释：轨迹中段信号测得的任何收益，其实是对解码开始前已可得难度估计的隐式重推导。

**指标。** 每规则每 λ 的平均遗憾 R_λ(r) 与归一化遗憾 NR_λ(r)；每检查点信号对验证器标签的 AUROC；过早/过晚停止的遗憾份额；相邻 λ 值间规则排序的 Kendall's τ；对半 oracle 重建噪声底。

**研究问题：**
1. RQ1 —— 重建的 oracle 是否非平凡（它是否真的会建议在轨迹结束之前停止）？
2. RQ2 —— 相对其自身噪声底，oracle 重建是否足够精确，从而许可遗憾比较？
3. RQ3 —— 校准过的单信号停止规则是否付出既统计上真实、又大于仪器噪声底的遗憾？
4. RQ4 —— 有没有在线信号能可靠地、高于随机水平地判别验证器核对的正确性？
5. RQ5 —— 自洽度信号在平均遗憾上是否支配置信度与熵？
6. RQ6 —— 信号历史的学习型组合是否相对最佳单信号规则降低遗憾，且该收益能否跨基准与跨模型迁移？
7. RQ7 —— 学习型估计器到 oracle 的剩余遗憾差距是否随任务难度增长？
8. RQ8 —— 按遗憾对停止规则的排序在准确率–算力汇率上是否稳定？
9. RQ9 —— 随汇率上升，主导的遗憾失败模式是否从过早停止移向过晚停止？
10. RQ10 —— 利用轨迹中段信号是否在仅解码前难度估计已捕获的价值之外增加价值？
11. RQ11 —— 检查点离散化是否粗糙到支配其余所有 RQ 所依赖的规则间遗憾差异？

**安慰剂优先次序（B0）。** 按本研究自身的对照结构，固定预算扫描（B0）在 RQ3–RQ10 中任何一个被打分*之前*评估，而不只是与它们并列报告：预注册的正当性判据要求最佳自适应启发式在中位 λ 下、在 3 个试点基准中至少 2 个上，以至少 20% 的相对平均遗憾（Holm 校正 p < 0.05）击败开发集选出的最佳固定预算。若 B0 未被以此幅度击败，则自适应本身在这些任务上尚未被证明有任何价值，论文的框架回退到全局转向（见结论），而不是把 RQ3–RQ10 当作自适应已成立那样继续打分。

#### RQ1：重建的 oracle 是否非平凡？

**设置。** 在中等汇率（λ 网格中点）下，计算试点实例（GSM8K、MATH-500、GPQA-Diamond；单一骨干模型）中 t*(x, λ) 严格早于轨迹最终检查点 K 的比例。

**预期结果。** 在中位 λ 下，oracle 在至少 20% 的实例上建议在轨迹结束前停止。

**证伪条件。** 若 oracle 在超过 80% 的实例上建议持续到最终检查点，则被驳倒——此时 oracle 退化，整个遗憾框架在这些任务和该模型上无物可测。

**假设（通俗表述）。** 停止决策在这些任务上具有经济意义：对相当份额的实例，可达前沿确实位于轨迹结束之前，而不只在其末端。

**指标。** 中位 λ 下 t* < K 的实例比例。

#### RQ2：oracle 重建是否足够精确以许可比较？

**设置。** 用同一批每检查点探针的两个不相交半集独立重建 t*(x, λ)；将所得对半遗憾（仪器的"自遗憾"）与最佳启发式规则在中位 λ 下实测的遗憾比较。

**预期结果。** 对半噪声底不超过最佳启发式规则在中位 λ 下实测遗憾的三分之一。

**证伪条件。** 若对半噪声底等于或超过最佳启发式实测遗憾的三分之一，则被驳倒——此时仪器无法可靠地把规则的真实遗憾与 oracle 自身构建中的采样噪声区分开，要么必须增大探针数 N，要么所有下游遗憾断言都须注明为不确定。

**假设（通俗表述）。** 相对它试图测量的效应量，仪器足够精确，可以把遗憾归因于规则而非 oracle 自身构建中的采样噪声。

**指标。** 对半遗憾（噪声底）；与最佳启发式实测遗憾之比。

#### RQ3：校准过的单信号规则是否付出真实、非噪声的遗憾？

**设置。** 试点阶段：2 个骨干模型 × 2 个条件（规则开启 vs. oracle）× 三个试点基准 × 每基准约 500 个实例（测试集允许处 ≥500）。扩大规模：≥3 个模型家族 × 5 个基准。每条规则的阈值 τ 在留出的 20% 开发集上校准；所有检验在不相交的 80% 评估集上进行。对逐实例遗憾做双侧 Wilcoxon 符号秩检验，跨规则对与 λ 值做 Holm–Bonferroni 校正，α = 0.05。

**样本量依据。** 每基准 ≥500 个实例（AIME 排除在假设检验外，仅描述性报告）的规模，是为了在常规功效下、对照 RQ2 建立的对半噪声底检测一个标准化的遗憾效应；若试点观测到的效应低于该阈值，将触发预先承诺的扩大规模样本增补，而非做出零效应断言。

**预期结果。** 每条校准过的单信号规则的平均遗憾显著大于零（归一化遗憾 NR_λ ≥ 0.05），并在三个试点基准中至少两个、七个被测 λ 值中至少五个上超过 RQ2 对半噪声底的 *3 倍*——不只是可检出地高于它。

**证伪条件。** 若某条单信号规则的遗憾在多数基准与 λ 值上未能越过 RQ2 噪声底的 3 倍，则被驳倒——一旦其遗憾在该边距下无法与仪器噪声干净区分，该规则就等于被 ε-认证为 oracle 级，意味着停止问题对它在这些任务上已经解决（对接结论中的 F-G1 转向措辞）。

**假设（通俗表述）。** 当今的停止启发式把真实、可测量的余量留在桌上；它们没有一条已处于可达前沿。

**指标。** 每规则平均遗憾及 95% bootstrap 置信区间；越过噪声底的（基准, λ）单元计数。

#### RQ4：在线信号是否高于随机水平地判别正确性？

**设置。** 对每个基准，计算每个信号（置信度、熵、自洽投票份额）在每检查点对该检查点自身验证器标签的 AUROC，跨实例与检查点合并。

**预期结果。** 每个基准上至少有一个信号达到 AUROC ≥ 0.60（bootstrap 95% 置信区间下界 > 0.55）。

#### RQ5：自洽度是否支配置信度与熵？

**设置。** 在所有被测（骨干 × 基准 × λ）单元上，将自洽投票份额规则与置信度阈值、熵阈值规则逐对比较平均遗憾，Holm–Bonferroni 校正。

**证伪条件。** 若自洽度在多数单元中被置信度或熵支配，或未出现一致排序（各信号胜出份额相近），则被驳倒——任一结果都意味着"样本一致性是最可靠停止信号"这一常识直觉在 oracle 相对意义上不成立。

#### RQ7：学习型估计器到 oracle 的剩余差距是否随难度增长？

**设置。** 在每个扩大规模基准内，按基线通过率把实例分成难度十分位；在中位 λ 下计算学习型估计器在每个十分位内的归一化遗憾 NR_λ。

**预期结果。** 学习型估计器在中位 λ 下的剩余归一化遗憾在每个基准上都不低于 0.10（oracle 差距未被关闭），且 NR_λ 与难度十分位的 Spearman 相关在 5 个基准中至少 3 个上不低于 0.5。

**证伪条件。** 若剩余差距在难度十分位上持平或收缩，则被驳倒——这意味着更难的实例事实上并不更难在线估计，与本方法所依托的机制矛盾。

**假设（通俗表述）。** 即使这里测试的最佳估计器也没有关闭到 oracle 的差距，且剩余差距恰好集中在它若反映真实估计难度就应集中的地方：最难的实例。

#### RQ8：停止规则的排序在汇率上是否稳定？

**设置。** 在跨约 0.01–3 准确率点/千 token 的 7 个对数间隔 λ 网格点上重算每条规则按平均遗憾的排序；在每对相邻网格点的规则排序间计算 Kendall's τ，按模型合并。

**预期结果。** 相邻 λ 排序间的平均 Kendall's τ 不低于 0.6，且没有任何相邻对低于 0.3。

**证伪条件。** 若规则排序在 λ 网格上大幅重排（相邻值间 Kendall's τ 低或接近零），则被驳倒——此时任何"规则 X 遗憾更低"形式的、独立于 λ 的陈述都站不住脚，每个报告的比较都必须显式注明其测量时的汇率。

**假设（通俗表述）。** 尽管绝对遗憾值随汇率变化，哪条规则最好是一个相对稳健的属性，而非所报告的那一个工作点的伪影。

**指标。** 每对相邻 λ 的 Kendall's τ，附实例重采样的 bootstrap 置信区间。

#### RQ9：随汇率上升，主导失败模式是否从过早转向过晚？

**设置。** 在每个 λ 网格点，对表现最佳的启发式规则与学习型估计器，计算可归于过晚停止（t_r > t*）的遗憾份额。

**预期结果。** 过晚停止的遗憾份额随 λ 上升（网格上 Spearman ρ ≥ 0.8），从最低到最高被测 λ 至少移动 20 个百分点。

**证伪条件。** 若过早/过晚停止的构成未按预测方向随 λ 移动，则被驳倒——这意味着过度思考 vs. 思考不足的失败模式并不像效用形式化所预测的那样受汇率支配。

**假设（通俗表述）。** 当算力相对准确率便宜（低 λ）时，规则倾向于停得过早；当算力昂贵（高 λ）时，主导失败变为停得过晚——一个经济上可读的模式，而非噪声。

**指标。** 每 λ、每规则的过晚停止遗憾份额。

#### RQ10：利用轨迹中段信号是否在解码前难度预测之外增加价值？

**设置。** 训练一个容量匹配、仅限解码前与首检查点特征的预测器；在匹配平均 token 开销下，跨所有扩大规模基准与模型，将其归一化遗憾与完整的学习型历史估计器比较。

**预期结果。** 在匹配 token 开销下，完整历史估计器以至少 10% 的相对归一化遗憾降低、且统计显著地击败仅解码前对照。

**证伪条件。** 若仅解码前对照在相同 token 开销下追平或击败完整估计器，则被驳倒——这意味着自适应轨迹中段停止的价值已被解码前难度预测穷尽，轨迹中段信号在生成开始前即可知的信息之外没有增加可测量的价值。

**假设（通俗表述）。** 在轨迹展开时读取它，捕获了生成开始前无法预测的真实、可利用的偏离——"在线边际效用估计"中的"在线"部分在做真正的工作，而非重推导一个静态估计。

**指标。** 匹配 token 开销下（完整估计器 vs. 仅解码前对照）的归一化遗憾降低及 bootstrap 置信区间。

#### RQ11：检查点离散化是否支配测得的规则间遗憾差异？

**设置。** 以 2 倍更粗的检查点粒度（保留一半转折标记）重新切分每条试点轨迹，并在中位 λ 下重算每条规则的平均遗憾；将由此产生的每规则平均遗憾移动与原（更细）粒度下测得的规则间遗憾差距中位数比较。

**预期结果。** 对规则库中的每条规则，2 倍粗化检查点造成的遗憾移动小于同一 λ 下规则间遗憾差距中位数的 50%。

**证伪条件。** 若粗化检查点使任何规则的平均遗憾移动达到规则间差距的 50% 或以上，则被驳倒——此时检查点粒度而非规则自身的信号质量，才是 RQ3–RQ9 所报告遗憾差异的主导驱动因素，本文所有绝对遗憾数字都必须从 oracle 相对断言降级为仪器相对断言（仅固定粒度内的比较仍被许可）。

**假设（通俗表述）。** 检查点切分足够精细，使归因于规则自身信号质量的遗憾差异不只是轨迹恰好被切多细的伪影——这是本文其余所有 RQ 所依赖的构念效度（construct validity）前提，而非一项独立发现。

**指标。** 2 倍粗化下每规则的遗憾移动；与原粒度下规则间遗憾差距中位数之比，附 bootstrap 置信区间。

## 相关工作

最接近的两个先行工作是 DEER [DEER2607] 与 TrimR [TrimR2607]，在综述更广的图景之前值得把差异说清楚：二者都是免训练、基于检查点的退出规则，其转折检测架构被本文的检查点探针仪器直接复用——DEER [DEER2607] 在检测到的推理转折点处依单轨迹置信度阈值退出，TrimR [TrimR2607] 在相邻片段答案趋稳时退出——但它们都从未被拿来与重建的逐实例 oracle 对照打分，因此都无法报告其退出规则实际收回了可达准确率–算力前沿的多大部分。这正是本文所要关闭的可识别性缺口。

**免训练的检查点式停止。** DEER [DEER2607] 通过语篇转换与反思 token 检测推理转折点，在每处诱导一个试答案，并在置信度越过阈值时退出；TrimR [TrimR2607] 用轻量验证器外部监控进行中的思维链，在相邻片段收敛到同一答案时退出。二者确立了对已具备能力的推理模型进行免训练、检查点式干预在准确率/token 节省度量下的实用性与有效性，但都不报告相对任何 oracle 的遗憾数字，也都不认证其报告收益中有多少反映真正的自适应、多少是所评估的单一工作点的伪影——这正是本文的检查点探针仪器与汇率扫描要关闭的缺口。

**学习型退出预测器与最优停止形式化。** Thought Calibration [ThoughtCalib2505] 在推理模型的隐藏表征上训练轻量探针，判断新颖推理何时进入平台期、思考何时可以终止；TERMINATOR [TERMINATOR2603] 从模型最终答案首次出现的位置学习逐实例退出点；同期工作（concurrent work）OS-Pruner [OSPruner2607] 把思维链剪枝形式化为一个最优停止（optimal stopping）问题，其显式效用在最终答案准确率与生成长度之间权衡——正是本文 U_λ 所形式化的同一效用对象。三者都与本文共享"正确的停止点是逐实例的"这一前提，OS-Pruner 尤其共享其每成本准确率效用；但每一个都是停止*方法*，以最终准确率和 token 节省对照其他方法验证。没有一个重建逐实例 oracle、认证重建自身的噪声底、按失败方向分解任何规则的遗憾、或检验其优势在汇率变化下是否幸存——特别地，TERMINATOR 的首次出现标签是一个仅含准确率、固定在单一隐含工作点的目标，而非跨汇率扫描的目标。本文是那些方法可以在其下被打分的测量研究，不是一条与之竞争的退出规则。

**自洽与一致性式自适应采样。** CaTS [CaTS2607] 把自洽一致性统计蒸馏成一个训练出的、单次前向的置信度头，自适应地决定何时停止重采样，其自身动机明确指出一致性判据"不是正确性的直接估计，且未必能跨任务与模型干净迁移"；Best-of-Infinity [BestOfInfinity2607] 把重复采样建模为来自未知类别答案分布的抽样，推导出一个贝叶斯因子停止规则，判断当前多数答案是否已收敛到总体多数。二者都量化了测试时算力*并行*采样维度的某些方面，但都不曾把其判据与逐实例、顺序轨迹的 oracle 对照打分——CaTS [CaTS2607] 点出了代理问题却未度量其大小，Best-of-Infinity [BestOfInfinity2607] 自身的参照点（无穷样本投票）本身可能是错的，不同于本文经机械验证的 oracle。

**离线预算校准与风险控制。** SAFER [SAFER2607] 通过保形风险控制（conformal risk control）在可交换的校准集上离线校准单一全局采样预算，并带弃答选项；Conformal Thinking [ConformalThinking2602] 同样把预算设定表述为无分布风险控制，将一个"确信即停"的上阈值与一个针对大概率不可解实例的先行下阈值配对。这些与本文研究的是真正不同的问题：二者都把阈值校准到一个事先固定的目标风险水平、依赖可交换的校准集——单条轨迹内的逐步推理信号并不满足该条件——且都不曾对照重建的逐实例 oracle 度量任何规则的遗憾，也不曾追问其保证在准确率–算力汇率变化下是否幸存。本文的在线框架不被离线校准所涵盖；它处理的是离线校准无法触及的场景。

**推理长度的学习型与理论刻画。** JET [JET2607] 通过强化学习训练推理策略在推得足够信息后停止，使用一个以正确性为条件的长度奖励；CoTLength [CoTLength2607] 推导出一个误差累积模型，预测链长与准确率之间的倒 U 形关系，最优长度取决于任务难度与模型能力。JET [JET2607] 改变的是底层策略本身的行为而非为给定策略的停止行为打分，且需要对固定黑盒模型不可得的 RL 访问；CoTLength [CoTLength2607] 解释了总体层面最优长度*为何*存在，却不提供它的在线逐实例估计器，也不评估可观测信号距实现它有多远——这正是本文贡献的估计器与遗憾分解机制。When More Thinking Hurts [MoreThinkingHurts2604] 在预算层面用经验记录了同一倒 U 形——边际收益递减，且延长的推理会放弃先前已正确的答案——但与 CoTLength [CoTLength2607] 一样，止步于刻画现象，而未度量任何可部署规则距逐实例最优有多远。

**解码前算力分配。** Adaptive Thinking [AdaptiveThinking2607] 从解码前隐藏状态预测查询的期望自洽度，在任何 token 生成之前分配推理算力；Snell 等 [Snell2024] 表明跨策略的算力最优分配强烈依赖于预测的提示难度。二者都确立了自适应测试时算力的相当一部分价值可以在生成开始前捕获——这正是本文解码前对照要排除或确认的对抗解释：轨迹中段规则表面上的价值，究竟是来自展开中轨迹的真正新信息，还是对静态解码前难度估计已知内容的重推导。

## 结论

本工作把测试时停止从一个关于准确率与 token 节省的问题，重构为一个关于*相对可达前沿的遗憾*的问题，并表明回答它需要的不只是一条更好的启发式——它需要一件让前沿本身可计算、并在任何度量之前先认证自身精度的仪器。核心的方法论赌注是："这条规则近乎最优"或"这条规则把余量留在桌上"这类判定性断言，只有当其所对照的 oracle 具有明示且经核查的噪声底、且所得遗憾已按失败方向分解并对评估者自身的自由参数（汇率）做过稳定性检验之后，才值得信任。无论试点与扩大规模的数字落在哪边，发现都具有决策相关性：若当今的启发式聚在 oracle 附近，则停止问题比领域所设想的更接近解决，进一步的启发式工作期望价值低；若它们留下可观的、非噪声的遗憾——尤其是随汇率重排的遗憾——则文献中每一条已发表的"我们的停止规则更好"断言都隐含地以一个未披露的工作点为条件。两条局限从一开始就框定该断言，并且是自然的后续步骤而非事后补注：本研究限定于可机械验证的任务，把开放式生成——停止规则可能最重要、却没有自动 oracle 的场景——留给未来工作，那将需要一个机械可验证性的替代品并带来其自身的可靠性问题；重建 oracle 自身的精度受有限探针数约束，在最难的难度层可能反而成为约束瓶颈——那里信号最嘈杂、对半噪声底最大——这指向把自适应或更大的探针预算专门用于高难度实例，作为下一个方法论目标。
