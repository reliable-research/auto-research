## N2 Motivation (verbatim from proposal.motivation)

Existing inference-time reliability and control methods show that LLM internal representations contain actionable signals about correctness, hallucination risk, and reasoning sufficiency, but they typically extract those signals from full hidden-state activations. @wang2025coe uses layerwise hidden-state trajectories for output-free self-evaluation, @chen2024inside derives hallucination indicators from hidden-state covariance structure, @beigi2024internalinspector trains confidence estimators over multiple internal activations, and @zhang2025selfverification probes hidden states to verify intermediate reasoning and enable early exit. These results collectively establish that internal states are informative, but they also reveal a systems problem: storing or recomputing high-dimensional activations across layers and time steps is expensive in memory and cumbersome to integrate into standard serving stacks.

A parallel line of work argues that reasoning depth should be adapted to problem difficulty rather than fixed globally. @wang2025pats performs process-level fast/slow switching using reward-based evaluation, while @yue2025dots searches for dynamic reasoning trajectories. These methods show the value of difficulty-aware control, but they depend on additional search, reward models, or explicit trajectory planning. This creates an opportunity for a lighter control signal that can be read directly from artifacts already produced during decoding.

The central gap is that prior work has not asked whether the KV cache itself can serve as that signal source. @belitsky2025kvsteering is particularly suggestive here: if KV caches can be manipulated to alter reasoning behavior, they likely encode more than transient attention bookkeeping. This motivates a new problem definition: can we replace hidden-state-based inference-time analysis with a KV-cache-based representation that is already present during decoding, thereby preserving much of the utility of internal-state probing while removing most of its storage and deployment cost? Solving this would enable self-evaluation and adaptive reasoning control to run essentially for free inside existing inference pipelines.

## N6 Methodology (verbatim from proposal.method)

We propose to repurpose the transformer KV cache as a lightweight inference-time representation, termed KV-Embeddings. Instead of storing hidden states, we aggregate cached keys and values across heads, layers, and token positions to obtain compact task-conditioned features that can support both self-evaluation and reasoning control. This formulation directly addresses the identified gap because the KV cache is already computed and retained by standard autoregressive decoding, so downstream analysis can be added with negligible extra memory and minimal FLOPs.

1. **KV-Embedding Construction**: We construct compact representations by pooling cached key and value tensors across heads and layers, using simple concatenation and averaging operations over the existing cache. This component is needed to convert the raw cache, which is organized for attention reuse, into a stable vector representation usable by downstream scoring modules. It extends the hidden-state representation logic of @wang2025coe, @chen2024inside, and @beigi2024internalinspector, but replaces full activations with a cheaper substrate motivated by the representational role of KV cache suggested by @belitsky2025kvsteering.

2. **KV-Based Chain-of-Embedding Self-Evaluation**: We instantiate a KV-CoE variant by forming a trajectory from per-token pooled KV vectors and computing local geometric features such as step lengths and angular changes between adjacent elements. This is needed to test whether the correctness signals observed in hidden-state trajectories remain recoverable from the cache alone. The design directly adapts the Chain-of-Embedding framework of @wang2025coe while pursuing the same output-free evaluation goal under the lower-cost representation hypothesis inspired by @chen2024inside.

3. **KV Difficulty Estimator for Fast/Slow Routing**: We train a lightweight MLP on pooled KV features to predict a continuous difficulty score, using supervision derived from the relative success of fast and slow reasoning traces. This component is needed because adaptive reasoning requires a compact online decision rule rather than full trajectory search or reward-model evaluation. It operationalizes the process-level adaptation objective of @wang2025pats and the dynamic trajectory perspective of @yue2025dots, while replacing heavier controllers with a cache-derived predictor.

4. **Inference-Time Switching Mechanism**: We use the predicted difficulty score to control reasoning mode through special tokens that trigger or terminate deliberate reasoning, with both one-shot and checkpoint-based dynamic switching policies. This component is needed to translate representation-level signals into actual compute savings during decoding. It extends the early-verification logic of @zhang2025selfverification and the adaptive-switching motivation of @wang2025pats, but avoids hidden-state probes and external search by reading directly from the evolving KV cache.

Together, these components form a coherent system: the same pooled KV representation supports both analysis and control, and both applications exploit the fact that local task-conditioned separability is sufficient even if KV cache is not a strong general-purpose embedding. The result is a deployment-friendly pipeline for self-evaluation and adaptive reasoning that reuses an inference artifact the model already maintains.
