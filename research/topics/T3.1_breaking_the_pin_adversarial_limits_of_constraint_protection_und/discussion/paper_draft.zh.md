# 每次都要活下来，破一次就够：测量上下文压缩下记忆钉扎的对抗边界与代价

> 由 `pipeline.md` 中六个已确认的阶段产出组装而成，已通过研究品味审计（`taste_audit.md`：🟢）。状态：**规格说明 / 论文草稿——尚未运行任何实验。**下文所有数字均为预注册的设计目标，而非结果。本文为 2026-08-21 修订后版本的中文译文；文献名称保留英文原文。

## 摘要（Abstract）

长时程 LLM 智能体（long-horizon LLM agent）会周期性地压缩（compact）其对话与工具历史以维持在 token 预算之内，而记忆钉扎（memory-pinning）正是运维者赖以让安全或任务关键约束在每一次压缩过程中存活下来的机制。我们指出，这种依赖建立在一个未经审视的不对称性之上：在一个跨会话反复执行的固定预算有损压缩信道下，被钉扎的约束只有在每一次压缩事件中都重新赢得保留预算竞争才能存活，而攻击者只需要它输一次，并且可以将离线优化预算摊销（amortize）到制造这一次失败上，对抗的却是每事件预算有限的防御者。Governance Decay（arXiv 2606.22528）——提出压缩致约束擦除现象、压缩驱逐攻击（compaction-eviction attack）以及本文各变体所分解的约束钉扎防御的那篇工作——已经表明基于优化的注入可以在每个被测模型上击败钉扎，但没有回答这一击破发生在攻击强度轴上的何处，也没有回答攻击者付出的代价相对于防御者运行该防御的代价是多少。我们构建了一个测量框架：在五种钉扎式防御变体和两个攻击族（基于梯度的后缀搜索与模板角色伪造攻击）上扫描归一化的注入强度参数，用一个以压缩前后约束状态为门控的两级判定器（two-tier oracle）验证约束违规，为每个变体拟合带自助法置信区间（bootstrap confidence interval）的击破率边界，并将攻击者与防御者的努力换算到同一代价货币中，报告该边界处的代价比。预算匹配的良性填充（benign-filler）与无防御对照将对抗性成因从一般性的长上下文退化中隔离出来。我们报告每种钉扎变体在何处、以多低的代价失效，以及这对把钉扎当作自主智能体部署的充分保障意味着什么。

## 引言（Introduction）

如今，长时程 LLM 智能体的会话已经长到其对话与工具调用历史必须被周期性压缩——摘要并压缩——以维持在可用的上下文预算之内。由于这种压缩在设计上就是有损的，越来越多的部署依赖记忆钉扎：通过重新插入、冗余复制、校验和验证或结构隔离，让一小组安全或任务关键约束在每一次压缩过程中存活，而不是被悄无声息地摘要掉。钉扎的吸引力在于它廉价且直观——诸如"绝不调用此工具"或"超过消费阈值必须上报"这样的固定规则只需附加一次，按照假设，就会在会话余下的时间里一直生效。

然而这一设计背后承重的安全假设仍未被系统刻画。Governance Decay（arXiv 2606.22528）确立了本文所研究的现象：它提出了压缩诱发的治理衰减（compaction-induced governance decay），演示了压缩驱逐攻击（诱导摘要器丢弃某条策略的对抗内容），提出了约束钉扎（constraint pinning）作为防御——一个豁免于压缩、逐字重注入并带每步完整性校验的钉扎缓冲区，本文的重注入、校验和验证与结构槽位变体正是由其直接分解而来——报告了其防御侧代价（约 47 个 token，低于 0.5% 的开销），并表明基于优化的对抗注入能在每个被测模型上击败钉扎，且"近期上下文中的操作者冒充（operator impersonation）"是其残余失效模式。因此，钉扎并非无条件稳健已是已知结论，而其防御分类与防御者代价均继承自该工作，并非本文贡献。Governance Decay 没有确立的是：对给定的钉扎机制，击破发生在攻击者努力连续谱上的何处，以及攻击者达到该点的代价相对于防御者每轮运行该防御的代价是多少——它的主结论是在固定攻击配置下二元的"钉扎有效（代价可忽略，冒充攻击除外）"。这一空白之所以重要，是因为在钉扎变体之间做选择的防御者并不是在"稳健"与"不稳健"之间选择——每种变体最终都会失效——而是在"击破所需的攻击者努力"与"防御自身为换取这种抗性所付出的开销"各不相同的变体之间选择。这条权衡曲线的精确形状，而不只是"钉扎终会失效"这一事实，才是尚无人测量的安全相关量。

最接近的已有工作从相邻但不同的角度切入这一空白。Governance Decay 如上所述是总体上最近的邻居——它拥有该现象、攻击前提、钉扎防御与防御者代价数字，但报告的是二元的有防御/无防御结果，而非连续强度轴上的击破边界或攻防代价比。IH-Benchmark（arXiv 2607.25987）是最接近的判定器工具——用谓词 DSL 检查加按类别限定的 LLM 评审来处理指令层级冲突——但它评分的是单决策冲突结果，而非约束跨压缩事件的持存性。Security–Fidelity Tradeoffs（arXiv 2606.30783）为提示注入防御的保真/效用代价定价，即代价账目中防御者的那一半，但没有攻击者一侧的分母。TensorTrust 用竞争性的人写攻防博弈构建了可解释的基准，并显式测量稳健性—可用性权衡——是与本文所需最接近的既有评测设计——但其防御是静态、人写、单轮的，没有压缩动态，也没有可扫描的连续攻击强度轴。LightMem 是最接近的既有机制：其"睡眠时（sleep-time）"整合步骤在结构上与本文结构槽位变体所参照的受保护记忆槽相似，但 LightMem 只在良性长时程对话一致性上被评测，从未经受对抗压力。SlotGCG、TAO-Attack 等基于优化的越狱攻击及其扩展的经典 GCG 后缀搜索方法，是在固定攻击预算下针对单轮安全拒答做优化，而不是跨压缩事件对结构化钉扎防御扫描强度。ChatInject 等模板角色伪造攻击表明伪造的对话角色结构能在某一固定配置下攻破智能体防御，但既不扫描强度参数，也不专门针对记忆钉扎。而 ThreatSnapshots 这类单骨干调用抽象刻意隔离单次 LLM 调用以固定归因，因而无法表示钉扎约束的存活——那是一个重复的、多事件生命周期的性质，而非任何单次调用的性质。

把这一空白变成可测量的问题会暴露出它自身的困难。压缩在构造上就是有损摘要，所以任何钉扎机制要么在该有损过程内部竞争保留预算，要么必须整体豁免于它——而若不直接对每轮约束状态做插桩，没有任何指标能区分某个变体实际采用的是哪种策略。能击败钉扎的两个攻击族在结构上不可通约：基于梯度的后缀搜索以优化迭代数、候选集大小和 token 预算计量，而模板角色伪造攻击以伪造轮数和载荷大小计量，二者之间没有自然的共同单位。验证约束在压缩后确实被违反，需要一个检查跨两个时间点的关系性质的判定器——压缩前存在、压缩时或之后被违反；结合确定性检查与限定范围 LLM 评审的两级判定器已经存在（IH-Benchmark 是最近的），但它们验证的是单决策结果，而非这种压缩前/后的持存性质。攻击者与防御者的努力以完全不同的资源计价（离线优化算力对每轮运行时开销），因此没有哪种比较货币是唯一正确的。而且由于 LLM 输出和任何 LLM 评审判定器都是非确定性的，击破率是一个随机估计量（stochastic estimand），其表观边界可能是试验数不足的伪影，而非被测机制的真实性质。

我们的方法把上述每个障碍都变成一个明确的设计选择，而不是一句托辞。五种钉扎变体——无防御对照、逐字重注入、冗余 k 副本钉扎、校验和验证钉扎，以及结构隔离的受保护记忆槽——被实现为可互换的中间件，并插桩记录每条约束在每次压缩事件前后的存在性与逐字状态，因此每个变体实际采用的策略是直接可观测的，而非推断的。两个攻击族原始的不可通约强度单位被归一化到一条共享的对数刻度轴上，因此无论击破曲线来自哪个族，都能对每个变体拟合并比较同一条"击破率—强度"曲线。约束违规由两级判定器验证——硬约束用确定性检查，软约束用基于量表的评审——并以显式的压缩前/后归因要求作门控，从而把持存性主张当作它实际所是的关系性质来检验。攻击者努力（达到变体边界所需）与防御者努力（每轮承担）被换算为 token 当量货币以及单独的 API 美元级货币，因此二者之比是一个单一可报告的数字，其对货币选择的敏感性本身也被检验而非被假设掉。并且每条边界只有在功效门（power gate）把每格试验数提升到抽样噪声足够小、拟合边界能与同形状的平坦率区分开之后才进行拟合。

我们在带显式策略约束的工具使用智能体基准和强制多次压缩事件的长多会话对话基准上评估该设计，将对抗注入与预算匹配的良性填充对照及良性压缩下的无防御对照进行比较，以把对抗性成因从一般性的长上下文退化中隔离出来。

概括起来，我们的贡献是：
- 对记忆钉扎作为保障手段背后的持久性/代价不对称性的识别与形式化：被钉扎的约束必须在每次压缩事件中重新赢得保留竞争，而攻击者只需要它输一次，并可将离线攻击预算摊销到对抗每事件预算有限的防御上。
- 一个强度归一化方案，把两个结构上不可通约的攻击族——基于梯度的后缀搜索与模板角色伪造——放到同一条可比轴上，使得无论攻击族为何，都能对每种钉扎变体拟合并比较单一击破边界。
- 一个跨压缩事件、以归因为门控的约束持存性判定器。两级结构本身（确定性硬约束检查 + 基于量表的评审）沿袭既有工具——IH-Benchmark 的谓词 DSL 加按类别限定评审是最近的——本文贡献仅限于把单决策检查变为持存性检查的压缩前/后关系门控。
- 一种双货币代价核算方法，在每个变体的实测边界处给出攻防代价比。仅防御侧代价已由 Governance Decay 报告，防御代价定价也已见于 Security–Fidelity Tradeoffs；本文贡献是实测击破边界处的攻击者对防御者之比，以及该比值对所选货币敏感性的检验。
- 一份关于每种钉扎变体在对抗性上下文压缩下于攻击强度轴何处、以何种代价失效的实证账目——需要指出，五种变体中有三种（重注入、校验和验证、结构槽位）分解自 Governance Decay 自己提出的防御，因此该发现是为一个既有防御定价而非提出新防御——以及这对把钉扎视为充分保障意味着什么。

## 问题定义（Problem Definition）

**形式化设定。**考虑一条由轮次 τ₁, ..., τ_T 组成的智能体轨迹，其中压缩事件 κ 把历史映射到至多 B 个 token，在轨迹上发生 m ≥ 1 次。取自约束套件 C 的被钉扎约束 c 一经引入即须在会话余下时间内保持成立。防御变体 d 取自 D = {无防御对照，逐字重注入，冗余 k 副本钉扎，校验和/标签验证钉扎，结构隔离的受保护记忆槽}。对抗注入过程取自攻击族 a ∈ {白盒梯度优化后缀搜索，黑盒模板角色伪造}，由归一化强度标量 s ∈ [0,1] 参数化。击破指示变量 V(c, 轨迹; d, a, s, 试验 ω) ∈ {0,1} 记录 c 在某次压缩事件之前存在的条件下，是否在该事件时或之后被违反。研究对象是：对每个（变体，攻击族，模型 g）组合，击破率函数 p_{d,a,g}(s) = Pr[V = 1]——它是否在被测强度范围内越过有意义的阈值？若越过，在何强度处（即边界），且该边界处攻防代价之比为多少？

**为何困难。**压缩在构造上就是有损摘要，因此防御变体要么在该有损过程内部竞争保留预算（逐字重注入、k 副本、校验和验证都是在竞争之后尝试事后恢复），要么整体豁免于它（结构槽位）——而若不直接插桩每轮约束状态，没有指标能区分某变体的观测抗性由这两种策略中的哪一种负责。两个攻击族以结构上不可通约的原始单位计量——梯度族是优化迭代数 × 候选集大小 × token 预算，模板族是伪造轮数 × 载荷 token 预算——因此以任一族原始单位报告的边界无法与另一族比较，除非有显式、公开的归一化。验证 V 需要一个检查跨两个时间点关系性质的判定器（κ 之前存在、κ 时或之后被违反），这与单轮有害性判断或单骨干调用安全评分是实质不同的对象。攻击者的努力（达到给定 s 所需的离线优化算力、查询或 token）与防御者的努力（运行变体 d 每轮附加的 token 与延迟）以完全不同种类的资源计价，因此其比值的货币没有唯一正确的选择——任何选定的货币都内嵌一个方法论假设，必须被摆到明面上并做压力测试，而非隐藏。并且由于 p_{d,a,g}(s) 是从有限、有噪的试验集中估计的，表观边界可能是试验数不足的伪影而非该（变体，攻击，模型）格的真实性质，除非试验数由显式的功效准则设定而非事先固定。

## 方法概览（Method Overview）

在概念层面，本研究是一条由五个协作部件组成的单一测量流水线。钉扎式防御变体矩阵与归一化的跨族攻击强度轴共同为每个条件产生一列试验结果；一个两级、以归因为门控的判定器把每次试验变成经验证的击破指示；一个功效门控、带自助法区间的曲线拟合把结果序列变成每变体一个可比的边界标量；一套双货币代价核算把攻击者与防御者的努力变成该边界处一个可报告的比值。

**结构化防御矩阵**把五种钉扎变体实现为压缩摘要器外的可互换中间件，插桩记录每条约束在每次压缩事件前后的存在性与逐字状态，使每个变体实际采用的恢复策略直接可观测。**强度归一化方案**把每个攻击族原始的、结构不可通约的强度单位映射到一条共享的对数刻度 [0,1] 轴上，使一个族下拟合的击破曲线可与另一个族下的曲线直接比较。**两级违规判定器**取每次试验的压缩后状态，验证被钉扎约束是否被违反：硬约束用确定性检查，软约束用基于量表的评审，并以显式的压缩前/后归因要求作门控。**双货币代价核算**取攻击者达到变体边界所需的努力与该变体每轮施加的防御开销，把两者换算为 token 当量货币及单独的 API 美元级货币，并在两种货币下分别报告其比值。**功效门控边界估计**取所得的击破序列，为每个（变体，模型，攻击族）拟合一条逻辑斯蒂（logistic）曲线，先把每格试验数提升到抽样噪声足够小、拟合边界可信为止，然后以自助法置信区间报告边界。

## 方法论（Methodology）

### 结构化防御矩阵（Structural Defense Matrix）

**挑战。**压缩在构造上就是有损摘要，因此任何钉扎机制要么在该有损过程内部竞争保留预算，要么必须整体豁免于它，而没有既有指标能区分给定变体实际采用的是哪种策略。

**洞见。**只有把钉扎内容完全移出压缩过程的变体才绕开了有损竞争；其余每种变体都在其内部竞争，区别仅在于事后恢复的方式——这一区别除非直接插桩每轮约束状态而非从最终转录推断，否则不可见。

**方法。**五种钉扎变体被实现为压缩摘要器外的可互换中间件封装：无防御对照、每次压缩事件后对钉扎约束的逐字重注入、冗余 k 副本钉扎、校验和/标签验证钉扎（验证器重算受保护片段的哈希并在不匹配时重新插入），以及豁免于摘要的结构隔离受保护记忆槽。智能体框架按轮次、按约束记录每条约束在每次压缩事件前后紧邻时刻的存在性与逐字状态。

### 强度归一化方案（Strength-Normalization Scheme）

**挑战。**能够击败钉扎的两个攻击族以结构上不可通约的原始单位计量，因此以一个族的单位报告的边界无法与另一个族的边界直接比较。

**洞见。**把两个结构不可通约的原始攻击预算归一化到同一条对数刻度轴上，正是使单一"击破率—强度"曲线能对每个变体拟合并跨族比较的前提；若改为报告各族原始单位，每个变体在族间都将不可比。

**方法。**每个攻击族配备显式的强度旋钮——梯度优化后缀族为优化迭代数 × 候选集大小 × token 预算；模板角色伪造族为伪造角色/轮数 × 载荷 token 预算——两者经对数变换、按族界定的刻度映射到共享的 [0,1] 轴上：s 等于原始预算的对数减去该族最小测试预算的对数，再除以该族最大与最小测试预算对数之差。

### 两级违规判定器（Two-Tier Violation Oracle）

**挑战。**验证被钉扎约束在压缩后被违反，需要检查跨两个时间点的关系性质——压缩事件前存在、事件时或之后被违反——这与单轮有害性判断或单骨干调用安全评分是实质不同的对象。

**洞见。**持存性判定器检查的是一个关系性的、双时间点的性质。两级结构——确定性检查加限定范围的 LLM 评审——并不新（IH-Benchmark 的谓词 DSL 加按类别限定评审是最近的既有工具）；既有判定器都不提供的，是把裁决条件设为"约束在压缩事件前紧邻时刻存在且在事件时或之后被违反"的那个关系门控。

**方法。**约束违规由两级判定器验证：对硬约束（禁用工具被调用、数值或格式规则被破坏）用确定性程序化检查；对软约束用改编自基于准则的越狱评测方法学的量表式 LLM 评审清单。两级都以归因要求为门控——约束在压缩事件前紧邻时刻存在、且在事件时或之后被违反——评审级在用于验证性结论之前，先对照一个留出的人工标注案例集接受审计。

### 双货币代价核算（Dual-Currency Cost Accounting）

**挑战。**攻击者努力（离线优化算力）与防御者努力（每轮运行时开销）以完全不同种类的资源计价，分别报告会使"该变体值不值它的开销"无法用单一数字回答，且没有哪种合并货币是唯一正确的。孤立的单侧定价已见于先前工作——Governance Decay 报告了钉扎的防御者代价（约 47 个 token，<0.5% 开销），Security–Fidelity Tradeoffs 为注入防御的保真代价定价——但尚无工作在实测击破点处把攻击者代价与防御者代价联系起来。

**洞见。**用同一单位表达攻防双方的努力，并且在两种各有独立依据的货币而非一种货币下进行，把一个不可通约的比较变成一个可检验的数字，其货币敏感性被报告而非被隐藏。

**方法。**攻击者代价按达到变体实测边界所耗的优化器查询、前向/反向传播或 API token 计算；防御者代价按该变体每轮施加的额外 token 与新增延迟计算。两者换算为 token 当量共同货币及单独的 API 美元级货币，并在两种货币下于每个变体边界处计算攻击者对防御者之比。

### 功效门控边界估计（Power-Gated Boundary Estimation）

**挑战。**击破率是一个随机估计量，因此表观边界可能是试验数不足的伪影，而非被测（变体，攻击，模型）格的真实性质。

**洞见。**把边界报告为由显式功效准则设定试验数所得的自助法区间，而非任意选定试验数下的点估计，才使真实边界能与实为平坦率周围抽样噪声的同形状曲线区分开。

**方法。**对每个（变体，模型，攻击族），持续提升每格试验数，直到观测网格最陡点处 Wilson 得分区间的半宽降到预设阈值之下，然后才拟合逻辑斯蒂"击破率—强度"曲线，给出带自助法置信区间的边界标量（50%/90% 击破率处的强度），并附上击破曲线下面积作为与强度无关的汇总量。

## 实验（Experiments）

### 实验设置（Experimental Setup）

**数据集。**AgentDojo——原生把任务约束与安全相关执行日志放在一起的工具使用智能体环境，为硬约束判定级提供可程序化检验的基底，无需仅靠评审打分。InjecAgent——间接提示注入智能体基准，提供模板角色伪造攻击族所改编自的注入基底与攻击插入脚手架。τ-bench——带显式策略约束、更接近生产智能体工作负载的工具智能体任务，用于检验边界与代价发现是否能泛化到单一基准的任务分布之外。LongMemEval 与 LoCoMo——原生需要多次、重复压缩事件的长多会话对话基准，这是单会话基准所不强制的；跨条件排序稳定性主张特别需要被钉扎约束必须多次重新挺过压缩的工作负载，因为单次压缩的任务无法区分"活过一次"与"每次都可靠地重新赢得保留竞争"。

**基线与对照**（是健全性检查与混淆隔离对照，不是要击败的竞争者——这是一项测量研究，此处没有任何研究问题被表述为"我们的流程胜过基线 X"）。良性、非对抗压缩（无攻击者在场）下的无防御变体确立了仅由压缩本身丢失的约束比例；这是下文归因层问题所必需的对照。预算匹配的良性填充注入把攻击者载荷替换为 token 预算、数量与插入位置全同的良性填充，用以隔离击破是由对抗内容本身引起，还是由匹配预算下的一般性长上下文退化引起。脚本化的非自适应模板变体（固定伪造角色数、无优化）检验任何观测到的强度相关趋势是否只是更长提示的一般伪影。

**攻击臂适用范围。**梯度优化后缀族需要梯度访问，因此局限于开放权重（open-weight）骨干模型；闭权重 API 模型（包括 τ-bench 式的生产工作负载）仅由黑盒模板角色伪造族覆盖。因此 RQ5 的跨模型排序主张按攻击族条件化：就梯度族而言它只是关于开放权重模型的主张，向 API 模型的泛化全靠模板族。

**指标。**经两级验证的击破率及 Wilson 95% 置信区间；边界标量 BT50 与 BT90 及自助法置信区间；击破曲线下面积；BT50 处两种货币下的攻防代价比；判定器评审—人工一致性的 Cohen's κ；跨模型/跨攻击族排序稳定性的 Kendall's τ。

**研究问题：**
1. RQ0（框定）——观测到的压缩后击破可归因于对抗注入本身，而非一般性的良性压缩退化吗？
2. RQ1——五种钉扎变体的抗性排序符合预测的"结构槽位最高"排名吗？
3. RQ2——在归一化强度轴下，多数（变体，攻击族，模型）格能拟合出可靠的击破边界吗？
4. RQ3——两级判定器的评审级与人工判断的一致程度足以支撑验证性结论吗？
5. RQ4——攻防代价比在变体间有实质差异吗？该排名在不同代价货币下保持吗？
6. RQ5——按边界与代价比得到的变体排序在跨模型、跨攻击族时稳定吗？

#### RQ0：观测到的击破可归因于对抗注入本身，而非一般性的良性压缩退化吗？

**设置。**比较无防御变体在良性（非对抗、空载荷）压缩下的击破率与其在匹配强度和轮数的对抗注入下的击破率；另在 token 预算、数量与插入位置全同的条件下，比较对抗注入的击破率与预算匹配良性填充对照的击破率。

**预期结果。**良性压缩击破率保持低位（其 Wilson 上界低于 0.20），且对抗注入的击破率在匹配预算下显著高于预算匹配良性填充对照——从而确立击破可归因于对抗内容，而非上下文退化或压缩本身。

**证伪条件。**若良性压缩击破率的 Wilson 上界达到或超过 0.20（约束仅因压缩就已丢失，使对抗性框定失去意义），或对抗注入的击破率与预算匹配良性填充对照在统计上不可区分（Wilson 置信区间重叠），则本问被驳回——任一情形都意味着所声称的对抗成因未能与其最强的替代解释隔离。

**假设（通俗表述）。**周边文献中两种良性压缩视角都不建模试图驱逐受保护约束的攻击者，因此其保留保证对对抗持久性无话可说；本问直接验证此处测量的是对抗性击破，而非那些良性模型本已预测的伪影。

**指标。**良性压缩下的击破率（Wilson 置信区间）；匹配预算下良性填充对对抗注入的击破率（Wilson 置信区间及重叠检验）。

#### RQ1：五种钉扎变体的抗性排序符合预测的"结构槽位最高"排名吗？

**设置。**用功效门控边界估计方法为每个（模型，攻击族）格拟合全部五种变体的 BT50；在每格内对五个 BT50 值做两两比较。

**预期结果。**在多数被测格中，五种变体的 BT50 按 结构槽位 > 校验和验证 > k 副本 > 逐字重注入 > 无防御对照 排序——抗性随变体恢复机制距"依赖有损压缩过程逐字保留约束"的远近而递增。

**证伪条件。**若预测排序在多数被测格中不成立，或预测顺序中任一相邻对在多数格中以互不重叠的自助法置信区间发生反转，则本问被驳回——任一情形都意味着抗性并不跟随变体恢复机制与有损过程的距离，结构豁免洞见不能按原样成立。

**指标。**每变体 BT50 及自助法置信区间；跨格两两排序一致率。

#### RQ2：在归一化强度轴下，多数（变体，攻击族，模型）格能拟合出可靠的击破边界吗？

**设置。**对每个被测（变体，攻击族，模型）格，在归一化强度轴上拟合逻辑斯蒂击破—强度曲线，并按拟合质量标准评估（McFadden 伪 R² ≥ 0.3，斜率显著为正，BT50 置信区间有界）。

**预期结果。**每模型、每攻击族下 5 种防御变体中至少 4 种通过拟合质量标准：McFadden 伪 R² ≥ 0.3，斜率显著为正（Holm 校正 p < 0.05），BT50 自助法 95% 置信区间宽度不超过被测强度范围的 25%。

**证伪条件。**若在多数（模型，攻击族）格中通过拟合质量标准的变体少于 4 种，则本问被驳回；而某变体的击破率在整个被测强度范围内保持平坦且低于低天花板，不算本问的证伪，而是一个独立的、同样值得报告的"范围内不可击破"发现，应单独报告而非计为拟合失败。

**假设（通俗表述）。**归一化强度轴在攻击族之间的可比性足以让多数钉扎变体上都能找到真实、拟合良好的边界——而非归一化选择的伪影。

**指标。**每格 McFadden 伪 R²；斜率显著性；BT50 自助法置信区间宽度占强度范围的比例。

#### RQ3：两级判定器的评审级与人工判断的一致程度足以支撑验证性结论吗？

**设置。**评审清单的类别植根于被钉扎约束自身的书面规格，在约 50 例留出校准切片上起草量表，然后在不相交的约 200 例留出审计集上，用 ≥2 名独立人工标注者审计冻结后的量表，计算评审与人工标签间的 Cohen's κ，并检查分歧结构是否存在向单一标签的系统性坍缩。

**预期结果。**评审级在留出审计集上对人工标签达到 Cohen's κ ≥ 0.7（依 `paper.md` 第 5 步 R2 工具验证序列，该标准已从最初的 0.6 提升到 guidance.md §3.4 R2 要求的 0.7 下限），且分歧结构无系统性坍缩。

**证伪条件。**若 Cohen's κ 低于 0.7，或即使 κ ≥ 0.7 分歧仍呈现向单一标签的系统性坍缩，则本问被驳回；无论哪种情形，软约束结果都降级为次要/探索性，仅硬约束（程序化验证）结果被用作 RQ1、RQ2、RQ4、RQ5 的验证性依据。

#### RQ4：攻防代价比在变体间有实质差异吗？该排名在不同代价货币下保持吗？

**设置。**在每个变体实测 BT50 处，分别按 token 当量与 API 美元级两种货币计算攻防代价比；跨任务对各变体的对数比做 Holm 校正的 Wilcoxon 符号秩检验的两两比较。

**预期结果。**最易击破与最难击破变体之间的代价比至少相差 2 倍（Holm 校正的 Wilcoxon 至少对一对拒绝相等，α = 0.05），且所得变体排名在两种货币下完全一致（Kendall τ = 1）。

**证伪条件。**若代价比在所有变体对之间统计不可区分（没有一对以显著检验达到 2 倍阈值），则本问被驳回，意味着钉扎机制的选择并不稳健地改变对抗代价；另外，若变体排名在两种货币之间发生反转，则作为排名稳定性失败被单独驳回，此时不报告单一比值，而是并列报告按货币条件化的排名。

**假设（通俗表述）。**尽管每种变体最终都会失效，钉扎实现之间的性价比仍有实质差异——按单位防御开销计，有些变体更贵才击得破。

**指标。**每变体两种货币下的代价比及自助法置信区间；Wilcoxon 检验统计量与 p 值；两货币排名间的 Kendall τ。

#### RQ5：按边界与代价比得到的变体排序在跨模型、跨攻击族时稳定吗？

**设置。**对每个被测模型与攻击族分别按 BT50 与代价比计算变体排序；对所有模型对与两个攻击族计算这些排序的平均两两 Kendall's τ，并做置换检验。

**预期结果。**基于 BT50 与基于代价比的排序均达到平均两两 Kendall's τ ≥ 0.6（置换 p < 0.05），表明即便绝对 BT50 值移动，钉扎变体的相对稳健性排名大体与模型和攻击族无关。

**证伪条件。**若平均两两 Kendall's τ 不显著为正（τ ≈ 0 或为负，或未通过置换检验），则本问被驳回——意味着哪种钉扎变体最好取决于具体模型与攻击者，无法从单一排名给出可迁移的部署指导。

**假设（通俗表述）。**钉扎变体的相对稳健性排名可跨模型与攻击族迁移，即便绝对击破点移动——从而给出无需为每个新骨干重跑全量扫描的实践指导。

**指标。**平均两两 Kendall's τ（基于 BT50 与基于代价比）及置换 p 值。

与本文最接近的先前工作是 Governance Decay（arXiv 2606.22528），在概览更广图景之前必须把差量说清楚。Governance Decay 提出了压缩诱发的治理衰减——正是本文所研究的现象——连同本文威胁模型所采用的压缩驱逐攻击、本文五种变体中三种所分解的约束钉扎防御（一个豁免于压缩、逐字重注入并带每步完整性校验的钉扎缓冲区）、其防御侧代价（约 47 个 token，<0.5% 开销），以及"优化注入能在每个被测模型上击败钉扎，近期上下文中的操作者冒充（本文模板角色伪造族的前身）为残余失效模式"这一发现。它没有报告的是本文的任何估计对象：其结果是固定攻击配置下二元的有防御/无防御，没有连续强度轴，没有击破边界位置，没有变体抗性排序，也没有攻防代价比。另有两个邻居界定了具体工具。IH-Benchmark（arXiv 2607.25987）提供最接近的判定器设计——指令层级冲突上的谓词 DSL 加按类别限定 LLM 评审——本文两级判定器在结构上沿袭它；差量仅限于压缩前/后持存性门控。Security–Fidelity Tradeoffs（arXiv 2606.30783）为提示注入防御的隐性保真代价定价——即本文代价账目中防御者的那一半——但没有攻击者侧的分母，也没有可供评估的边界。

在更早的评测设计与机制中，TensorTrust 用竞争性的人写攻防博弈构建了可解释基准并显式测量稳健性—可用性权衡——是与本文所需最接近的既有评测设计——但其防御是静态、单轮的，没有压缩动态，也没有可扫描的连续攻击强度轴。LightMem 是最接近的既有机制：其"睡眠时"整合步骤在结构上与本文结构槽位变体所参照的受保护记忆槽相似，但 LightMem 只在良性长时程对话一致性上被评测，从未经受对抗压力——这正是本文对抗扫描要填补的空白。

**面向 LLM 智能体的提示注入攻击与防御。**ChatInject 把恶意工具输出内容包裹在伪造的对话角色定界符中，使智能体把攻击者文本当作更高权限的结构处理，其攻击成功率在单一固定配置下对提示式与检测器式防御做了评测。ThreatSnapshots 把单次骨干 LLM 调用连同其完整执行上下文隔离出来，以便在不模拟完整智能体的情况下对各模型的骨干安全性打分比较。两者都确立了 LLM 智能体安全可测可比，但都没有对结构化记忆钉扎防御扫描连续攻击强度参数，且 ThreatSnapshots 的单调用抽象无法表示钉扎约束的存活——那是重复、多事件生命周期的性质，而非任何一次调用的性质。

**基于优化的越狱。**GCG 确立了在对抗后缀 token 上做梯度引导贪心坐标下降搜索、以从对齐模型诱出肯定式响应的方法；SlotGCG 把插入位置本身也变成被优化的变量，TAO-Attack 则用渐进式两阶段目标替换了 GCG 的单一前缀目标损失。三者都是在固定攻击预算下针对单轮安全拒答做优化，而非对结构化钉扎防御扫描连续强度变量，也都不测量攻击必须克服的防御侧代价——压缩下的攻防代价权衡因此仍未被测量，而这正是本文代价核算方法要填补的。

**注入成功评测与稳健性基准。**GuidedBench 把越狱成功评测细化为由基于准则的评审打分的实体/动作清单，降低了评测者歧义——但其对象是单轮有害内容诱出，没有为"被钉扎约束是否在压缩事件后被违反"提供判定器，后者需要检查跨时间的持存性而非单个响应的有害性。IH-Benchmark（见上文）在工具侧最接近——其谓词 DSL 加限定评审的设计是本文判定器沿袭的结构模板——但它评分的是单决策冲突结果，没有持存性门控。TensorTrust（见上文，最接近的早期评测设计）在静态单轮博弈中联合测量稳健性与任务有效性。

**上下文压缩与记忆流水线。**COMI 把长上下文压缩表述为固定 token 预算下的受约束信息选择，按查询相关性与冗余度分配预算；一个伴随的信息论视角把压缩器建模为噪声信道，用源与压缩表示之间的互信息度量压缩质量。两者建模的都是压缩在良性目标下协作保留什么；都不建模主动试图驱逐受保护约束的攻击者，因此其保留保证对对抗持久性无话可说——这正是本文 RQ0 归因检查直接验证的空白。LightMem（见上文，最接近的机制邻居）把记忆生命周期重构为预压缩、话题分割、摘要与离线整合，为跨会话保留持久内容给出了具体、现实的流水线，但对其中任何环节都未做对抗压力测试。

## 结论（Conclusion）

本工作把记忆钉扎背后的一个治理假设——约束一经固定即能挺过之后每次压缩——重新表述为可精确测量的边界与价格，而非二元的稳健/不稳健性质。核心的方法论押注是：钉扎的失效只有在被定位到一条可比强度轴上、并以共同的攻防货币定价之后才有信息量；一个赤裸的"它会破"发现——Governance Decay 已经确立，而本文所研究的变体正分解自其钉扎防御——对部署决策该选哪个变体、何时该担心毫无指导。无论扫描揭示出何种排序与代价分化，该发现都与决策相关：若最廉价变体的边界又低又便宜，就说明在任何有意义的攻击者预算下都不应仅靠钉扎；若结构槽位变体的边界分离良好且昂贵难及，就说明真正的安全裕度在于机制选择，而不只是"钉扎与否"。三个局限从一开始就界定该主张，且是自然的后续步骤而非事后补丁：代价比的货币依赖性被当作一等的可报告结果，而非靠选定一种货币来消解，货币间的真实反转本身就是发现而非需要掩盖的设计缺陷；为保持白盒臂计算可行而采用的热启动、可迁移梯度攻击，相对完全重优化攻击可能低估真实攻击强度，本设计在子集上测量而非假设掉这一校准差距；梯度族对开放权重的需求把该臂限制在开放权重骨干上，因此对闭权重 API 模型的跨模型结论只依赖黑盒模板族。
