# 证明还是幻觉：大模型服务替换的"检测—伪装"成本前沿

## 摘要

大语言模型（Large Language Model, LLM）API 的黑盒（black-box）用户无法验证提供方是否真的在提供其宣称的检查点
（checkpoint）或服务档位（service tier）。行为指纹（behavioral fingerprinting）——对端点发起探测、检验其输出
是否与参考模型一致——被提出作为可部署的防御手段；一系列黑盒检测器（分布相等性检验、基于秩的一致性检验、
单 token 与对数概率检验）已使其在面对**被动**提供方时具备实用性。但有两个事实动摇了这一防御。第一，替换并非
假想：模型相等性检验（Model Equality Testing）发现 31 个商业 Llama 端点中有 11 个所提供的分布与已发布权重不同；
近期一项网关审计在 15 对同名模型的提供方中标记出 14 对存在量化与内核偏差。第二，指纹是可被伪装（spoof）的：
一个了解检测器的提供方可以低成本地把更便宜的模型改造成模仿预期模型。真正未解的问题不是指纹**是否**可伪装，
而是**有多可伪装**——在多大的对手预算下、在多大的服务噪声（serving noise）下、提供方要付出多大代价——因为
这个答案决定了行为审计究竟是一个可用的兜底手段还是一种虚假的安慰，进而决定了密码学证明（cryptographic
attestation）是可选的还是必需的。我们持这样的立场（position）：在最要紧的情形下，仅靠行为的证明无法充当模型
服务的身份层；并且我们用实验来支撑这一立场。在我们自控、按已知检查点对提供服务、并注入经真实 API 校准的
服务噪声的端点上，我们测量一条**检测—伪装成本前沿**（detection-vs-spoofing cost frontier）：检测能力（power）
作为审计方查询预算与提供方伪装预算的函数，覆盖三种情形——跨族完全替换（R1）、向量化/蒸馏兄弟模型的档位降级
（R2）、以及自适应伪装（R3）。我们检验关于前沿**形状**的三条可证伪假设：**不对称性**（最贴近消费者的 R2 降级
比 R1 替换更便宜伪装）、**成本悬崖**（很小的伪装预算即可击溃 R2 检测）、以及**噪声掩蔽界**（某个现实噪声水平
在零对手预算下即可击败降级检测）。我们进一步计量提供方的隐藏成本，报告一个**收益侵蚀比**（savings-erosion
ratio）——提供方为击败检测器而必须花费的算力，是否吞噬了驱动其降级的服务成本节省。若前沿是"温和"的，则立场
被证伪、行为审计足矣——这本身是一个可发表的反转。无论哪种结果，前沿都告诉从业者：行为审计能抓住哪些违规、
抓不住哪些违规，以及在何处只有密码学证明加披露规范（disclosure norms）才能弥补缺口。

## 1. 引言

大语言模型越来越多地通过第三方 API 访问，因为其算力需求使本地部署对多数用户不切实际。在这种设定下，用户只能
观察到提示（prompt）与返回文本；所服务的检查点、数值精度、批处理策略与路由都由提供方掌控。每当一个决策——
采购、验收、付款、科学可复现性——取决于**究竟是哪个模型**在回答时，用户就需要一种从外部验证该身份的手段。

这并非假想的顾虑。对商业 Llama 端点的模型相等性检验发现 31 个端点中有 11 个所提供的输出分布与 Meta 发布的
权重不同（Gao 等，arXiv:2410.20247）；一项有预算约束的网关审计把 15 对同名模型的提供方中的 14 对标记为
统计不一致，源于真实的量化与内核偏差，另一项六平台审计在 28 个"平台—模型"单元中发现 7 个不一致，且集中在
高端端点（Zhang 等，IRIS，arXiv:2607.20860）。经济动机是结构性的：当推理成本占主导时，在高价档位上偷偷提供
更便宜的量化或蒸馏兄弟模型是一种长期存在的诱惑。

该领域提出的防御是**行为指纹**：探测端点、检验其可观测行为是否与可信参考一致。如今已有一整套工具——分布
相等性检验（Gao 等，2410.20247）、基于秩的一致性检验（Zhu 等，arXiv:2506.06975）、单 token 输出分布检验
（arXiv:2607.10252）、对数概率跟踪（arXiv:2512.03816）、知识边界指纹（Fang 等，arXiv:2605.29524）、以及
有预算的网关审计（IRIS，2607.20860）。但它们无一例外都是在评估一个**被动**、忠实展现自身行为的提供方。

而这一假设刚刚被证明会失效。一个了解检测器的提供方可以用参数高效微调（parameter-efficient fine-tuning）把
弱模型改造成模仿强模型，从而低成本地规避用户侧指纹（Zhang 等，《你的"Pro"订阅可能其实是"免费版"》，
arXiv:2606.16100）。这就把一个检测问题变成了**经济**问题。单一的检测率无法刻画一场对抗性交互；真正相关的对象
是一条双边前沿，联系审计方资源、对手的精巧程度与花费、伪装成功率、以及提供方的隐藏成本。既有工作确立了这条
前沿**存在**；无人测量过它的**形状**。

**立场。** 我们主张：在最要紧的情形下——面对理性的、了解检测器的提供方所实施的静默档位降级——仅靠行为的证明
无法充当模型服务的身份层；并且这必须靠实验来判定，而非断言。学界已经通过论证得出对立结论：一派认为仅靠软件的
检测不可靠、可信执行是唯一出路（Cai 等，arXiv:2504.04715）；另一派为静默模型更新提出治理与披露机制
（arXiv:2604.27789）。二者都没有测量行为检测究竟**在成本前沿的何处**失效，因此都无法告诉从业者：一次廉价的
外部审计仍能抓住哪些违规、哪些则需要硬件支撑的证明。

**方法路径。** 我们搭建自控端点，按已知检查点对提供服务——参考模型 m0、跨族替换 m1、档位降级兄弟模型 m0\*
——都置于同一共享服务栈之后，于是替换状态由构造保证为真值（ground truth）。我们注入服务噪声（温度、批处理
不确定性、量化、路由），其幅度**校准到实测的真实 API 方差**（关卡 G1）。一个外部黑盒审计方运行一批已发表的
检测器，先在干净模型对上复现（关卡 G2）。一个了解检测器的提供方在 Kerckhoffs 式对手阶梯上花费可计量的伪装
预算。我们把检测能力报告为查询预算与伪装预算上的一个曲面，覆盖三种情形，并计量提供方的隐藏成本以计算收益
侵蚀比。

**贡献。**
1. **带校准服务噪声的真值测试床**：把封存的检查点身份与生产环境拟合的噪声画像交叉，从而把对抗性替换与良性
   服务变异分离开（并且也与良性的模型**漂移**——另一条漂移审计工作线的主题——分离，后者被我们排除在范围之外）。
2. **检测—伪装成本前沿**：在三种情形（R1 替换、R2 档位降级、R3 自适应伪装）下、针对一个公平有界的对手阶梯
   测得，并附三条可证伪的结构性假设——不对称性、成本悬崖、噪声掩蔽界。
3. **隐藏成本核算**：一个共享资源账本与一个收益侵蚀比，检验击败检测器是否吞噬了降级的经济动机——本文的经济
   "牙齿"与第二项贡献。
4. **决策地图及其含义**：把测得的前沿映射到（噪声 × 对手预算）平面，得到若干区域——行为审计足矣、需要披露
   规范、只有密码学证明才能弥补缺口——即经验支撑的"模型服务的 TLS"（TLS for model serving）论证，且把"测量
   得到的"与"论证得到的"边界明确标出。

## 2. 背景与威胁模型

**行为检测器（审计方的工具）。** 模型相等性检验把问题框定为双样本检验，当字符串核上的最大均值差异（MMD）
统计量把 API 样本与参考样本分开时拒绝原假设（Gao 等，2410.20247）。RUT 把目标得分转成随机化的秩并检验其
一致性，查询高效且难被察觉（Zhu 等，2506.06975）。单 token 指纹读取单 token 输出分布（2607.10252）；对数概率
跟踪随时间跟踪端点的 logprob（2512.03816）；KBF 对知识边界附近稳定的数值召回进行指纹刻画（2605.29524）；
IRIS 仅凭返回文本审计网关并自定查询预算（2607.20860）。我们把这些全部视为一个可供**构建其上**、而非与之竞争
的**检测器库**——先在干净对上复现（G2），再置于噪声与对手之下承压测试。

**可伪装性这一转折点。** GhostPrint 表明提供方可以参数高效微调一个弱模型去模仿更强的模型、以低微调成本绕过
代表性指纹，并证明有限查询预算与弱分类器使当前指纹易受攻击（Zhang 等，2606.16100）。正是这个结果把检测变成了
经济：它确立了可伪装性存在，但只在固定工作点上报告成功率，而非一条联合预算前沿，也从未追问伪装成本是否侵蚀了
降级的节省。

**两个对照靶（foils）。** Cai 等（2504.04715）在现实条件下评估仅靠软件的检测，发现其对细微替换与推理不确定性
不可靠，主张可信执行环境（Trusted Execution Environment, TEE）是稳健之路。我们承认 TEE 是稳健的终点、不与其
比拼工程；我们的增量是去**测量那条使 TEE 成为必需的前沿**——精确定位行为检测在何处崩溃——并指出 TEE 未覆盖
之处（行为等价性与披露）。治理这条线（2604.27789）主张静默模型更新需要披露机制；我们承认这一框定，并补上它
预设的**可执行性基底**（enforceability substrate）：一个你无法从外部审计的披露规范只是承诺、而非管控，而我们的
前沿恰恰指出哪些违规便宜可查（规范可自执行）、哪些便宜可伪（规范需密码学背书）。可验证推理类方法——SVIP
（2410.22307）、DiFR（2511.20621）、零知识与 TEE 方案——都需要可信内部信息、同步随机种子或硬件证明，因而无法
解决我们所研究的纯外部黑盒问题。

**威胁模型。** 端点提供 m ∈ {m0, m1, m0\*}。审计方只有黑盒查询访问——无 logits、无执行轨迹、无硬件计数器——在
预算 b 内发起 n 次自适应查询，并在假阳率（false-positive rate）α 下输出判决。提供方是 **Kerckhoffs 式**的：
它了解检测器类别及其公开统计量（检测器不是秘密），并花费可计量的算力预算 h 于一个伪装策略 π_h，把 m0\*/m1
的输出在检测器可见的统计量上朝 m0 投影。公平性由**把整条前沿报告为 h 的函数**来定义：既非固定弱对手、也非
无界对手才是主张。核心对手层被限定为**轻量后处理**（重加权/重排序/解码校准），使其可复现并给出可伪装性的
**下界**；基于重训练的伪装（PEFT、蒸馏）是一个被明确标注的**上层 A4**，用以给出**上界**。服务噪声 N（温度、
批处理不确定性、量化、路由）是环境中一等的、经校准的组成部分，而非事后补丁。

## 3. 方法

*图1。测试床、对手阶梯、隐藏成本账本，以及两个交付展品——测得的成本前沿与论证得到的决策地图。测量所得曲面与论证所得区域之间的虚线边界在 §4–§6（结果，测量）与 §7（含义，论证）中始终被强制区分。*

**3.1 真值测试床。** 我们在统一的开源服务栈（如 vLLM/TGI 置于同一封装之后）上搭建 API 端点，提供已知检查点：
m0 为中等规模开源参考（Llama 或 Qwen 类，7–70B）；m1 为规模相近的跨族模型；m0\* 为 m0 的量化（8-bit/4-bit）
和/或蒸馏兄弟模型。由于我们掌控每个端点服务哪个检查点，替换状态由构造即为真值，且所有权重开源，故测试床
可复现，无需依赖任何厂商的私有 API。

**3.2 校准服务噪声（关卡 G1）。** 我们注入温度变化、批处理/内核不确定性、量化抖动与依赖负载的路由。G1 要求
N 的幅度**拟合到实测的真实公开 API 不确定性**：对少量商业端点重复相同查询，在版本稳定窗口内测量输出分布方差
与 logprob/秩稳定性，并报告一条从"实测低"到"实测高"的噪声扫描。稳定窗口通过穿插固定金丝雀（canary）提示、
并对响应/延迟/头部通道施加变点检验来识别；外部端点只提供噪声分布信息，绝不提供检查点身份真值。

**3.3 检测器库（关卡 G2）。** 我们把基于秩（2506.06975）、单 token（2607.10252）、logprob（2512.03816）与
MMD 相等性（2410.20247）的检测器移植到统一接口之后。G2 要求每个检测器先在干净（无噪声、非自适应）对上复现
其源论文的检测能力，才允许它在噪声或对手下被信任。审计方以序贯似然比检验驱动该库，其下一提示的选择最大化
期望信息增益，在越过判决边界或耗尽查询预算时停止。

**3.4 对手阶梯。** A0 无；A1 朴素输出匹配（事后朝 m0 高频 token 投影）；A2 了解检测器的分布匹配（匹配检测器
所用的具体统计量）；A3 经公平有界的、通过轻量后处理（针对已部署检测器优化的重加权/重排序/解码校准）的最优
响应；A4（上层）参数高效微调/蒸馏，依 GhostPrint，给出可伪装性上界。每一层的伪装算力都被计量为预算轴 h。

**3.5 双预言机博弈。** 审计方与提供方在每个预算单元内交替给出**留出集上的**最优响应：每个审计方回合针对当前
可行伪装集优化；每个提供方回合搜索一个符合账本约束、最大程度降低检测能力的策略。候选策略在训练划分上选出、
在互不相交的留出划分上只评一次，因此被报告的最优响应绝不会在其自身评估片段上被选中。一条预注册的重启/收敛
规则与截断的策略空间使交替保持有界；若收敛未被认证，我们报告最后一个稳定前沿并加以标注，而非宣称已达不动点。

**3.6 隐藏成本账本。** 一个共享的计量账本记录查询、输入/输出 token、加速器秒、延迟、调优评估、训练样本、
存储与人时，在预注册情景下把经常性与摊销资源换算为统一美元口径，同时把 p95 延迟保留为显式可行性约束（而非
折叠进标量成本）。对一份配对工作负载，设 C_T、C_D、C_M 分别为参考、未改动降级、了解检测器的伪装三者每次
成功请求的成本，则毛节省为 S = C_T − C_D，**侵蚀比**为 E = (C_M − C_D)/S：E = 0 表示未改动的降级，0 < E < 1
表示保留了部分节省，E = 1 为盈亏平衡，E > 1 表示伪装的花费超过了降级所节省的。仅当 S 的置信下界越过 C_T 的
预注册比例时才报告 E；否则标记为不可判定，并报告绝对增量 C_M − C_D 与残余 C_T − C_M。

## 4. 结果一——隐藏一次降级有多难？（R2）

*（结果部分只报告测得的曲面。）* 我们从最贴近消费者的情形——档位降级 R2 及其崩溃——切入，而非从测试床切入，
以便让有区分度的结果最先出现。

**4.1 噪声下的基线可检测性（RQ1）。** 面对非自适应提供方（A0），我们报告 R2 在校准噪声扫描下检测能力随查询
数的变化。预期结构：在低噪声下检测能在实用查询数上奏效，但对 R2 而言随着噪声上升检测能力急剧下降，因为量化/
蒸馏兄弟模型在输出分布上贴近 m0，被服务模型之差趋近于噪声包络。该面板在任何对手入场前先确立审计方工具是可靠
的（G2 成立）。

**4.2 伪装成本前沿（RQ2，核心）。** 固定查询预算，我们报告 R2 检测能力随伪装预算 h 的变化，按对手层 A0–A4
分别给出。这是本文的"招牌"展品（图1，左下）。三条可证伪的结构性主张：
- **成本悬崖（H1）。** 很小的伪装预算即可把 R2 检测能力压到实用审计阈值之下（例如 10k 查询下 D < 0.5）——是
  一个平台断崖，而非平缓退化。
- **前沿非平凡（H0 零假设）。** 若检测能力在整条阶梯上、直至很大的 h 都保持 ≥ 0.8，则行为审计对 R2 并不易被
  伪装、立场被证伪、此处证明是可选的——一个可发表的反转（证伪条件 F2）。

## 5. 结果二——不对称性与噪声掩蔽界

**5.1 R2 与 R1 的不对称性（RQ3）。** 对 R1 跨族替换运行同一流水线，我们检验 **R2 是否比 R1 更便宜伪装**
（H2）：消费者保护情形恰恰是薄弱情形，因为兄弟模型本就贴近。若 R2 并不比 R1 更便宜，则 H2 错误（证伪 F3），
"消费者情形即薄弱情形"的主张不成立。

**5.2 噪声掩蔽界（RQ4，扩展）。** 在核心数据上的附加分析，不引入新对手：是否存在一个现实噪声水平，使 R2 降级
即便在 A0 下、在任何实用查询预算内都不可检测？预期结构：存在一个掩蔽阈值，在此降级效应量落入噪声包络之内
（H3）。此处若为零结果（高噪声下降级仍可检测，F4）本身也有信息量——它把论证收紧为"是对手、而非噪声，才是
问题所在"。

## 6. 结果三——隐藏的经济学（RQ5）

对经济上合格的降级（毛节省 S 被解析到预注册下限之上），我们报告为使对手在收敛后的审计方面前达到目标漏检率
所需的侵蚀比 E。假设：达到高漏检率会把 E 推到 ≥ 1——伪装吞噬了驱动降级的节省（H4）。若伪装几乎免费
（E ≈ 0，F5），则"证明物有所值"的经济论证被削弱，我们会如实说明。我们还报告次级能力代价：一个被迫模仿 m0
的降级模型，可能恰恰在降级本欲省成本的那类基准任务上损失性能——这是测得的，而非断言的。

## 7. 含义——决策地图（论证所得，非测量所得）

*（本节是对 §4–§6 的解读，而非新的测量；每条区域边界都内联标注其阈值参数。）* 把测得的前沿映射到（噪声 ×
对手预算）平面（图1，右下），得到三个区域：**行为审计足矣**（低噪声、低 h——便宜可查，披露规范可自执行）；
**需要披露规范**（违规真实但检测不可靠，故治理需要一个验证基底）；以及**需要密码学/TEE 证明**（在现实噪声下
便宜可伪——即"模型服务的 TLS"区域）。我们的主张是：最贴近消费者的点——在校准噪声下、面对适度了解检测器预算
的 R2——落在"需要证明"的区域。这把 Cai 等（2504.04715）从"TEE 是必需的"锐化为"TEE 在前沿的**此处**是必需的、
在**彼处**若无披露规范则不充分"，并补上治理提案（2604.27789）预设却未提供的可执行性地图。我们用一个合理的
第三方审计预算（例如 10k 查询）作为决策阈值，并展示结论在一系列阈值上稳健。我们不设计证明协议本身；那是含义
与未来工作。

## 8. 证伪条件与效度威胁

**证伪条件。** F1（G2）：若无检测器能在干净 R1 对上达到 0.8 能力，则该库有缺陷——是关卡失败，而非发现。
F2：R2 能力在整条阶梯上保持 ≥0.8 ⇒ 立场被证伪（证明可选）。F3：R2 不比 R1 更便宜 ⇒ 不对称性主张错误。
F4：高噪声下 A0 仍可检测降级 ⇒ 无噪声掩蔽界（有信息量的零结果）。F5：伪装免费 ⇒ 经济论证被削弱。

**威胁。** *对手稻草人*——通过按层报告的 A0–A4 阶梯（呈现趋势而非单点）、Kerckhoffs 公平界、以及开源伪装器
缓解。*注入噪声不真实*——通过 G1 校准到实测商业 API 方差、完整扫描、以及附带协议的附录缓解。*开源权重测试床
与闭源前沿服务之别*——范围上承认；可迁移的主张是前沿的**形状**（悬崖、不对称），而闭源服务只会增添不透明度、
强化证明结论。*节省很小时侵蚀比失定义*——合格性规则与"不可判定"标注防止近零分母；若中心情形不合格则改报绝对
增量。*双预言机收敛性*——附带一个重启回合（F2 式稳定性检验）报告，若未认证则加以标注。*良性漂移与对抗性替换*
——明确划界：本文测量对抗性替换；良性模型漂移与变更日志对齐属另一条工作线，不在此范围内。

## 9. 结论

对 LLM 服务身份的可靠外部证明，不能止步于展示某个静态指纹能在干净解码下分开两个检查点。真正的问题是：在
生产级噪声与蓄意模仿之下，行为证据是否仍具区分度，以及隐藏是否保留了提供更便宜检查点所带来的任何经济优势。
我们持这样的立场：在最贴近消费者的情形下它并不保留；并且我们予以支撑——一条测得的检测—伪装成本前沿、其
不对称性与成本悬崖、一个噪声掩蔽界、以及一份收益侵蚀核算，映射成一个决策，告诉从业者一次廉价外部审计仍能
抓住哪些违规、哪些则需要密码学证明加披露规范。若前沿"温和"，则立场被推翻、行为审计足矣——仍是一个与安全
相关的结果。无论哪种，该领域都获得了 TEE 必需论与治理论都预设却均未测量的可执行性基底。
