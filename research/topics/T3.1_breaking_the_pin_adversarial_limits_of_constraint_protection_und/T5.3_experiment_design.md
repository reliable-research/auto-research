# T5.3 Experiment Design Spec (standalone protocol — executable without the paper)

## Global commitments
- Estimand: per-category Δκ = κ_HH (Fleiss) − κ_VH (Cohen, non-abstained items vs human majority). CIs: cluster bootstrap over cards, `\p<B>` resamples.
- Verdict order (mechanical): (1) reference-unstable if κ_HH < `\p<KF>` (anchor: Landis–Koch 0.40), decided verifier-blind → report κ_HH only, P/R undefined; would-have-been P/R to diagnostics appendix only. (2) automatable iff Δκ CI-upper ≤ `\p<BAND>` ∧ P ≥ `\p<P*>` ∧ R ≥ `\p<R*>` ∧ coverage ≥ `\p<C*>`. (3) human-required iff Δκ CI-lower > `\p<BAND>` or floors fail with usable reference. (4) else inconclusive (reported).
- Robustness columns (never revise verdicts): percent agreement, PABAK.
- Thin cell rule: < `\p<MIN_CELL>` pairs → inconclusive by rule.
- Multiple comparisons: Holm across the category family for all McNemar tests, α = `\p<ALPHA>`.

## Datasets & baselines (with justifications)
- Corpus: `\p<N>` cards / `\p<M>` pairs / `\p<R>` repos (≥3 architecture styles — layered, hexagonal, plugin; ensures structural rules exist to author against) / `\p<A>` agents `\p<AGENT_LIST>` (default configs; heterogeneity is an external-validity gate, not a comparison axis).
- Patch provenance: natural violations (agent never sees card) + induced variants (task chosen so straightforward implementation conflicts with card; card still never shown). Report natural-violation rate `\p<NVR>`. No hand-edited patches.
- Baselines: regex/keyword floor (compiled from card surface text); human-majority ceiling; single-shot LLM-judge control **budget-matched on tokens** (primary), matched call-count as robustness.

## Phase 0 — Pilot gate (run before anything scales)
Two categories (API constraints ↔ structural; design principles ↔ intent). 10 cards, 40 pairs, 3 annotators from pinned pool `\p<POOL>`, regex floor, frozen CARDCHECK.
PASS iff, mechanically and without manual patching: per-category κ/P/R emitted; κ-floor sensitivity check runs; under-encoding double-coding runs; κ_HH usable in ≥1 category.
Also at pilot: derive `\p<BAND>` from the pilot κ_HH dispersion and WRITE THE DERIVATION INTO paper.md before the confirmatory run.

## Phase 1 — Tuning (exploratory, declared)
CARDCHECK prompts/thresholds/routing tuned only on `\p<TUNE_FRAC>` of cards, stratified by category. Freeze = hash of prompts+thresholds+router, published in artifact.

## Phase 2 — Confirmatory run (single execution)
Frozen CARDCHECK + control + floor over all held-out pairs. Annotation: 3 independent labels/pair (binary + confidence + one-line rationale); randomized order; no same-repo consecutive items; no annotator labels a repo they contributed to; annotators never see verifier output.

## Per-RQ protocol
- RQ1/H1 (criteria 1–2): ≥ `\p<K_struct>` structural categories Δκ CI-upper ≤ `\p<BAND>` AND intent categories Δκ CI-lower > `\p<BAND>`. Test: bootstrap CIs; no NHST needed — criterion is CI-position.
- RQ2/H2 (criteria 3–4): floors P/R/coverage; F1 gain over regex floor `\p<F1_gain>`; CARDCHECK vs token-matched control by McNemar per usable category, Holm-corrected.
- RQ3/H3 (criterion 5): recompute partition at `\p<KF>`±0.05 → automatable set invariant, boundary shift ≤ `\p<SHIFT>`; merge-2-most-similar + split-largest → report every verdict-class migration.
- RQ4/H4 (secondary): double-code under-encoding type {quantifier scope, implicit boundaries, cross-file coupling} on all HR/RU cards; report distribution `\p<DIST>` + coder κ `\p<KD>`; pre-registered demotion to qualitative discussion if `\p<KD>` < `\p<KF>`.
- Routing yield: review-load reduction `\p<RR>`% at retained recall ≥ `\p<RC>`% on our mix `\p<MIX>`; release per-category routing table (category → verdict → Δκ → P/R where defined) so savings recompute per reader card-mix.

## Falsifiers & committed wording
(a) all categories similar Δκ → category axis not where operationalizability lives → stop. (b) intent reaches band → "more automatable than believed" paper. (c) too many RU → format-level under-encoding finding. (d) automatable set band-sensitive → granularity-bound finding.

## Sample-size rationale
`\p<MIN_PER_CAT>` cards/category set so the bootstrap CI half-width on Δκ ≤ `\p<BAND>`/2 at pilot-estimated variance; derivation in artifact notebook.
