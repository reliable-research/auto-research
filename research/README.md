# Research archive

This directory preserves the source portfolio as research material. It contains
45 B/T/H topic studies, four position-paper folders, and a separate
`loop_r1_worldmodel_explorations` collection. The source records date primarily
from August 2026; their venue windows, novelty assessments, and proposed results
are historical and need fresh checks before use.

| Entry | Contents |
|---|---|
| [topics/README.md](topics/README.md) | Topic index and original tier assignments |
| [portfolio_2026-08.md](portfolio_2026-08.md) | Audit rationale, active leads, holds, and retirements |
| [position_paper_pipeline_2026-08.md](position_paper_pipeline_2026-08.md) | Position-paper candidates and evidence requirements |
| [positions](positions) | Position-paper discussions and drafts |
| [topics/loop_r1_worldmodel_explorations](topics/loop_r1_worldmodel_explorations) | Additional proof-learning ideas and paper drafts |
| [overview.md](overview.md) | Original research map and context |
| [readme_draft.md](readme_draft.md) | Current portion of the original working analysis |

Topic roots retain seeds and specifications; their `discussion/` folders retain
refinement traces, reviews, experiment designs, Markdown/LaTeX drafts, translations,
bibliographies, and reference digests. A proposal or draft is not a measured result.
Keep dated evidence and review records even when a topic has been retired.

Generated PDFs, packaged archives, bitmap presentation exports, LaTeX build files,
and backup snapshots are omitted. Links to omitted artifacts point to the pinned
source revision where possible. The original idea corpus mentioned in older notes
was not present in either source snapshot and has not been reconstructed here.

Start new work through the [bundled skills and commands](../docs/SKILLS.md), and
use a separate ARA project for generated runs. [Migration notes](../docs/MIGRATION.md)
record source revisions and cleanup decisions.
