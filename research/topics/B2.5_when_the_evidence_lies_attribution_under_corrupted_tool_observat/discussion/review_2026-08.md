## 2. Feasibility (se-paper-reviewer lens)

- **Power arithmetic: sound.** RQ3's discordant-pair gate (≥72 pairs ≈ 0.8 power at 5 pp,
  per `experiment_design.md`'s exact-binomial computation) and RQ6's per-cell bands
  (n≥120 scored / 50–119 INCONCLUSIVE / <50 descriptive) are correct and pre-registered.
  Verified no inconsistency between draft and `experiment_design.md`.
- **Kill-tests: present.** RQ2 (yield pilot, 100+100 candidates), the sham-injection +
  label-shuffle placebo gate, and the premise-collapse branch (m_A(D_overt) > 40%) form a
  real go/no-go lattice before scale-up spend.
- **[moderate] F6 — no run-count/cost accounting anywhere in the draft.** Scale-up implies
  ≥300 verified × 3 arms × 3 frameworks = 2,700 verified trajectories; at the RQ2 yield floor
  (20%) with twin replays this is ≈13,500 gate-passing candidates ≈ 27,000
  corrupted-plus-twin executions before any attribution scoring (5 methods + paired license
  re-runs). No budget statement, no descope order. Fleet precedent (B1.2 F5, B2.1 review §2)
  treats this as moderate. **Fixed:** pre-registered run-budget + descope-ladder paragraph
  added to Experimental Setup (arithmetic derived only from already-stated design targets; no
  fabricated results).
- **[minor] F7 — GAIA twin-replay determinism.** GAIA tasks touch live web content; the twin
  replay's "holding seed and temperature fixed where the framework allows" does not pin the
  environment. Partially mitigated *by design*: the sham-injection placebo (identity mutation
  through identical machinery) will catch replay nondeterminism as a non-null placebo and
  invalidate the run rather than contaminate it. Recommendation (no text change): cache/frozen
  snapshots for GAIA tool backends at build time.
- **[minor] F5 — checker-validity threat.** V(τ) is the ground-truth signal for the flip
  criterion; Hardening Agent Benchmarks (16% of 1,968 tasks hackable) and SWE-Marathon
  (13.8% rollouts reward-hack) show programmatic checkers have exploitable error modes. B2.5's
  agents are non-adversarial and AgentDojo checkers are state-based, so exposure is low;
  logged as a threats-to-validity candidate for the eventual paper, no spec change.
