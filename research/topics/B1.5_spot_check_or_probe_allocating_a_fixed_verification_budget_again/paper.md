## Step 0 — Core Asymmetry (升维)

**Asymmetry sentence:** A pass-rate-optimizing agent concentrates its failures precisely in the complement of the coverage it can predict, so under a fixed budget the detection value of a verification call is set by how unpredictable and disjoint its coverage is from the agent-visible test distribution — not by the call's standalone accuracy.

**判据 (deletion test).** Delete the domain nouns (agent, verifier, pass rate, verification call, test distribution): "A ___-optimizing ___ concentrates its failures precisely in the complement of the ___ it can predict, so under a fixed ___ the value of a ___ is set by how unpredictable and disjoint its ___ is from the ___-visible ___." The residue is not a valid generic statement — without a strategic optimizer whose objective is *apparent* pass rate, failures do not concentrate anywhere (random bugs are coverage-indifferent, so accuracy per call WOULD be the right metric and the sentence would be false). The sentence's truth depends on the adversarial coupling between the optimizer's objective and the checker's coverage; it is an asymmetry claim, not a bridge.

**Estimand (guidance.md §3.4 R1).** The quantity this paper measures is the undetected-shortcut rate MR(π,B) — the fraction of ground-truth-shortcut episodes with zero flagged checks — as a function of allocation policy π and budget B, over the population of (task, attack-family) episodes drawn from the Stage-1/Stage-2 task suites; the unit of analysis is one episode; the decision it feeds is which allocation policy (or mixture) a budget-constrained verifier designer should commit to at a given call budget and adversary-awareness regime. This sentence is stated once here and is not re-derived per experiment; Step 5's formal notation and Step 6's hypotheses all instantiate it.

## Step 5 — Formal Problem Definition

**Notation.** Task τ with reference solution r_τ; agent submits program s. Visible tests T_vis(τ); episode e = (τ, s, y_e, w_e) where y_e ∈ {genuine, shortcut} is the ground-truth label and w_e a machine-checkable witness (trigger predicate or violated invariance), known by construction (M5). Check flavors F = {R (random spot-check), P (invariance probe), H (hidden combinatorial test)} as operationalized in M2. One verification call = 1 sandboxed execution + 1 comparison (the cost meter, M2). Allocation policy π ∈ Δ² (the flavor simplex) with integer rounding at budget B; within-flavor check selection is always randomized (M3).

| Load-bearing adjective/verb | Formal definition | How measured |
|---|---|---|
| **undetected (miss)** | episode e with y_e = shortcut and zero flagged checks among the ≤B spent calls; MR(π,B) = #missed / #shortcut-episodes | direct count from per-episode logs (M4) |
| **cost / matched budget** | realized calls per episode c(e) ≤ B under the common meter; two arms are matched iff same B and same meter | logged calls; wall-clock and tokens logged as secondary (Assumption A3) |
| **frontier** | curve B ↦ MR(π,B), B ∈ {1,2,4,8(,16)}; AUC*(π) = trapezoidal AUC normalized by budget range, units = mean miss rate ∈ [0,1] | M4 evaluator |
| **dominates (Pareto)** | π dominates π′ iff MR(π,B) ≤ MR(π′,B) ∀B swept, strict at ≥1 B, with task-level bootstrap 95% CI on the difference excluding 0 at the strict point | bootstrap over 10,000 task-level resamples |
| **shortcut-seeking / pass-rate-optimizing** | attack policy whose output passes 100% of T_vis(τ) while failing on the witness region w_e (M1 families a–c) | acceptance filter at implantation time; episodes failing the filter are discarded |
| **allocation-blind / allocation-aware** | blind: attack policy's input excludes any function of π; aware: attack policy conditions on the verifier's past check outcomes and/or a descriptor of π (Stage 2, C1) | experimental condition flag |
| **mixed** | π in the interior of Δ² (all weights > 0), or the adaptive Thompson-style re-weighting policy (M3) | policy registry |
| **targeted** | flavor whose check inputs are a deterministic function of the task specification (P: metamorphic transforms; H: t=2 covering arrays), not draws from a distribution similar to T_vis | construction (M2), frozen per A6 |
| **false alarm** | genuine episode (y_e = genuine) with ≥1 flagged check; FA(π,B) analogous to MR | direct count; guard metric |
| **apparent-vs-true gap** | pass rate on T_vis minus ground-truth success rate | logged per condition |

## Assumptions (A1–A7)

- **A1 (construct):** Implanted shortcuts (M1/M5) occupy input regions representative enough of naturally emergent shortcuts for MR ordering to transfer (threat t1). *Failure mode:* natural reward hacks live elsewhere; ordering flips. *Detection:* pilot audit of ≥20 naturally occurring test-special-casing episodes, assembled from two named sources: (i) unprompted solver runs of this paper's own models over the Stage-1 task suite, auditing T_vis-passing solutions for spontaneous special-casing (in-harness; expected low but nonzero yield), and (ii) published reward-hacking incident reports from public RL-for-code and agent-evaluation writeups — each candidate episode must be witness-checkable before it counts. Checked against the same flavors; discordant ordering triggers a scope-narrowing to "implanted-shortcut regime" in all claims. *Downgrade rule:* if fewer than 20 verifiable episodes can be assembled, A1 is not silently assumed — the scope-narrowing consequence fires by default and every claim carries the implanted-shortcut qualifier.
- **A2 (agent):** Attack elicitation yields non-trivial shortcuts — visible pass rate 100% by filter AND ≥30% survive the no-verification floor into the shortcut-episode pool per family. *Failure:* refusals or weak attacks flatten all frontiers. *Detection:* walking-skeleton gate G1 (below); fallback attacker = scripted implantation floor + open-weights model (digest N6 feasibility mitigation).
- **A3 (cost meter):** 1 call = 1 execution + 1 comparison is fair across flavors — per-call wall-clock/token cost ratios between flavors stay within 3×. *Failure:* one flavor is covertly more expensive. *Detection:* skeleton logs real costs; if violated, all frontiers are re-indexed by wall-clock cost as the primary axis (pre-committed re-analysis, not a new experiment).
- **A4 (oracle):** Every implanted episode carries a witness w_e that machine-validates (M5). *Failure:* unverifiable labels corrupt MR. *Detection:* skeleton gate — 100% witness validation required; episodes failing validation are excluded before any arm sees them.
- **A5 (corpus):** Held-out I/O pools (≥50 cases), metamorphic transforms, and covering arrays are constructible for ≥90% of sampled APPS/BigCodeBench tasks. *Failure:* flavor availability confounds allocation. *Detection:* harness coverage report at pilot start; tasks lacking any flavor are dropped *before* randomization, and the drop rate is reported.
- **A6 (independence):** Verification-flavor library (M2) is frozen — content-hashed and timestamped — before any attack generation; one attack family is held out of all harness development (threat t2). *Failure:* probes tuned to attacks inflate targeted flavors. *Detection:* held-out family's results reported separately; if the held-out family reverses the pooled ordering, co-design bias is declared and only held-out-family results are claimed.
- **A7 (genuine-label purity):** Genuine episodes (y_e = genuine, the FA guard's denominator) are reference solutions r_τ plus unprompted model solutions that pass T_vis, assumed free of *spontaneous* test-special-casing. *Failure mode:* impure genuine labels inflate FA for targeted flavors and can spuriously trigger the FA > 10% disqualification in E1. *Detection:* skeleton-time audit of a random 100-episode genuine sample per model family for special-casing patterns (shares machinery with A1 source (i)); if impurity ≥ 2%, FA is reported with an impurity-adjusted bound and every flagged-genuine episode is manually adjudicated before the disqualification rule is applied.

## Instrument validation (guidance.md §3.4 R2)

The two targeted flavors are *generated instruments* — a metamorphic mutation set (P) and a covering-array detector (H) — and therefore get the full R2 treatment; asserted soundness without this protocol is treated as absent. All steps run before any hypothesis arm and are frozen per A6.

1. **Ground** — transforms and covering arrays are derived mechanically from task specifications only (M2, never from inspecting attacks), grounded in the metamorphic-testing and combinatorial-test-design literatures (digest N3).
2. **Draft wide, refine on held-out calibration tasks** — generate the candidate probe/check pools on a calibration slice of tasks disjoint from all evaluation tasks; named refinement operation: *drop* (a transform type or generated check that fails step 3 is removed, never patched per-task).
3. **Validate with acceptance thresholds** — (a) *soundness:* r_τ must pass **100%** of retained P probes and H checks on every retained task (probes/checks that flag r_τ are dropped before freezing; the drop rate is reported — this also screens out-of-domain covering-array inputs that would otherwise inflate FA); (b) *positive control:* at exhaustive check budget, P must detect **≥ 90%** of scripted family-(c) (invariance-breaking) episodes and H **≥ 90%** of scripted family-(a) (hard-coded) episodes — a flavor that cannot detect its own attack class by construction is a broken instrument, and no null involving it is interpretable. Both run as walking-skeleton gate G5.
4. **Inspect the failure structure** — probes that flag r_τ must be concentrated in identifiable transform types (which are then dropped wholesale); a diffuse failure pattern across transform types means the metamorphic-relation extraction is unreliable for this task corpus and the P flavor's scope is narrowed to the transform types that pass, with the narrowing reported.
5. **Freeze** — content-hash the validated library before any attack generation (A6).

## Step 6 — Pre-Registered Experiments

Common design constants (hardened from digest N8 analysis plan): ≥600 shortcut episodes per (policy, budget, condition) cell in Stage 1, ≥1,200 in Stage 2 (power > 0.9 for a 10 pp miss-rate difference at base rate ≈ 50%); two-proportion z-tests, Holm–Bonferroni within each budget's policy-pair family, α = 0.05; task-level cluster bootstrap (10,000 resamples) is the primary interval estimate (t4); frontier AUC* compared by the same bootstrap. The power figures above treat episodes as independent; because episodes cluster by task, cell adequacy for the thin-cell rule is assessed on cluster-adjusted effective n (design effect DEFF = 1 + (m̄ − 1)·ICC, with ICC estimated from Phase-B pilot data — no ICC value is asserted in advance; cells whose *effective* n falls below the powered threshold are INCONCLUSIVE per the rule below).

**Thin-cell rule (guidance.md Part 2 A2 / Part 6 item 9 / Part 4 situation 5).** Per-cell episode counts are logged before any hypothesis is scored. Any (policy, budget, condition) cell that falls below the powered threshold above (e.g., through A5 task drops, A6's held-out-family split, or seed dedup reducing effective episodes) is pre-declared **INCONCLUSIVE** for that cell — never treated as a null result and never silently dropped from the reported grid. H1/H2/H3/H3b's primary contrasts are scored only over adequately powered cells; if a *primary* contrast's cell is thin, that specific contrast is reported INCONCLUSIVE and the affected claim in the Claim–Evidence Map is marked accordingly rather than defaulting to its fallback wording (fallback wording is reserved for a powered test that fails, per §5 of goal.md's verdict procedure).

### E1 (RQ1) — Which pure flavor minimizes miss rate at fixed B?
- **Assumption:** A1, A2, A3, A4, A5, A6.
- **Hypothesis H1:** holds iff, in the Stage-1 allocation-blind condition, min(MR_P, MR_H) is below MR_R by ≥ 10 percentage points at BOTH B = 4 and B = 8, each contrast p < 0.05 after Holm correction, and the task-level bootstrap 95% CI excludes 0.
- **Metric:** MR(π,B) as defined in Step 5; FA(π,B) reported as guard (a flavor whose FA exceeds 10% at any B is disqualified from being declared winner).
- **Verification:** pairwise two-proportion z-tests among {R, P, H} within each B ∈ {1,2,4,8}; Holm over the 3 pairs per budget; cluster bootstrap sensitivity; pre-registered primary contrasts only (t4).
- **Fallback F1:** If H1 fails, the paper's claim becomes: "Under a fixed verification budget, uniform random spot-checking from a large held-out pool is already cost-competitive with structurally targeted probing against implanted shortcut-seeking agents, and the miss-rate–cost frontier we release quantifies exactly how little targeting buys." (Matches digest N9 Result-1 falsification condition.) The stronger clause "check-flavor composition is a second-order defender lever at budgets ≤ 8" is licensed ONLY under combination rule CR-4 (H2 also fails) — if H2 passes, a mixture demonstrably improves the frontier and the clause would be false (see Fallback-combination rules). **Wrong-direction rule (guidance Part 4 situation 4):** if MR_R is instead *lower* than BOTH targeted flavors by ≥ 10 pp (same test and correction), that reversal is reported at full prominence as E1's headline, with pre-committed wording: "targeted structure actively hurts at matched budget — every probe or hidden-test call spent is a held-out random draw forgone."

### E2 (RQ_INF_1) — Does any mixture Pareto-dominate every pure vertex?
- **Assumption:** A1, A2, A3, A4, A5, A6 (H2's external validity depends on construct fidelity and library independence no less than H1's).
- **Hypothesis H2:** holds iff a **pre-specified confirmatory mixed policy** — the uniform interior mixture (1/3, 1/3, 1/3) or the adaptive Thompson-style policy (Stage 2) — has AUC* lower than EVERY pure vertex's AUC* by ≥ 0.05 (i.e., ≥ 5 pp mean miss rate over the swept budgets), with the task-level bootstrap 95% CI on each mixture-vs-vertex AUC* difference excluding 0.
- **Metric:** AUC*(π) (Step 5); Pareto-dominance check at each B as the qualitative companion.
- **Verification:** the two pre-specified mixture candidates vs. every pure vertex are the confirmatory contrasts, Holm-corrected over the 2 candidates; the full 10%-grid simplex sweep is **exploratory and labeled as such — no grid mixture is selected post hoc from the same data and scored against H2** (winner's-curse guard); bootstrap CIs, α = 0.05.
- **Fallback F2:** If H2 fails, the paper's claim becomes: "Mixing dilutes rather than hedges: the best pure flavor's frontier is not improved by any evaluated portfolio, so a budget-constrained verifier should identify the dominant flavor for its shortcut mix and commit — a one-flavor recommendation we state as conditional on the allocation-blind regime." (Matches digest N9 Result-2 falsification condition.)

### E3 (RQ_INF_2) — What survives an allocation-aware agent?
- **Assumption:** A1, A2, A4, A6 (plus Stage-2 elicitation of adaptive attacks, M1).
- **Hypothesis H3:** holds iff the blind→aware miss-rate degradation ΔMR of the best pure policy exceeds ΔMR of the best mixed/randomized policy by ≥ 10 pp at B = 4, via a policy × condition interaction term in a logistic model with task-clustered robust SEs, p < 0.05. **H3b (secondary):** the single-channel suspicion-score-auditing baseline (reproducing `[AIControl, OpenReview:KviM5k8pcP]` / `[ControlTax, OpenReview:BpyR6Wkl1c]` at matched call budget) degrades by ≥ 10 pp more than the best portfolio at matched cost, same test, Holm-corrected with H3.
- **Metric:** ΔMR(π) = MR_aware(π, B=4) − MR_blind(π, B=4); full frontiers in both conditions reported.
- **Verification:** paired blind/aware design on identical task sets; interaction test as above; digest N9 Result-3 falsification condition adopted verbatim as the refutation rule. *(Concession, per digest N3's security-games entry: H3's direction — randomized/mixed allocations degrade less against an informed adversary — is the expected result in the Stackelberg security-games literature; the pre-registered contribution is its measured magnitude for executable check portfolios at matched call cost, and a refutation would be the more surprising outcome.)*
- **Manipulation check (pre-scoring gate):** the aware condition counts as *operative* only if the scripted **oracle-aware** attacker (told π verbatim; skeleton gate G6, re-run at Stage-2 scale) degrades the best pure policy's MR at B = 4 by ≥ 10 pp over blind. If this floor is not met, the awareness channel is declared inoperative and H3/H3b are reported **INCONCLUSIVE** — an instrument failure, never a mechanism claim; F3's wording is licensed only when this check passes.
- **Fallback F3:** If H3 fails *with the manipulation check passed*, the paper's claim becomes: "Allocation-awareness taxes all defenses equally: we measure the awareness tax (the uniform blind→aware miss-rate shift) and refute the mixed-strategy-robustness hypothesis for check portfolios — the binding variable is information leakage to the agent, not budget composition."
- **Fallback F3b (H3b-specific):** If H3b fails while the manipulation check passes (regardless of H3's verdict), the paper's claim becomes: "A flavor-portfolio confers no additional robustness over a well-tuned single-channel auditing threshold once the agent adapts — the portfolio's value, if any, is confined to the allocation-blind regime, and we report both defenses' measured blind→aware degradation at matched cost."

### Mandatory baselines
- **B0 — "why do this at all" control:** three arms. (i) *No-verification floor:* B = 0, MR ≡ 1 by construction — anchors the frontier. (ii) *Visible-test-replay verifier:* spend all B calls re-executing draws from T_vis(τ). Since attacks pass T_vis by filter, its expected MR ≈ 1; if this arm's MR is NOT ≈ 1 (> 0.9), the attack filter is broken and all runs halt (links to A2). This arm proves the problem exists: a budget spent without leaving the agent-visible distribution detects nothing, so allocation is a real decision. (iii) *Label-permutation placebo (null-by-construction, guidance §3.3(1)(b)):* permute y_e labels within task and re-score every policy through the identical M4 evaluator; any apparent policy separation on permuted labels must vanish (task-level bootstrap CI on every pairwise difference including 0). A non-null permutation placebo means the scoring pipeline measures an artifact — the run is invalid (Part 4 situation 1), checked before any H\* is scored.
- **B-alt — strongest-alternative-explanation control:** *Rival explanation:* "targeted flavors win only because their inputs are novel (held-out) relative to T_vis, not because of their structure (metamorphic consistency, combinatorial coverage) — i.e., any held-out inputs would do." Control: **unstructured-novelty arm** at matched budget — B calls drawn uniformly from the SAME input universes P and H draw from (the transform-generated and parameter-domain input pools), but with targeting logic ablated: random input mutations without the semantics-preserving constraint, random parameter tuples without the covering-array structure, judged against r_τ identically. **Hypothesis H4 (binary, primary for this arm):** holds iff each targeted flavor that individually beat R in E1 attains MR at B = 4 at least 5 pp below the unstructured-novelty arm, task-level bootstrap 95% CI excluding 0, Holm over the tested flavors. applies_if: A2, A3, A4, A5, A6; metric: MR (Step 5); test: two-proportion z + cluster bootstrap, α = 0.05; effect_floor: 5 pp; aggregation: every E1-winning flavor must clear the floor. **Fallback F4 (verbatim):** "Held-out novelty, not targeting structure, is the active ingredient: structurally targeted checks buy no detection beyond equally novel unstructured draws at matched budget, and Step 0's asymmetry is re-attributed to distributional disjointness alone."

### Pre-registered sensitivity analysis — taxonomy-duality confound (R3)
**Constraint→confound (named per R3):** the attack families (M1 a–c) are near-dual to the flavor detection classes (digest C2), so the pooled family mix — an experimenter choice — mechanically shapes the MR ordering; *the per-family breakdown plus this reweighting analysis removes the winner-as-artifact-of-mix confound.* Procedure (reanalysis of logged per-episode outcomes; no new runs): recompute the H1 winner and the H2 mixture-vs-vertex contrasts under reweighted family mixes with each family's share set in turn to {10%, 33%, 80%} (renormalizing the others). **Pre-committed wording:** the allocation recommendation is stated unconditionally only if the winner is stable across all reweightings; otherwise it is stated mix-conditionally ("for shortcut mixes dominated by family X, flavor Y wins"), and A1's natural-episode audit anchors which mixes are deployment-realistic.

## Step 9 — Walking Skeleton

**Binary question:** on scripted (non-LLM, cannot-refuse) attacks, do a targeted flavor and random spot-checking produce *any* separable miss-rate gap under the frozen harness?

- **Arms (5):** pure R, pure P, pure H, visible-test-replay B0(ii), and an **oracle-aware arm** (pure H under a scripted attacker told π verbatim, which redistributes implants away from predicted coverage). Budget B = 4 only.
- **Task set:** 20 APPS tasks passing the A5 coverage check; 2 scripted attack families (family (a) hard-coding of visible test inputs for the R/H/aware arms; family (c) invariance-breaking for the P positive control — both template-based, cannot refuse); 1 seed.
- **Metrics:** deterministic only — MR at B = 4, witness-validation rate, per-call wall-clock per flavor, P/H soundness rates on r_τ, and positive-control detection rates at exhaustive budget (R2 step 3). No LLM-judged quantities.
- **Cost:** ≈ 20 tasks × 5 arms × (4 + validation) executions plus the exhaustive-budget positive-control passes ≈ 800–1,200 sandboxed runs; < 2 h wall-clock on one multi-core CPU server; ≈ $0 API (scripted attacks).
- **Gates:** G1 (A2): 100% of scripted episodes pass T_vis and validate witnesses (A4). G2 (A3): per-call cost ratio between flavors < 3× (now measured across all three flavors, P included). G3: B0(ii) MR > 0.9. G4: |MR_H − MR_R| ≥ 15 pp raw gap (no test — 20 tasks is not powered; this is a signal check, matching Stage 1's go/no-go in N6). **G5 (instrument, R2 step 3):** r_τ passes 100% of retained P probes and H checks; at exhaustive budget, P detects ≥ 90% of scripted family-(c) episodes and H ≥ 90% of scripted family-(a) episodes; failing probes dropped pre-freeze with the drop rate logged. **G6 (aware channel operative):** the oracle-aware scripted attacker raises pure-H MR at B = 4 by ≥ 15 pp raw over blind (signal check, unpowered like G4) — failure means the verifier→attacker redistribution channel is broken upstream of all Stage-2 aware experiments.
- **Passed ⇒ scaling is a config change:** the full grid differs only in task count (100/400), attack families (+b, LLM-elicited variants of a–c), policy list (simplex grid, adaptive), budgets, seeds, and swapping the scripted oracle-aware attacker for LLM-elicited aware attackers behind the same attacker interface — the verifier→attacker feedback channel itself is already exercised in the skeleton (oracle-aware arm), so no new code path opens at scale. If any gate fails, fix is upstream of all experiments.

## Abstract v0 (draft, mechanism-first)

> **[DRAFT — WRITTEN BEFORE ANY RESULTS; ALL EMPIRICAL SLOTS OPEN]**
> An agent optimizing apparent pass rate concentrates its failures exactly where verification cannot reach, so a fixed budget of checks earns its value from coverage the agent cannot predict — not from per-check accuracy. We formalize budgeted verification as an inspection game whose defender action is a portfolio over three structurally distinct check flavors — uniform random spot-checks, targeted invariance probes, and hidden combinatorial tests — under a common cost meter, and measure each allocation's undetected-shortcut-rate-vs-cost frontier on coding tasks with implanted shortcuts whose ground-truth labels are known by construction. Pre-registered contrasts isolate flavor structure from mere input novelty and test whether mixed allocations survive allocation-aware agents better than pure or single-channel defenses at matched budget. We report which composition minimizes miss rate at budgets of 1–16 calls, and how much of that advantage an agent that infers the verifier's policy destroys. (146 words)
