# 在场不等于合规：测量约束固定在规模化时何时开始适得其反

> 由 `pipeline.md` 中六个已确认的阶段产出汇编而成，已通过品味审计（`taste_audit.md`：🟢）与评审（`stage_review.md`：两条 REVISE 发现已应用——见下文）。状态：**规格说明 / 论文草稿——尚未运行任何实验。** 下文所有数字均为预注册的设计目标，而非实验结果。

## 摘要

大型语言模型（LLM）智能体正被要求遵守越来越大的常驻约束集（standing constraint sets）——安全规则、用户偏好、组织政策——而确保这类智能体"看到"每条规则的默认工程做法是固定（pinning）：在每一轮对话中逐字重复完整的约束集。我们指出，这一默认做法建立在一个未经检验的不对称性之上：固定一条约束的 token 成本随约束数量线性增长，而真正为遵守每条约束付费的注意力预算（attention budget）却不会随之增长——因此，保证规则在上下文中"在场"（presence）的做法并不能保证对它的合规（compliance），而且当前实践中没有任何东西定位出这一鸿沟开始付出代价的临界点（如果存在的话）。我们构建了一个约束数量扫描测量框架（sweep harness），将约束数量与原始提示长度、适用性密度（applicability density）解耦；直接对照任务成功率来测量完全固定的 token 开销，以定位（或排除）一个断点（breakpoint）；评估一族预算封顶、按步骤条件化的选择性固定策略（selective-pinning policies）——包括一个与相似性选择器对照测试的适用性感知选择器——并以随机预算下界作参照；同时用经人工校准的双模式违规检测器（dual-mode violation detector）为每条违规率曲线把关。我们报告当约束数量从个位数扩展到数百条时，完全固定的 token 开销在何处（如果存在）开始侵蚀任务成功率，以及一个有界预算的选择策略能否以远低于该成本的代价守住违规率底线。

## 引言

生产环境中的 LLM 智能体如今被要求同时遵守数百条常驻规则。航空与零售政策客服智能体、企业副驾驶（copilot）与个人助理，均须遵守日益累积的安全约束、组织政策与用户偏好——不是一两条，而是可能数百条须在多轮任务全程同时成立的常驻规则。对"如何确保智能体不忘记规则"这一问题，默认的工程答案是固定（pinning）：把每条约束逐字粘贴进每一轮的上下文窗口。它实现廉价、易于推理，并在实践中被当作安全默认，而非一个开放的实证问题。

然而，没有任何证据表明这个默认修复——固定——会随着规则数量增长而持续有效。固定以随约束数量线性增长的 token 代价购买约束在上下文中的*在场*，但对任一约束的合规是从一份固定的每轮注意力预算中支付的，而每一条共驻约束都会稀释这份预算。这两种"货币"并不必然同向变动：一条规则可以在每一轮上下文中完美在场却仍被违反——如果共驻规则的绝对数量降低了模型对任何单条规则的忠实度，或者不断膨胀的约束块本身开始挤占任务成功所需的 token。对多轮智能体情境中的常驻规范性约束而言，这两种失效模式是否真的发生——若发生，在什么约束数量、以什么 token 代价、带来什么违规后果——从未被联合测量过。

现有最接近的工作从相邻但不同的角度逼近这一空白。多约束指令遵循方向的工作（如 RECAST）通过训练模型并挖掘验证奖励来提升模型能同时*满足*多少条要求，在领域上与本问题最接近，但它测量的是满足度，而非承载这一约束集的 token 成本。受控认知负载基准方向的工作（如 CogniLoad）在方法上最接近——它已将干扰项密度、序列长度与任务复杂度解耦为可独立调节的因子，使性能退化可以归因于单一维度而非多维混杂——但它只被应用于事实性与推理性材料，从未用于一组以违规（而非答错）为关注结果的常驻规范性规则。一个并行的 2025 年末–2026 年集群——面向长程智能体的可学习上下文管理、有界记忆测试床、面向多约束遵循的事后重放训练——对进入智能体窗口的内容做预算控制，或提升被满足的约束数量，但同样既未对承载一套常驻规范集的 token 成本定价，也未在规模化下测量其违规后果（见相关工作的并行工作段落）。无论最近的先行工作还是这一并行集群，都没有确立不断增长的约束数量本身——而非更长的提示或更难的任务——是否、以及在何处降低智能体的合规性。

把这一空白转化为可测量的问题会带来其自身的困难。任务成功率随约束数量增长而下降的任何观测，天然与"固定更多约束也意味着更长的提示"纠缠在一起，因此若不在实验上将二者分离，归因于"约束数量"的效应完全可能只是原始提示长度的伪影。哪些约束在给定步骤真正生效，是一个依赖状态与任务、须在每一轮重新裁决的问题，而非可假定由相似度检索捕获的静态属性，因此仅基于语义相关性的选择策略可能出于与语义无关的原因选错子集。三个关键量——违规率、token 开销、任务成功率——无法坍缩为一个诚实的标量，因为安全规则与格式偏好对一次违规的定价并不相同。而且由于对数百条约束在众多回合中做穷尽式人工核查不可行，上述每一项测量的可信度都取决于产生它的自动检测器，这意味着检测器误差不是次要问题，而是压在每一个下游结论之上的混杂因素（confound）。

我们的做法是把上述每个障碍转化为一个具体的设计选择，而非一句托词。一个析因扫描框架（factorial sweep harness）使约束数量、原始提示长度与适用性密度可独立控制——包括一个长度匹配的惰性填充组（inert-padding arm），用等长的非规范性文本替换约束——从而把可归因于约束数量的下降与仅归因于长度的下降区分开。完全固定的 token 开销被直接对照任务成功率在整个扫描中测量，并以带正式断点检验的分段回归（segmented regression）定位权衡曲线上的拐点（若存在），而非假定其存在。一族五个预算封顶的选择器在每一轮依据真值适用性标签重新裁决，检验适用性感知选择器是否真的优于仅基于当前步骤语义相似性的选择器。同时，每条违规率曲线都由一个双模式检测器把关——规则型约束用精确的程序化校验器，语义型约束用 LLM 评判器——并在任何曲线被当作事实解读之前对照人工标注进行校准。

我们在一个从个位数到数百条同时生效约束的数量扫描上评估该设计，约束取自真实领域政策与可验证指令语料，在具有可程序化校验终态的工具使用智能体任务上，将完全固定与不固定、一族选择性固定策略、以及随机预算下界进行对比。

综上，我们的贡献是：
- 识别并形式化约束固定作为治理默认做法背后的不对称性：保证规则被*看到*的 token 成本随规则数量线性增长，而为每条规则的合规付费的注意力预算并不随之增长，因此随着常驻规则数量增长，在场与合规可能悄然解耦。
- 一个析因式约束数量扫描框架，将约束数量与原始提示长度、适用性密度解耦，使合规性下降可以被归因于正确的原因，而非靠假定。
- 一族预算封顶、按步骤条件化的选择性固定策略——包括对"规范适用性是否可约化为语义相似性"的直接检验——对照能力匹配的随机预算下界进行评估，而非作为要在排行榜上取胜的系统去跑分。
- 一份实证结论：完全固定的 token 开销是否、以及在什么约束数量开始可测量地侵蚀任务成功率——全程由经人工校准的违规检测器把关——以及这对生产 LLM 智能体中把固定作为默认治理机制意味着什么。

## 问题定义

**形式化设定。** 考虑一个回合（episode）e = (τ, C, π, m, s)：从任务套件中抽取的任务 τ、从约束池中抽取的约束集 C（|C| = n）、固定策略 π、模型 m 与随机种子 s。回合在轮次 t = 1, …, T_e 上展开。每条约束 c ∈ C 携带一个真值适用性标签 app(c, e, t) ∈ {0,1}——即 c 在第 t 轮是否真正约束智能体的动作——以及一个验证程序，在 c 适用的轮次上给出检测器裁决 viol(c, e) ∈ {0,1}。固定策略 π 决定每一轮有 C 的哪个子集驻留在智能体上下文中：π_full 每轮逐字重复全部 n 条约束；π_none 仅在 t = 1 陈述一次约束集；π_k^σ 在选择器 σ 与固定 token 预算 k 之下，选出一个有界子集在每轮保持驻留。三个量作为 (n, π, m) 的函数被追踪：违规率 V，即适用的（约束, 回合）对中被违反的比例；开销比 O，即约束块占提示的每轮平均比例；任务成功率 S，即通过程序化终态校验的回合比例。研究对象是：在 π_full 下，logit(S) 作为 log n 的函数是否存在可检测的断点——若存在，一个预算封顶的选择性策略能否以 π_full 开销 O 的一小部分把 V 维持在 π_full 的水平附近。

**为什么这很难。** 固定这一做法本身没有对 n 施加任何上限——π_full 的 token 成本线性增长且没有内置断路器，因此 S 是否、以及在何处随 n 增长而弯折是一个需要定位的经验事实，而非可以直接读出的设计参数；需要带正式断点检验的分段模型，才能把它从肉眼观察的趋势变成可证伪的断言。随 n 增长观察到的任何下降也与"更大的 C 意味着更长的提示"相混杂，因此要把真正的约束数量效应与原始长度效应分离，就必须在只变约束内容时保持长度不变、在只变数量时保持适用性密度不变。某条约束在给定轮次是否真正生效——app(c, e, t)——是一个依赖状态与任务的规范匹配问题，而非语义相似性问题，且现有选择方法从未针对真值适用性（而非文本相关性）做过验证。不存在能正确地在 V、O、S 之间定价的单一标量，因为不同约束类别（安全规则与格式偏好）对一次违规的定价并不相同。而且由于对数百条约束在众多多轮回合中做穷尽式人工核查不可行，每一个被测得的 V 的可信度都取决于产生 viol(c, e) 的检测器，因此在把任何由其导出的曲线解读为事实之前，必须先在经验上界定检测器误差。

## 方法概览

在概念层面，本研究是一条包含五个协作部件的单一测量流水线，其中四个产生可证伪的断言，一个刻意保持描述性。约束池与智能体任务回合进入一个析因扫描框架，该框架独立控制约束数量、原始提示长度与适用性密度；完全固定的 token 成本在该扫描上被直接对照任务成功率测量，以定位断点（若存在）；一族预算封顶的选择器在同一框架内被评估，把扫描变成"有界选择策略能否守住违规率底线"的检验；一个双模式检测器以经人工校准的一致性阈值为每次违规读数把关；一个权衡追踪器（trade-off tracker）呈现所得的三轴曲面，而不把它坍缩为单一数字。

**解混杂扫描框架**接收约束池与任务套件，生成约束数量、提示长度与适用性密度均可独立操纵的回合——包括一个长度匹配的惰性填充组——使合规性下降能够被归因于正确的原因。**开销测量与断点检验**接收完全固定下的每轮 token 计数与任务成功结果，拟合一个分段模型，要么定位 n 中的断点，要么把"在所测范围内不存在断点"作为有效发现报告。**选择性固定策略族**在固定 token 预算下接入同一框架，评估五个选择器——包括一个建立在真值适用性而非文本相似性之上的选择器——以检验有界策略能否以远低于完全固定的成本逼近其违规率。**双模式违规检测器**接收每个回合的转录，产生经校准的违规读数，对程序化与语义化约束分别把关，并在任何曲线被采信之前对照人工标注验证两者。**权衡追踪器**接收 (n, 策略, 模型) 全网格上的违规率、开销与成功率，将其呈现为带各约束类别分解的帕累托曲面（Pareto surface），报告刻画出的前沿，而不将其归结为某个偏好的运行点。

## 方法论

### 解混杂扫描框架（Deconfounded Sweep Harness）

**挑战。** 任务成功率随约束数量增长而下降的任何观测，天然与"更大的约束集也意味着更长、更分散注意力的提示"相混杂——关于"数量"的断言总有可能实际上是关于"长度"或"集合中真正生效的比例"的断言。

**洞见。** 数量效应、长度效应与适用性密度效应做出相同的预测（固定的文本越多，成功率越低），除非有办法固定其中两者、只变第三者——因此解混杂需要析因设计，而不是对天然相关的原始条件加大采样。

**方法。** 回合以约束数量 n、适用性密度与提示长度为可独立控制的因子实例化。长度匹配的惰性填充组用等长的非规范性填充文本替换约束，在保持 token 数不变的同时移除全部规范性内容，从而使仅由填充复现的下降归因于长度、只有在真实约束内容下才出现的下降归因于约束数量本身。真值适用性标签 app(c, e, t) 在建池时人工撰写，使密度可以在固定 n 下独立变化。由于这些标签承担三重载荷——设定密度因子、定义违规率分母、供给 oracle 选择器——将对其分层抽样由第二位标注者独立复标，一致性随 RQ4 的检测器校准一并报告，以防标签噪声悄然扭曲建立在其上的各项量。

### 开销测量与断点检验（Overhead Instrumentation and Breakpoint Test）

**挑战。** 固定这一做法没有对约束数量施加上限，因此 token 成本的线性增长是否——以及在何处——真正开始侵蚀任务成功率，是一个必须去定位的经验事实，而非可以事先读出的设计参数。

**洞见。** 断点断言需要带有明确显著性阈值与置信区间的正式检验，而非绘图趋势上的肉眼拐点，否则"过了某个点就会适得其反"在构造上就不可证伪。

**方法。** 在完全固定下，逐轮记录约束块 token 数（绝对值及占提示比例）与任务成功结果，覆盖整个约束数量扫描。对 logit(任务成功率) 关于 log n 拟合分段（分段线性）回归，用 Davies 检验检查断点；若检测到断点，其位置连同自助法（bootstrap）置信区间一并报告。完全固定下的违规率在同一扫描中并行追踪，从而使"违规率上升而约束在场程度并未相应下降"可以被解读为合规与在场解耦，而非靠假定。

### 选择性固定策略族（Selective-Pinning Policy Family）

**挑战。** 哪些约束在给定轮次真正生效，是一个依赖状态与任务的规范性问题——"规则 r 是否适用于即将采取的动作"——而非文本或语义相似性对当前步骤就能保证答对的问题，且没有任何先行选择方法针对真值适用性（而非相关性）做过验证。

**洞见。** 检验规范适用性是否可约化为语义相似性的唯一途径，是构建一个刻意不基于相似性的选择器，并在相同 token 预算下与基于相似性的选择器对比——两者结果之差直接回答了仅相似性选择方法未曾检验的问题。

**方法。** 在固定 token 预算 k 下，实现五个选择器并在每一轮重新运行：随机 k 下界、按试点测得违规频率排序的静态 top-k 策略、嵌入相似度选择器、边际信息增益选择器（改造自证据压缩所用的打分规则）、以及直接对照扫描框架真值标签打分的适用性分类器。由于最后这个选择器消耗部署时不可得的适用性标签，它被解读为适用性感知选择的 *oracle 上界*（oracle upper bound）：适用性对相似性的对比是"语义相关性之上还有多少上升空间"的存在性检验，而不是宣称一个可部署的分类器已经达到了这一空间。每个选择器所得的违规率与开销在匹配预算下测量，从而使适用性分类器与相似性选择器之间的任何差距可归因于选择准则本身，而非预算或任务差异。

### 双模式违规检测器（Dual-Mode Violation Detector）

**挑战。** 对数百条约束在众多多轮回合中做穷尽式人工核查不可行，而本研究中每条违规率曲线的可信度都取决于产生它的自动程序——未经校准的检测器可能制造或掩盖正在被刻画的那个权衡本身。

**洞见。** 检测器误差是压在每一个下游结论之上的混杂因素，而非事后再处理的独立小问题——在解读任何曲线之前以预注册的人工一致性阈值把关，才能防止一个噪声检测器悄然决定论文的结论。

**方法。** 规则型约束用精确的程序化校验器检查；语义型约束用 LLM 评判器检查。二者都在任何由检测器导出的曲线被读作发现之前，对照按约束数量、策略与约束类别分层的人工标注样本进行校准。若未达到预注册的一致性阈值，则将主要结论重述在约束池中可程序化校验的子集上，语义约束的结果单独报告并标注为受检测器误差界定，而非被悄然撤回。

### 权衡追踪器（Trade-off Tracker）

**挑战。** 违规率、token 开销与任务成功率无法坍缩为一个诚实的标量目标，因为不同约束类别对一次违规的定价并不相同，也没有任何数据驱动程序能为它们之间的单一权重辩护。

**洞见。** 报告按约束类别分解的完整三轴曲面才是诚实的刻画；强行给出单一数字会把一个设计本身无法辩护的任意价值判断固化进去。

**方法。** 记录 (约束数量, 策略, 模型, 种子) 全网格结果，并呈现为带各约束类别分解的帕累托曲面。该部件刻意不产生自己的可证伪假设：它描述所得的权衡曲面，而不将其归结为单一推荐运行点，而这份描述——而非关于前沿上"正确"位置的断言——就是它对本研究的贡献。

## 实验

### 实验设置

**数据集。** τ-bench（航空/零售政策遵循型工具使用任务）提供主任务套件，任务成功通过数据库状态校验验证。IFEval 与 FollowBench 提供规则型、可程序化验证的约束模板，按 RECAST 约束挖掘流水线的方式挖掘并扩展，把约束池建到 n = 400。PrefEval 提供构成池中 LLM 评判部分的语义约束模板，这正是检测器有效性研究问题特别需要压力测试的部分。

**基线**（下界与合理性校验的参照物，不是要击败的竞争者——这是一项测量研究，这里没有任何研究问题被表述为"我们的程序击败基线 X"）。完全固定是每个条件都要对照的、被压力测试的默认做法。不固定（约束仅在回合开始陈述一次）是确立底层问题确实存在的必要对照：若不固定下的违规率不随约束数量上升，则约束保持根本不成其为问题，任何形式的固定都无须进一步研究。相同 token 预算下的随机 k 选择器是任何适用性感知选择断言都必须越过的能力匹配下界。长度匹配的惰性填充组是把约束数量与原始提示长度分离的对立解释对照。

**指标。** 违规率及其混合效应趋势斜率；token 开销（绝对值及占提示比例）；任务成功率及其分段回归断点（若有）；以及检测器一致性（对照人工标注的 Cohen's κ）。

**测量成本。** 规模化网格总计 7 个约束数量档 × 6 个策略 × 3 个模型 × 每格 450 回合 = 56,700 个多轮工具使用回合（试点另计）——其中完全固定的格子主导 token 账单，因为其约束块在每个回合的每一轮中都随 n 线性增长直至 n = 400。一项以"线性于 n 的 token 成本是问题"为论点的研究，理应对自身的成本记账：各条件的 token 开支作为一等输出记录（产生开销比 O 的同一套测量装置也为实验本身定价，并随工件一并发布）；不变的固定约束块在服务栈支持处通过提示前缀缓存（prompt-prefix caching）供给——缓存与未缓存的 token 数分开报告，因为缓存改变的是"在场"的价格而非研究对象的注意力预算负载——并且规模化以试点为闸门，使最大的格子只运行一次而不反复迭代。

**研究问题：**
1. RQ1——随着约束数量增长，完全固定的任务成功率是否存在可检测的断点？在每条约束都保持驻留的情况下，违规率是否仍会上升？
2. RQ2——预算封顶的选择性固定策略能否以完全固定开销的一小部分把违规率维持在其水平附近？适用性感知选择器是否优于基于相似性的选择器？
3. RQ3——观测到的下降是否可归因于约束数量本身，而非仅仅是原始提示长度或适用性密度？
4. RQ4——双模式违规检测器是否足够可靠，使测得的曲线反映智能体行为而非检测器误差？

#### RQ1：完全固定的任务成功率是否存在可检测的断点？在每条约束都保持驻留时，违规率是否仍会上升？

**设置。** 试点阶段：2 个骨干模型 × 2 个条件（完全固定 / 不固定）× 50 对 × 20 回合，在规则型子集上进行。规模化：7 个约束数量档 {4, 10, 25, 50, 100, 200, 400} × 6 个策略 × 3 个模型 × 150 个任务 × 3 个种子（每格 450 回合）。以任务为随机效应，对回合成功率关于 log n 做混合效应逻辑回归；分段回归加 Davies 断点检验，α = 0.05，跨模型 Holm 校正；违规率以回合层面的聚类稳健标准误比较。

**样本量依据。** 每格 450 回合是为在 80% 功效、α = 0.05 下检测 10 个百分点的成功率差异而定。任何在剔除废行后每臂低于 388 回合的格子，预先声明该格为 INCONCLUSIVE（无定论）——连同实际达到的样本量一并报告，绝不计为零结果，也绝不悄然丢弃；所需格子不足的主假设自身也声明为 INCONCLUSIVE，并把断言收窄到有足够功效的子集。此预算只为任务成功率对比定价：此处 3 个百分点的违规率对比与 RQ2 的 0.02 非劣性边际，是比该格量所依据的成功率差异更小的效应，其功效建立在（约束, 回合）对层面——每个回合为每条适用约束贡献一个观测，用聚类稳健标准误吸收回合内相关——而非回合层面。若试点测得的基线率与回合内相关意味着在对层面对某违规率边际的功效不足 80%，则受影响的边际放宽到预注册的后备值 0.03（绝对值）并如实报告为已放宽，遵循同一"绝不悄然丢弃"规则。

**预期结果。** 完全固定下的任务成功率存在可检测断点（Davies 检验 p < 0.05，95% 自助法置信区间落在 [25, 400] 内），且在 3 个被测模型中至少 2 个上，n = 400 的成功率比 n = 10 至少低 10 个百分点；在 3 个模型中至少 2 个上，n = 400 的违规率比 n = 10 至少高 3 个百分点（绝对值）——尽管每条约束在每一轮都仍在上下文中。

**证伪条件。** 若在直到 n = 400 的全部被测范围内，完全固定的任务成功率没有统计显著下降——分段回归找不到断点且 log n 的系数非负——则该断言被驳倒（不存在适得其反），此时诚实的结论是：在此范围内，穷尽式固定的代价是经济性的而非行为性的。另外，若尽管 token 开销比大幅增长，n = 400 的违规率与 n = 10 在统计上不可区分，则合规解耦断言被单独驳倒——那意味着即使在规模化下，在场与合规仍然同步。

**假设（通俗表述）。** 通过完全固定保证规则在上下文中在场，并不能保证对它的合规，而且一旦常驻规则数量达到一两百条的量级，这一鸿沟会大到可测量地降低任务成功率。

**指标。** 分段回归断点位置及 95% 置信区间；n = 10 对 n = 400 的每格成功率；n = 10 对 n = 400 的每格违规率；并行记录的开销比。

#### RQ2：预算封顶的选择性固定策略能否以完全固定开销的一小部分把违规率维持在其水平附近？适用性感知选择器是否优于基于相似性的选择器？

**设置。** 在约束数量 n ≥ 100 时，全部五个选择器（随机 k、静态 top-k、嵌入相似度、边际信息增益、适用性分类器——最后者消耗真值标签、按方法论解读为 oracle 上界）都在固定为对应 n 下完全固定约束 token 25% 的预算下运行。每个选择器的违规率对完全固定的非劣性用单侧 95% 置信区间在 0.02 绝对边际下检验；适用性分类器与最佳相似性选择器之间用 Holm 校正的成对检验比较。

**预期结果。** 在 n ≥ 100 时，表现最好的选择器在最多使用完全固定开销 30% 的情况下，违规率对完全固定在 0.02 绝对值内非劣；适用性分类器在相同预算下的违规率比最佳相似性选择器至少低 0.03（绝对值）。

**证伪条件。** 若没有任何选择器在任何被测预算下越过对完全固定的非劣性边际，则可行性断言被驳倒——此时诚实的结论是：对规范性内容而言（与证据检索不同），目前不存在安全的有界选择，在 RQ1 定位的断点以下，完全固定仍是唯一可靠的策略。若适用性分类器与最佳相似性选择器在统计上等价（±0.02 内，双单侧检验（TOST）等价性检验），则适用性对相似性断言被单独驳倒——那意味着对这个约束池来说，规范适用性在经验上可约化为语义相关性，更廉价的相似性选择即已足够。

**假设（通俗表述）。** 一个有界的、按步骤条件化的选择策略能以完全固定 token 成本的一小部分逼近其合规水平，而做到这一点需要推理哪些规则真正适用，而非哪些规则只是听起来与当前步骤相关——oracle 对比能确立这一上升空间的存在，但可部署的选择器仍须在没有真值标签的情况下将其变现。

**指标。** 匹配预算下每个选择器的违规率与开销比；对完全固定的非劣性边际检验结果；适用性分类器对相似性选择器的成对对比。

#### RQ3：观测到的下降是否可归因于约束数量本身，而非仅仅是原始提示长度或适用性密度？

**设置。** 在 n = 400 时，将长度匹配的惰性填充组（token 数与位置相同、无规范性内容）与真实约束的完全固定组，就相对 n = 4 的任务成功率下降进行比较。在固定 n = 100 时，在保持 n 不变的前提下于三个水平独立变化适用性密度，并比较各密度水平的违规率。

**预期结果。** 长度匹配的惰性填充最多复现 n = 400 时完全固定任务成功率下降的 50%（在 α = 0.05 下统计可区分）；在固定 n = 100 时，高适用性密度使违规率相对低密度至少升高 0.03（绝对值，p < 0.05）。

**证伪条件。** 若惰性填充复现了真实约束下观察到的全部下降，则被驳倒（纯长度伪影）——那意味着"约束数量"效应实际上是原始提示长度效应，约束数量方面的指导坍缩为既有的长上下文指导，本文再无特有内容可补。另外，若在固定 n 下适用性密度对违规率没有可测量的效应，则密度作为不承重的因子从框架中移除，并如实报告而非悄然删去。

**假设（通俗表述）。** 约束数量负载是与原始提示长度不同的退化维度——固定更多规则并不只是"提示变长了"的特例。

**指标。** 真实约束组对填充组的任务成功率下降幅度，附下降差异显著性检验；固定 n 下按适用性密度水平的违规率。

#### RQ4：双模式违规检测器是否足够可靠，使测得的曲线反映智能体行为而非检测器误差？

**设置。** 按约束数量、策略与约束类别分层抽取 300 个回合样本，由两名人工标注者独立标注。计算检测器裁决与人工标注之间的 Cohen's κ（总体与各约束类别，附自助法置信区间），并检查各类别混淆结构，确认分歧集中在相邻约束子类型之间，而非某一类别整体坍缩到另一类别。

**预期结果。** 双模式检测器对照人工标注总体达到 Cohen's κ ≥ 0.80，其中程序化校验器原始一致率至少 0.95，且至多经过一次校准迭代。

**证伪条件。** 若经一次校准迭代后 κ 仍低于 0.80，则被驳倒——此时语义约束曲线从主要结论（RQ1–RQ3）中撤出，主要结论重述在约束池中可程序化校验的子集上，LLM 评判的结果单独报告并附评判器误差条，而非以同等置信度呈现。若混淆结构检查发现某一类别向另一类别的系统性（非相邻）坍缩，即使总体 κ 越过 0.80，同样的撤出规则也按类别适用。

**假设（通俗表述）。** 测得的违规率曲线反映的是智能体的实际行为，而非不可靠检测器的伪影——而且这必须在主要曲线被解读之前、而非之后检验。

**指标。** 总体与各约束类别的 Cohen's κ 及自助法置信区间；程序化校验器原始一致率；各类别混淆率检查。

## 相关工作

与本文最接近的先行工作是 RECAST 与 CogniLoad，在综述更广的图景之前值得把差异直说：RECAST 在领域上最接近——它已记录模型随同时施加的要求数量增长而显著退化——CogniLoad 在方法上最接近——它已把干扰项密度、序列长度与任务复杂度解耦为可独立调节的因子，使退化可归因于单一维度而非多维混杂。但 RECAST 训练模型去更好地*满足*一组固定要求，从未测量在多轮轨迹中承载该集合的表征成本；而 CogniLoad 的析因设计只被应用于事实性与推理性材料，从未用于一组以违规（而非答错）为关键结果的常驻规范性规则。恰好补上这一空白——对被固定的规范性约束数量做受控的、解混杂的扫描，联合对照违规率、token 开销与任务成功率——正是本文的全部目的。

**多约束指令遵循。** RECAST 从指令-响应语料中挖掘可验证约束，将其分为规则型与模型型两类，并用约束级验证奖励训练以提升模型能同时满足的要求数量，其动机是模型随要求数量增长而显著退化的证据。这一脉络把约束集当作表征上免费的东西——它优化对给定约束的满足度，从不考虑在多轮轨迹中让不断增长的约束集驻留在智能体上下文中的 token 成本，而后者正是本文要测量的量。

**长上下文下常驻项的保持与遗忘。** PrefEval 检验一条只陈述一次的用户偏好能否在被埋入冗长无关对话后幸存；ICF-Bench 检验模型能否在新上下文取代之后抑制一条被撤销或被取代的指令。二者都把单个常驻项与充满干扰的历史对立起来，且只报告合规性。二者都没有扩展到同时约束多条的情形，也都不报告任何保持机制——包括简单地重述该项——为维持其显著性所付出的 token 开销，而这正是本文的开销测量装置专门要测的。

**智能体上下文与历史管理。** Sculptor 为智能体配备对自身任务历史进行分片、隐藏与恢复的工具，在既成事实之上维护一个低干扰工作区；AgentFold 学习一个折叠策略，在保持最新一步全保真的同时维护较旧子轨迹的多尺度摘要。二者都在主动管理会话累积的*任务历史*，但都把常驻指令或政策块当作固定背景，从不把约束违规率作为结果报告——它们优化的是过去交互中什么进入工作区，而非数百条常驻规则中哪些值得驻留上下文，后者才是本文的实际研究对象。

**并行的有界上下文与约束规模化工作（2025 年末–2026）。** 一个快速推进的并行集群正在逼近本设计估计对象（estimand）的各个单一轴向，其差异值得精确让渡。Context as a Tool（CAT；arXiv:2512.22087）把上下文管理本身变成长程软件工程智能体的可学习工具，在 token 预算下决定什么进入窗口；AgenticSTS（arXiv:2607.02255）实现了一个有界记忆契约，决定哪些类型化经验槽位占据有限的每决策窗口，并将这些槽位对任务胜率做消融；面向多约束指令遵循的事后重放强化学习（HiR；arXiv:2512.23457）针对显式约束集 C = {c₁, …, cₙ} 训练模型，以提升同时被满足的约束数量。它们各自恰好占据本设计的一个轴向——为*任务历史或经验*做预算化上下文驻留（CAT、AgenticSTS），或在训练时提升多约束集的*满足度*（HiR）——而没有一个测量本研究所要测量的东西：当常驻*规范性*约束数量从个位数扫到数百条、且数量与原始提示长度和适用性密度解混杂时，违规率、token 开销与任务成功率的联合变化。该集群研究的驻留决策关乎智能体做过什么、经历过什么；本文研究的驻留决策关乎智能体有义务遵守什么，其违规——而非遗漏——才是记录在案的结果。

**上下文压缩与受控负载基准。** COMI 在固定 token 预算下按边际信息增益给单元打分来压缩上下文——对查询的相关性减去与已保留内容的冗余——并在证据与摘要检索上得到验证；同一边际增益打分规则在本文中被复用为选择性固定策略族的一个对照臂，但其验证从未延伸到规范性内容：在那里"相关性"意味着规则是否适用于当前动作而非与查询的语义相似性，而且压缩规则的措辞可能摧毁其可执行性。CogniLoad（前文已作为最近的方法邻居讨论）与 Lost in the Middle（表明单个检索目标埋在长上下文中部时可能不被使用）都确立了"在上下文中在场不保证被使用"——但二者都没有量化当同时生效的规范性条目数量增长时合规性如何退化，也没有量化让它们全部驻留的开销成本，而这正是本文的扫描要补上的。

## 结论

本工作把一个治理默认——逐字固定每条常驻约束是安全的（哪怕浪费的）选择——重新表述为一个具有精确可识别性结构的实证问题，而非把逐字重复当作不证自明的充分做法。核心的方法论押注在于：只有把约束数量与原始提示长度、适用性密度解混杂，并且断点断言由正式的分段回归检验而非肉眼趋势背书之后，在场与合规才是可区分的；较弱的设计有把长度伪影误认为约束数量效应、或把未测量检测器的噪声误认为真实行为趋势的风险。无论扫描产出哪种结果，其发现都与决策相关：检测到断点意味着早在约束数量达到生产规模之前，固定就需要配套的选择机制；在被测范围内未检测到断点则意味着穷尽式固定的代价目前是经济性的而非行为性的，实践者可以用 token 成本换取简单性而不付出合规代价。两条局限从一开始就界定本断言的范围，并且是自然的后续工作而非事后补丁：违规率、开销与成功率之间的权衡曲面被刻画而非归结为单一推荐运行点，因为没有任何数据驱动程序能独立为跨约束类别的某种权重辩护；本研究的范围限定为单一回合内固定、有界的常驻约束集，把任务中途新增、修订或撤销的约束——以及跨会话而非会话内持续的约束集——留给后续工作。
