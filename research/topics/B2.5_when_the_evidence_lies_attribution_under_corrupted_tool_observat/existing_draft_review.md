## Architecture (canonical = ZB2.5)

Pipeline (measurement-only; explicitly proposes no new attributor — the "trust-license fix" in the room's one-liner never materalized in the methods, which is fine given the audit's mechanism framing):

1. **Substrate.** Reproducibly successful ("known-good") trajectories from **AgentDojo (≥ 2 tool domains) + GAIA (≥ 1 web/file domain)**; Who&When appears only as context. Exactly **one tool observation corrupted per trajectory** under five schema-preserving operator families: numeric (value/unit/sign), entity swap, boolean flip, structural (truncation/reorder within schema), stale-value replay.
2. **Invisibility certification.** Three legality gates — JSON-schema re-validation, domain parser, disjoint-model plausibility screen (τ_plaus) — plus a **held-out fourth plausibility scorer** never used in selection (paired gap ≤ 0.05, AUC ≤ 0.55) to prove invisibility is not a gate-selection artifact.
3. **Decisiveness certification (the technically distinctive part).** FORCED-REPLAY twin semantics: downstream action *slots* held fixed to the known-good sequence; a deterministic **provenance detector** labels each argument slot COPY-BOUND (verbatim/normalized copy of an observation span) or NON-COPY-BOUND; only copy-bound slots and the terminal answer payload are recomputed from the corrupted observation; an end-state checker that reads *content* decides the flip. Faithfulness of the copy-binding is audited by re-decoding under the recording sampling regime (k = 5, majority; decode-unstable cases quarantined; ≥ 90% confirmation floor). Honest scope restriction: certified population is enriched for literal copy-through pipelines; compute/paraphrase dependencies are conservatively certified non-decisive.
4. **Judged variant + blinding.** Attributors consume the **free-execution re-run** (agent re-decodes downstream steps against the corrupted observation), which is internally consistent — the forced-replay splice is only ever a certification artifact. Trajectories whose free-execution re-run *recovers* to success are partitioned out of both arms (attribution is ill-posed without a realized failure). Harness strips twins/tags; leakage audited by a **prefix-only probe** (recall ≈ base rate) and a **splice-consistency probe** (≤ 5% flagged).
5. **Measurement.** Verdicts from unmodified LLM-judge and trained-tracer families (runtime-monitor family acknowledged as unsourced — an open roster gap), projected by ≥ 2 blinded annotators onto a frozen {plan, tool, execution, abstain} ontology (Krippendorff α ≥ 0.75). Headline: **Δ-trust gap** = misattribution rate on non-recovered silent corruptions − rate on *matched* overt errors (identical corrupted value re-tagged with an error string, same forced-replay decisiveness, same recovery filter, re-balanced on operator family and suffix-length strata, SMD < 0.1), estimated as difference-in-differences via mixed-effects logistic regression (suffix-length + operator family fixed effects, trajectory random effect). Pre-registered floors: gap ≥ 20 pp overall, ≥ 10 pp in every suffix stratum; channel specificity: exceeds an **injected, twin-verified agent-side-fault control** gap by ≥ 15 pp; direction: plan-layer misblame ≥ 1.5× matched-control base rate. Scale: ~2,400 injection candidates → ≥ 360 certified → ≥ 200 non-recovered matched pairs per arm; overt arm provisioned ≥ 360, agent-side arm ≥ 300.

The differential-recovery argument is a nice touch: overt errors are more salient recovery cues, so equal recovery-filtering *compresses* the gap, making any surviving Δ a conservative lower bound.

## Novelty highlight

- **Sharpest claim:** the *diagnostic layer inherits the tool's lie* — attribution degrades specifically because the false evidence is well-formed (Δ-trust gap survives suffix-length stratification and an agent-side-fault contrast), and the misblame is *directional*, landing on the plan layer, so automated repair loops retrain the innocent planner while the lying tool escapes. Direction, not just error rate, is what repair pipelines act on — this is the mechanism angle the audit flagged as the topic's value.
- **Nearest prior work:** TOOLMAZE / ToolGate / "Failing Tools" (agents over-trust corrupted tool returns — but they measure the *acting agent's* recovery, not post-hoc diagnosis); prompt-injection/security work (ChatInject, InjecAgent, MCP-SafetyBench — attack success, not blame localization); Who&When / TraceElephant (natural agent mistakes only); **AgenTracer is the closest overlap and the report honestly flags the boundary as unresolved** — its programmatic fault injection may or may not include schema-valid false environmental feedback; AEGIS injects context-aware errors but labels via an LLM manipulator. Nobody measures *where blame lands* when ground truth is a certified tool-layer lie.
- **Operational delta:** forward-manufactured, replay-certified ground truth in which the true faulty layer is the *tool observation channel*, with matched overt controls making well-formedness the sole manipulated variable, and a shared verdict ontology making heterogeneous attributors comparable. The invisibility/decisiveness orthogonal-certification design (gates + twin replay, held apart) is the Defects4J-style move for agent traces.
- **Load-bearing?** Yes for the headline (plan-ward skew is unmeasurable without the certified tool-layer ground truth and the matched controls). The provenance/copy-bound machinery is load-bearing for *validity* (decisiveness under stochastic agents) but not for the concept; it is also the main cost/complexity risk, and its copy-through scope restriction must stay in the claims.

## Freshness check vs 2026-08

Drafts froze 2026-07-09/10. With failure attribution now the largest arXiv tag (53.8% of recent papers) and crowding fast:

1. **The anti-LLM-judge positioning is this topic's natural moat and should be the lead.** Every crowding pipeline scores attribution against LLM- or human-labeled ground truth read off the trace — but here the trace itself is the corrupted evidence, so judge-labeled ground truth is *circular by construction*. ZB2.5's abstract already gestures at this ("diagnosis consumes the corrupted evidence circularly"); it should be sharpened into an explicit impossibility argument in the intro: this question is unanswerable by the dominant methodology, which is exactly why it is uncrowded despite the crowded tag.
2. **Resolve the AgenTracer novelty boundary before submission.** The report leaves "does AgenTracer's fault injection cover schema-valid false observations?" open. This is now urgent: inspect the AgenTracer/TracerTraj release and any July–August 2026 follow-ups; one paragraph of precise differentiation (their injections target agent actions and are LLM-annotated; ours target the observation channel and are twin-certified) removes the biggest reviewer landmine.
3. **Compose with B2.1 (family lead).** The corrupted-observation channel is one fault type in B2.1's controlled-substitution taxonomy; B2.5's {plan, tool, execution} ontology, blinded harness, and forced-replay twin machinery should be shared infrastructure with B2.1 and B2.4. B2.5 then reads as "the observation-channel chapter" of a coherent family rather than a standalone benchmark in a saturated area — and the agent-side-fault control arm is essentially a B2.1 fault injection, so the composition is already latent in the design.
4. **Roster gap:** the three-family claim (judges, tracers, runtime monitors) has no runtime-monitor representative sourced. By 2026-08 either source one (e.g., a guardrail/monitor product or an open monitor from the runtime-assurance literature) or pre-emptively descope the paper to two families, as the report itself recommends. Do not let the abstract promise three families.

Verdict: **framing survives; needs the circularity argument promoted, the AgenTracer boundary settled, and the roster pinned.**
