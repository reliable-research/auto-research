## N1/N2 Motivation (verbatim from corpus record `proposal.motivation`)
Metric-based AI-text detectors are attractive because they generalize better than heavy supervised classifiers, but their reliability is constrained by how they use token-level evidence. Methods such as @mitchell2023detectgpt and @bao2024fastdetectgpt derive local probability-based signals and then aggregate them into a passage-level decision. Even when these signals are produced by sophisticated curvature or perturbation schemes, the aggregation step assumes that token-level scores are already trustworthy. This assumption is weak in practice because LLM sampling randomness can bias individual token scores, so direct summation or thresholding propagates local errors into the final decision.

Several prior works reveal this gap from different angles. @yang2024dnagpt reduces randomness by comparing against regenerated text, and @nguyenson2024simllm likewise exploits structured similarity across generation contexts, indicating that instability in local signals is a central obstacle rather than an incidental artifact. Meanwhile, @sadasivan2023detectability shows that existing detectors are brittle under paraphrasing and distribution shifts, which suggests that detectors built on noisy local evidence can fail even when their global metric remains conceptually meaningful. The unresolved problem is therefore not only how to invent new detection metrics, but how to calibrate the token-level score sequence produced by existing detectors before aggregation.

This gap matters because it creates a modular opportunity: if token-score noise has predictable structure, then one can improve many metric-based detectors without redesigning their core metrics. In particular, neighboring token scores are expected to be correlated through contextual generation dynamics, while early-token scores are more unstable because the generation process is less conditioned at the beginning of a sequence. Exploiting these properties would allow a detector-agnostic refinement layer that preserves the simplicity and generalization advantages of metric-based detection while improving robustness in cross-LLM, cross-domain, and adversarial paraphrasing settings exposed by @sadasivan2023detectability.

## N6 Methodology (verbatim from corpus record `proposal.method`)
We propose a Markov-informed calibration layer that refines token-level detection scores before final passage-level aggregation. The core idea is to treat the base detector's token outputs as noisy unary evidence and then perform lightweight structured inference over adjacent tokens, while downweighting unstable early positions. This formulation directly addresses the identified gap because it corrects score inconsistency at the sequence level without replacing the underlying detector metric introduced by methods such as @mitchell2023detectgpt, @bao2024fastdetectgpt, or @yang2024dnagpt.

1. **Unified Token-Score Interface**: We first represent an existing metric-based detector as two stages: token-level score computation and text-level aggregation. This abstraction is needed because detectors like @mitchell2023detectgpt and @bao2024fastdetectgpt differ in how they compute scores, but they share the same vulnerability of aggregating noisy local evidence. By converting each token score into a normalized two-class prior over human- vs. machine-generated labels, we create a common calibration interface that can be stacked on top of diverse detectors.

2. **Pairwise MRF Score Calibration**: We model the token label sequence with a pairwise Markov Random Field whose unary potentials come from the base detector and whose pairwise potentials encourage adjacent tokens to take compatible labels. This component is needed to encode the neighbor-similarity structure that raw aggregation ignores. It extends the detector outputs of @mitchell2023detectgpt, @bao2024fastdetectgpt, @yang2024dnagpt, and @nguyenson2024simllm by treating their token scores as correlated observations rather than independent quantities.

3. **Positional Instability Weighting**: We introduce a position-dependent weighting function that suppresses pairwise interactions and final contributions of early tokens. This is needed because initial token scores are systematically less stable, so forcing strong neighborhood consistency there can amplify error instead of correcting it. The component complements the structured smoothing above by making calibration selective rather than uniform across positions.

4. **Mean-Field Iterative Inference Layer**: We implement MRF inference through iterative mean-field updates, initializing from the base detector priors and repeatedly applying a softmax-normalized correction step. This is needed because exact inference over token-label configurations is intractable, while mean-field provides an efficient approximation with linear complexity in sequence length and iteration count. The design directly draws from the practical Markov inference strategy demonstrated by @deng2022markovgcn, but adapts it to token-score calibration rather than graph node classification.

5. **Lightweight Learnable Reward-Penalty Matrix**: Instead of using a single symmetric smoothness weight, we learn a small 2x2 reward-penalty matrix for different neighboring label interactions. This is needed because the influence of machine-like neighbors and human-like neighbors need not be identical, and a single scalar would underfit these asymmetric correction patterns. The resulting parameterization remains compact, which helps preserve the cross-domain and cross-model generalization advantages that motivate metric-based detection in the first place.

These components form a coherent system because the base detector supplies detector-specific evidence, the MRF captures local score dependence, the positional weighting prevents overcorrection at unstable prefixes, and mean-field inference turns the full model into an efficient plug-in module. The result is a detector-agnostic calibration mechanism that improves robustness by refining evidence before aggregation rather than replacing existing zero-shot metrics.
