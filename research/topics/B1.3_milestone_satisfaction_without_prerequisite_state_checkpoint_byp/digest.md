## N6 — Methodology

`overview`: [HYPOTHESIS] — "The method constructs multi-step agent tasks each annotated with an explicit prerequisite dependency DAG over milestones, equips each milestone with an independent verifier that mirrors common agent-benchmark grading practice (local, checkpoint-scoped pass/fail with no cross-milestone state access), and separately defines a terminal end-to-end state-consistency oracle as ground truth. It then constructs completion trajectories exercising three distinct bypass strategies — out-of-order milestone completion, step-skipping, and direct state injection — and measures the *checkpoint-bypass rate*: the fraction of trajectories that pass every milestone check while failing the end-to-end oracle, broken down by strategy and by graph topology.
**Staged plan.** *Stage 1 — Pilot (= the seed's minimal experiment):* ~20–40 hand-authored DAG tasks in a single domain with a canonical, independently-computable terminal state (e.g., filesystem/coding tasks graded by file hashes and program output), per-milestone verifiers (M2), constructed bypass traces for all three strategies (M3), and the terminal oracle (M4); compute the bypass rate (M5). *Stage 2 — Scale-up:* procedurally generate 200–500 tasks (M1) across 2–3 domains (coding/filesystem, tool-use/DB-state, web-action), and additionally run 3–5 real LLM agents to measure the *natural* (non-adversarial) bypass incidence among rollouts that per-milestone grading would score as complete."

`key_components`:
