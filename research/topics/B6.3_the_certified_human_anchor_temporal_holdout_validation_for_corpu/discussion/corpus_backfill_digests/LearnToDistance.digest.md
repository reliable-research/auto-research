## N1/N2 Motivation (verbatim from corpus record `proposal.motivation`)
Detecting machine-generated text remains challenging because modern language models produce outputs that closely resemble human writing across a wide range of domains and prompts. Early passive detection methods often rely on likelihood statistics derived from surrogate language models. For example, curvature-based approaches such as DetectGPT and Fast-DetectGPT analyze probability variations in the model’s token distribution to identify machine-generated text @mitchell2023detectgpt; @bao2024fastdetectgpt. While effective under controlled conditions, these methods depend strongly on assumptions about the underlying generation distribution. When prompts or domains shift, the conditional probability structure changes, causing these likelihood-based signals to degrade.

Rewrite-based detection offers a promising alternative. Methods such as RAIDAR demonstrate that when a language model rewrites a passage, machine-generated text typically undergoes fewer modifications than human-authored text, producing a measurable reconstruction discrepancy @mao2024raidar. Learning2Rewrite further shows that this pipeline can benefit from training, improving robustness by adapting the rewriting process itself @hao2025l2r. However, existing rewrite-based approaches share a key limitation: they rely on fixed, handcrafted distance metrics—such as edit distance or semantic similarity scores—to measure the discrepancy between original and rewritten text. These metrics implicitly assume that simple lexical or embedding-based similarity captures the true geometric relationship between human and machine text distributions. In practice, the optimal distance function may vary significantly across language models, domains, and prompts, leaving existing detectors poorly aligned with the underlying structure of the problem.

This gap suggests a new opportunity. If LLM-generated text occupies a constrained region of representation space, as suggested by representation-based detectors @chen2025repreguard, then reconstruction through rewriting effectively projects text toward that region. The effectiveness of rewrite-based detection therefore depends critically on how the reconstruction error is measured. Instead of relying on fixed similarity metrics, we propose to learn a task-specific distance function that maximizes the separation between human and machine reconstruction errors.

## N6 Methodology (verbatim from corpus record `proposal.method`)
Our approach introduces a rewrite-based detection framework in which the distance between a text and its LLM-generated rewrite is learned rather than predefined. The key idea is to parameterize the distance function using a language model that evaluates each text through normalized log-likelihood. By training this scoring model to maximize the discrepancy between reconstruction errors of human and machine texts, the system learns a geometry that separates human-authored content from the generative subspace of the target LLM.

1. **Rewrite-Based Reconstruction Pipeline**: Given an input text, we first generate one or more rewrites using a target or surrogate language model, following the principle established by RAIDAR that machine-generated text tends to remain closer to its rewrite than human-authored text @mao2024raidar. Multiple rewrites are sampled to reduce stochastic variability in the generation process. The average discrepancy between the original text and these reconstructions forms the reconstruction error used for detection.

2. **Learned Likelihood-Based Distance Function**: Instead of computing reconstruction error using fixed metrics, we define the distance between two texts as the absolute difference between their normalized log-likelihood scores under a parameterized language model. This formulation draws inspiration from generative evaluation metrics such as BARTScore, which interpret language-model likelihood as a measure of semantic alignment between texts @yuan2021bartscore. The resulting function acts as a soft, learnable approximation of an optimal distance that collapses distances between LLM-generated texts while enlarging distances involving human text.

3. **Distance Metric Optimization Objective**: The scoring model is trained using paired corpora of human-written and LLM-generated texts. The objective maximizes the expected reconstruction error gap between these two groups, encouraging the model to assign probability structures that make human texts diverge more strongly from their rewrites. This idea extends the training-based philosophy introduced in Learning2Rewrite but shifts the learning target from the rewriting model to the distance metric itself @hao2025l2r.

4. **Efficient Parameter Adaptation**: To make training practical, the scoring model is initialized from a pretrained language model and adapted using lightweight parameter updates such as low-rank adaptation (LoRA). This allows the detector to learn a task-specific distance metric without training a full model from scratch, while preserving the expressive capacity needed to capture stylistic or distributional signals highlighted by prior work on machine-style alignment @chen2025imitate.

Together, these components produce a detection system in which rewriting reveals a projection toward the LLM’s generative subspace, and the learned distance function defines the geometry needed to measure that projection effectively.
