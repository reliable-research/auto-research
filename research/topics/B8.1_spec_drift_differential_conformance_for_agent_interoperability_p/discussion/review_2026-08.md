## 6. Feasibility findings (se-paper-reviewer lens)

- **[moderate] F1 — Left-truncation unhandled in the window estimator.** The
  estimator brackets a window's *start* "by the last-conforming and
  first-'neither' sweeps" — but a server already in "neither" at its first
  observation has no last-conforming sweep (left-truncated entry), and, worse,
  the whole panel is anchored to a real revision date (2026-07-28 RC): servers
  that transition *before the first sweep* are invisible, biasing prevalence
  down and width toward long windows. Standard survival machinery handles this
  (left-truncation / delayed-entry terms), but the pre-revision draft never said
  so. **Revision applied** (estimator method + conclusion-validity threat).
- **[minor] F2 — No concrete sweep cadence or panel size.** RQ2 gives a power
  target (10 pp gap at ~80%) and 2605.22333 shows ~8k live servers exist, so
  the arithmetic is plausible (a 15%-vs-5% paired contrast needs on the order of
  10² servers, well under directory size even after Holm correction over a
  plausible 30–100-clause delta set), but the cadence (daily? weekly?) that sets
  the resolution floor is never fixed. Left as pre-registration slack; no
  revision manufactured.
- **[minor] F3 — Power calculation circularity.** RQ2's sizing depends on "the
  pilot's observed error variance" — self-referential, but acceptable because a
  pre-committed directory enlargement (not a null claim) is the fallback.
- **[minor] F4 — Reference-implementation availability assumed.** "The
  protocol's official reference server built and tagged at N and N+1" assumes
  taggable reference builds exist for both MCP versions and A2A; plausible for
  MCP SDK reference servers, thinner for A2A. The A2A precondition gate in the
  setup partially covers this.
- Kill-tests: present and real — RQ1 is a blocking instrument-validity gate;
  RQ2/RQ4/RQ5 each carry a pre-registered null/downgrade path. No finding.
- Ethics: non-destructive harness + stop-the-run condition (RQ7) is stronger
  than most deployed-measurement precedents. No finding.
