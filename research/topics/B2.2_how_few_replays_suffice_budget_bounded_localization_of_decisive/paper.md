# How Few Replays Suffice? Budget-Bounded Localization of Decisive Failures in Long Trajectories — Pre-Registered Paper Specification
> Generated from digest.md + README.md. Status: specification, no experiments run.

## Step 0 — Core Asymmetry (升维)

**Asymmetry sentence.** A decisive failure corrupts agent/environment state that every *later* checkpoint inherits but no *earlier* checkpoint carries, so the end-of-task verifier's pass/fail outcome is a (near-)step function of the replay checkpoint index — making the decisive step recoverable by search over that ordering rather than by re-executing every step.

**判据 (deletion test).** Delete the domain nouns (decisive failure, agent/environment state, checkpoint, verifier, replay, step):
> "A ___ corrupts ___ that every later ___ inherits but no earlier ___ carries, so the ___ outcome is a step function of the index."

Without the nouns the sentence is empty: nothing tells you *why* the outcome would be monotone in the index. The load-bearing content is the causal fact that corruption is **inherited by suffixes and escaped by prefixes** in sequentially-executed agent state — a domain-specific invariant, not a generic "binary search finds things" statement. The sentence therefore is not a bridge; it names an invariant (state-inheritance monotonicity of the suffix-replay outcome) that the whole design exploits and measures.

## Step 1 — Estimand (guidance.md §3.4 R1)

**Estimand.** For a trajectory drawn from the study's population (fault-injected + natural-failure trajectories, across ALFWorld and cached-web GAIA, two agent scaffolds, two LLM families), the quantity of interest is *localization accuracy (exact-step, ±2-tolerance, and layer) as a function of replay-unit budget B, per localization strategy* — the decision this feeds is a provisioning one: how many replay units a team should budget per trajectory of length n to reach a target localization accuracy before deciding a causally-verified attribution is worth running at all (CO4's "minimum sufficient replay budget" curve).

## Step 2 — Archetype

**Primary archetype: measurement / characterization study** (consistent with digest N12 `value=empirical`). No new localization *algorithm* is the headline; bisection and group testing are classical primitives being *characterized* under a replay budget. Secondary: **technical-artifact** (CO1 — the replay harness + fault-injected corpus as reusable protocol).

Downstream consequences:
- **(a) Abstract contribution slot** = a *measurement*: per-strategy cost-accuracy curves and a "minimum sufficient replay budget" curve — not "we propose a localizer."
- **(b) Intro logic** = "what becomes possible": if the state-inheritance monotonicity holds, causally-verified attribution drops from O(n) to O(log n) replays and becomes cheap enough to run routinely in agent dev loops. Not "beat prior attribution accuracy by X points."
- **(c) Evidence standard** = paired cost-accuracy curves with bootstrap CIs and pre-registered paired tests across a budget grid; a *ranking* of strategies stable across three cost axes — not a single SOTA number.

## Step 5 — Formal Problem Definition

Notation. Trajectory τ = (s₁,…,s_n), each sᵢ a step (one LLM call + its tool result) with a step-boundary checkpoint cᵢ of agent+environment state. `replay(k, seed)` re-executes steps k..n from cₖ (prefix 1..k−1 fixed, its tool calls served from cache) and returns the task verifier's outcome. d = ground-truth decisive step index; ℓ(d) ∈ {plan, tool, execution} its layer. B = replay-unit budget per trajectory.

| adjective/verb (from digest Claims) | formal definition | how measured |
|---|---|---|
| **decisive** failure (step d) | earliest k s.t. `replay(k, ·)` with the *original* action passes AND with the injected/observed corruption fails (outcome-flipping counterfactual, per AgenTracer/Who&When) | fixed by construction in M2; recorded per trajectory |
| **suffix-replay predicate** g(k) | g(k)=1 if `replay(k)` end-of-task verifier passes, else 0; a noisy Bernoulli oracle | logged by M1 per probe |
| **localize** (exact-step accuracy) | 1[ predicted index d̂ = d ]; also step@±2 = 1[ \|d̂−d\| ≤ 2 ]; layer acc = 1[ ℓ̂ = ℓ(d) ] | M6, deterministic given d̂ |
| **replay unit** / **position-dependent cost** | cost of one `replay(k)` = (n−k+1) resumed LLM calls; total cost per trajectory = Σ over probes | billed per invocation by M1 |
| **(near-)monotone** g(k) | g is a single-threshold step function: ∃ t, g(k)=1 for k≤t, g(k)=0 for k>t. Violation = any k<k′ with g(k)=0, g(k′)=1 | monotonicity-violation rate = fraction of trajectories whose empirical g-profile violates this (M6) |
| **logarithmic fraction** (of cost) | structured-strategy replay-unit cost / exhaustive-scan cost → scales as Θ(log n / n) | ratio computed per trajectory over the corpus |
| **noise-tolerant** / **de-noise** | probe decision taken by majority vote over r repeated replays; single-replay flip rate p = P(g(k) disagrees across two draws) | r swept ∈ {1,3,5}; p estimated per trajectory |
| **structured** (strategy) | uses the index ordering (bisection M3 / group testing M4); vs. unstructured = uniform sampling | design label |

**R3 confound note (injected-corpus monotonicity), added 2026-07-04.** Two M2 design choices bias the measured monotonicity-violation rate downward *by construction*: (i) injected faults are **exogenous** one-shot perturbations that a fresh re-sample at k ≤ d almost never regenerates — unlike natural failures, which the policy's own propensity can re-commit on replay; (ii) M2's keep-filter ("perturbed fails AND original-at-d passes") selects trajectories with monotone-compatible g-profiles. Constraint (exogenous injection + keep-filter) → named confound (selection toward monotonicity). Pre-committed interpretation: Claim 1/Claim 7 and every violation-rate number are licensed **only as injected-corpus (exogenous-fault) properties**; they are never generalized to natural failures except via the natural slice's own measurement (A6/A8), and the degenerate case (natural slice non-replayable AND ~zero injected-corpus variance) routes to F-G2 below. A constructive mitigation — a *propensity-sampled fault mode* (inject the policy's own high-temperature wrong action at step d, so replays can regenerate it) — is a pre-Phase-B design option requiring pilot validation; if adopted, log it in `pipeline.md` before Phase B and report violation rates per fault mode.

### RQ1 (digest N8; addresses C1,C2; tests CO2) — minimum replays vs. full re-execution
- **Assumption**: A1, A2, A3, A4.
- **Hypothesis H1**: On the injected-fault corpus, **bisection and/or group testing reach ≥90% of the exhaustive per-step scan's exact-step accuracy while consuming ≤25% of its replay-unit cost.**
- **Metric**: exact-step accuracy (M6); replay-unit cost (M1); ratio = structured cost / exhaustive cost.
- **Verification**: paired design, all strategies on the same trajectories. Per-trajectory replay-units-to-correct-localization compared via Wilcoxon signed-rank; accuracy gap tested vs. exhaustive via McNemar. α=0.05, Holm–Bonferroni across strategy pairs. n=300 (scale-up); 95% bootstrap CIs (1,000 resamples).
- **Aggregation** (guidance.md §3.1): the primary criterion is scored on the **pooled** n=300 scale-up corpus (both environments × both scaffolds × both LLM families); PASS additionally requires the same-direction effect (structured within the stated accuracy/cost floor of exhaustive) in **≥3 of the 4** environment×LLM-family strata, so a pooled PASS cannot be carried by one favorable stratum while the others disagree. If an environment stratum is lost to PG-2 (reproduction-gate failure), the rule degrades pre-committedly to same-direction in **2 of 2** remaining strata and the claim's envelope narrows to the surviving environment (guidance.md situation 10; shrink logged in `pipeline.md`).
- **Fallback F1** (fires on **any** H1 FAIL, i.e. NOT[≥90% of exhaustive accuracy at ≤25% of its replay-unit cost]) → claim: *"Structured replay does not achieve logarithmic savings on this corpus; we localize the trajectory property (monotonicity-violation rate) that predicts the achievable saving,"* reporting the saving as a function of A3's violation rate. Pre-committed sub-case wordings: (a) *mid-zone* (accuracy floor met, but only at 25–50% of exhaustive cost): *"Structured replay yields a real but sub-logarithmic saving — [measured]% of exhaustive cost — short of the pre-registered 25% floor."* (b) *extreme* (≥50% of exhaustive budget needed to come within 5 pts — N9 RQ1's refutation condition): the headline F1 sentence verbatim. (c) *degenerate covariate* (A3's violation rate has ~zero variance, predictor unfittable): drop the predictor clause; combination rules — with H2 also FAIL → F-G1; with a non-replayable natural slice → F-G2.

### RQ_INF_1 (N8; C1,C3; CO2,CO3) — full cost-accuracy curves
- **Assumption**: A1, A2, A5.
- **Hypothesis H2**: At budget B = n/4 replay units, **structured strategies' exact-step accuracy exceeds uniform sampling by ≥15 percentage points (paired McNemar p<0.05, Holm-corrected), AND the zero-replay judge sits ≥20 points below the best structured strategy.**
- **Metric**: exact-step accuracy at each budget on the grid B∈{2,4,8,16,32,64,exhaustive}; cost-accuracy AUC (normalized area under accuracy vs. log-budget).
- **Verification**: per-budget paired McNemar (structured vs. uniform), Holm–Bonferroni across the grid; bootstrap CIs on all curves.
- **Aggregation** (guidance.md §3.1): scored on the pooled n=300 corpus at the single pre-registered budget B=n/4; as with H1, PASS requires the pooled effect **and** the same sign in ≥3 of 4 environment×LLM-family strata — the full budget-grid curve (B∈{2,...,64,exhaustive}) is reported descriptively for all budgets, but only the B=n/4 point is confirmatory. H1's PG-2 stratum-loss rule applies identically.
- **Fallback F2** (fires on **any** H2 FAIL): pre-committed sub-case wordings: (a) *below-floor advantage* (structured beats uniform significantly but by <15 pts at B=n/4): *"Index structure yields a real but modest advantage over uniform replay — [measured] points at B=n/4, below our pre-registered 15-point practical floor; we report the margin and decline the headline claim."* (b) *no advantage* (uniform matches/dominates bisection across the grid): *"Under matched budgets, index structure yields no advantage over uniform replay; we report the budget regime where each collapses to chance."* (c) *judge parity or better* (the zero-replay judge matches or beats the best structured strategy — a wrong-direction result, reported at full prominence per guidance.md situation 4): *"Replay yields no advantage over log-only judging at matched budgets on this corpus; the causal-verification premium is not detectable here."* Combination rules: (b) + H1 FAIL → F-G1; (c) is the premise-collapse outcome and also routes through F-G1's pivot machinery.

### RQ_INF_2 (N8; C4; CO3) — advantage across layers & group designs
- **Assumption**: A4, A6.
- **Hypothesis H3**: **The structured advantage (≥10 pts over uniform at B=n/4) holds in all three layers (plan, tool, execution); AND layer-crossing group designs beat contiguous designs by ≥5 pts specifically on plan-layer faults.**
- **Metric**: per-layer exact-step & layer accuracy; contiguous vs. layer-crossing group-design accuracy (M4/M6).
- **Verification**: per-layer paired McNemar; layer × design interaction via stratified analysis; Holm across the 3 layers. Balanced corpus (M2) guarantees ≥90 traces/layer at n=300.
- **Aggregation** (guidance.md §3.1; revised 2026-07-04, superseding the earlier all-3-of-3 conjunctive rule): at the per-layer power stated below (~65–70%), the probability of clearing all three per-layer tests even when H3 is true in every layer is only ≈0.65³–0.70³ ≈ 0.27–0.34 — a conjunctive PASS would mostly measure power, not truth. Pre-registered rule: H3's first conjunct PASSes iff the ≥10-pt structured advantage holds in **≥2 of the adequately-powered layers** AND no adequately-powered layer shows a statistically significant reversal (uniform > structured); under-powered layers are INCONCLUSIVE and excluded from the denominator, and if fewer than 2 layers are adequately powered the whole first conjunct is INCONCLUSIVE. The second conjunct (layer-crossing ≥5 pts over contiguous, specifically on plan-layer faults) is scored separately and unchanged; H3 PASS requires both conjuncts.
- **Power (per layer)**: ~90–100 trajectories/layer at n=300 gives ~65–70% power to detect a 10-point paired accuracy difference at α=0.017 (Holm-corrected over 3 layers, McNemar, ~20% discordance) — below the pooled n=300 check's >80% power. Per guidance.md Part 6 item 9, any single layer's test that falls under this power floor is pre-declared **INCONCLUSIVE for that layer**, not FAIL, and is excluded from the ≥2-of-powered-layers denominator in the revised Aggregation rule above.
- **Fallback F3** (fires on **any** H3 FAIL, or on a first-conjunct INCONCLUSIVE): pre-committed sub-case wordings: (a) *layer-dependence* (advantage in ≤1 adequately-powered layer, or a significant reversal in any powered layer): *"The replay-structure advantage is layer-dependent; we report per-layer applicability rather than a uniform recommendation."* (b) *design immaterial* (first conjunct passes but the layer-crossing margin on plan-layer faults is absent): *"Group-design choice is immaterial on plan-layer faults at this scale; contiguous designs are reported as the default."* (c) *under-powered* (fewer than 2 adequately-powered layers): *"Per-layer applicability could not be adequately powered; pooled results are reported with per-layer point estimates and CIs, and no per-layer claim is made."*

### RQ_INF_3 (N8; C2,C3; CO2,CO3) — votes, noise, and the group-testing crossover
- **Assumption**: A5, A3.
- **Hypothesis H4**: **r=3 votes/probe stabilizes bisection to within 3 pts of r=5 accuracy at temperature 0.7; AND there exists a single-replay flip rate p ≥ 15% above which group testing's accuracy-per-replay-unit exceeds vote-multiplied bisection's.**
- **Metric**: exact-step accuracy vs. r∈{1,3,5}; accuracy-per-replay-unit vs. estimated flip rate p; crossover point.
- **Verification**: paired accuracy comparison across r (Wilcoxon signed-rank; **α=0.05 with Holm correction across H4's two conjuncts, per-conjunct 0.025**); locate the crossover with a 95% bootstrap CI on the p-axis and require the CI to exclude "no crossover within the observed flip-rate range."
- **Aggregation** (guidance.md §3.1): scored on the pooled n=300 corpus, pooling across environments/scaffolds/LLM families (the r/noise axis is a property of the replay oracle's sampling temperature, not of environment identity, so no per-environment stratification is pre-registered here); PASS requires both conjuncts (r=3 stabilization AND an existing crossover flip rate) to hold on the pooled data. **p-axis support pre-condition**: the crossover conjunct is scorable only if the observed per-trajectory flip rates span the pre-registered threshold region (a non-empty set of trajectories with p ≥ 15% at the swept temperatures); otherwise that conjunct is pre-declared **INCONCLUSIVE (insufficient noise support)**, not FAIL — note the environments were chosen for reproducibility (A2), so this pre-condition is a live risk, not a formality.
- **Fallback F4** (covers the full failure space of H4's two conjuncts): (a) IF accuracy is insensitive to r (oracle effectively deterministic, C3 moot) → claim: *"On these environments the replay oracle is near-deterministic; de-noising is unnecessary and the noise leg of the tradeoff is empty"* (a scoping result, not a failure). (b) IF no noise regime in the observed p-range shows a group-testing advantage → CO3's crossover claim is retracted and the study reports bisection as uniformly preferred. (c) *Mixed conjuncts* — IF the crossover exists but r=3 fails to stabilize within 3 pts of r=5 → claim: *"De-noising is more expensive than assumed (r=3 insufficient); bisection's effective cost is re-reported at the empirically sufficient r, which strengthens the case for group testing's redundancy above the measured flip rate."* (d) IF the p-axis support pre-condition is unmet → the crossover conjunct is INCONCLUSIVE and CO3's crossover claim is reported as *untested in this noise regime*, not retracted.

### Mandatory baselines
- **B0a current-practice / "why do this at all" arm** — **zero-replay log-only LLM judge** (Who&When all-at-once + step-by-step, M5c). This is the no-mechanism arm: it never re-executes anything. Its above-chance-but-weak accuracy is *expected* and does not bear on run validity; if B0a localizes as accurately as replay-based strategies, the entire replay enterprise is unjustified — a premise-collapse outcome routed through F-G1's pivot logic (guidance.md §3.3 job (a)), never buried.
- **B0b null-by-construction placebo (run-validity gate)** — two components, both of whose localization signal must be at chance: (i) *label-shuffle placebo* — score every strategy's predictions against ground-truth indices permuted across trajectories; accuracy must fall inside the analytic chance band (≈1/n exact-step, bootstrap CI). (ii) *sham-injection arm* — apply M2's perturbation machinery at a step whose corruption verifiably does **not** flip the outcome (round-trip checked: the perturbed run still passes); replay-based strategies must read "no fault" (g(k)=1 everywhere, up to noise) and the judge's predicted index must be at chance w.r.t. the sham site — this specifically detects conspicuous-injection artifacts. **B0b non-null = the pipeline measures an artifact = the whole run is invalid**; goal.md §5 step 1's "placebo first" check applies to **B0b, not B0a**, and B0b is scored before any H\*.
- **M5d (hypothesis-then-verify) reporting rule** — the DoVer-style LLM-hypothesis + replay-verification arm runs on the same trajectories and budget grid and is reported descriptively (not confirmatory). Pre-committed guidance rule: if M5d dominates any structured strategy at any pre-registered budget point, CO4's provisioning guidance switches, for that budget regime, to the hybrid wording ("an LLM-prior hypothesis pass followed by structured replay verification") rather than recommending blind structure.
- **B-alt strongest-alternative-explanation control** — **uniform-random checkpoint sampling at matched replay-unit budget** (M5a). Rival explanation: *"the savings come merely from spending replay budget / from having replay access at all, not from the index structure of bisection/group testing."* Budget-matched uniform holds replay access and replay-unit spend constant, isolating the *structure* (Step 0 invariant) as the cause of any advantage. (Exhaustive per-step scan M5b serves as the accuracy ceiling, not the isolation control.)

### Global fallback F-G1
IF the central hypothesis family (H1+H2: structured replay achieves logarithmic-fraction savings over exhaustive AND beats budget-matched uniform) fails, **pivot archetype from "measurement of a saving" to "negative-result diagnostic"**: instead of quantifying how much structure saves, quantify *when it cannot* — deliver a predictor from trajectory features (monotonicity-violation rate, recovery probability, layer) for whether budget-bounded structured replay will succeed.
> *Pivoted abstract:* "Structured replay is often assumed to make counterfactual failure attribution cheap; we show it does not, and instead isolate the trajectory property — non-monotone recovery of the suffix-replay outcome — that determines when any sub-exhaustive replay budget can localize the decisive step, turning a failed shortcut into a testable go/no-go predictor for practitioners."

### Global fallback F-G2 (compound construct failure)
IF the natural-failure slice proves non-replayable (fewer than 30 re-hosted Who&When logs pass the harness round-trip gates PG-1/PG-2) AND the injected corpus's monotonicity-violation rate is degenerate (~zero variance, leaving F1's/F-G1's predictor unfittable — the outcome the R3 confound note above anticipates), **pivot to measuring the replayability censoring itself**: quantify what fraction of natural agent failures is amenable to counterfactual replay at all under a state-of-practice harness, with per-log failure reasons (irrecoverable environment state, live-web drift, scaffold mismatch), and report the injected-fault curves as an upper-bound protocol whose transfer to natural failures is explicitly unmeasured.
> *Pivoted abstract (F-G2):* "Counterfactual replay is the only causally verified route to failure attribution, but we find it is available for only X% of natural agent failures [X measured, never assumed]; we characterize the censoring mechanism — which logged failures can be re-executed at all, and why the rest cannot — and deliver the replay-verified injected-fault protocol as an upper-bound instrument, turning an unmeasurable transfer claim into a measured availability bound."

## Step 9 — Walking Skeleton

**One binary question**: *Does bisection localize the injected decisive step at ≥90% of the exhaustive scan's exact-step accuracy while spending ≤25% of its replay units, on a deterministic environment?* (RQ1/H1 in miniature.)

- **Arms (3 + 2 smoke)**: bisection (M3, r=1), uniform sampling (M5a, budget-matched), exhaustive per-step scan (M5b, ceiling); plus two smoke arms so that scale-up stays config-not-code: a 2-group contiguous group test (M4 primitive, 5 traces) and the **B0b sham-injection placebo** (5 sham traces; every localizer must read no-fault/chance — rehearses the Phase D validity gate). No judge, no noise sweep yet.
- **Task set**: 20 injected-fault ALFWorld trajectories (lengths 20–40), balanced 7/7/6 across plan/tool/execution, one agent scaffold, one model.
- **Metrics (deterministic only)**: exact-step accuracy, replay units per trajectory. No statistical tests — estimation only.
- **Pre-gate**: harness deterministic-failure-reproduction rate ≥95% (A2). If it fails, stop — nothing downstream is valid.
- **Expected cost**: ~20 traces × (30 exhaustive probes + ~5 bisection probes + budget-grid uniform) × ~15 calls, plus the two 5-trace smoke arms ≈ 10^4 LLM calls, <$250, <1 day wall-clock (N6 feasibility pilot estimate).
- **"Skeleton passed → scaling is a config change" criterion**: reproduction gate ≥95% met; the three main arms' cost-accuracy points are visibly separated; the M4 group-intervention primitive and the B0b placebo path both executed end-to-end in their smoke arms; adding environments/scaffolds/models, the full group-testing designs, the noise/vote sweep, and the budget grid is then data-config expansion of the *same* `replay(k, seed)` loop, M4 primitive, and M6 evaluator — no change to the replay primitives or accounting. (The zero-replay judge B0a is a standalone log-reader touching neither the replay loop nor the accounting; its Stage-2 addition does not violate the gate.)

## Abstract v0 (draft, mechanism-first) — DRAFT BEFORE RESULTS

A decisive failure corrupts agent state that every later checkpoint inherits but no earlier one carries, so an agent trajectory's end-of-task verifier outcome is a near-step function of the checkpoint you replay from. We isolate this state-inheritance monotonicity and measure how much it lets us skip: under a fixed replay budget, how few targeted suffix-replays localize the decisive failure step and layer, versus exhaustive per-step counterfactual replay, budget-matched uniform sampling, and zero-replay log-only judging. On trajectories with programmatically injected, replay-verified failure locations across plan/tool/execution layers — plus a human-annotated natural-failure slice — we billed every replay in resumed-LLM-call units and swept matched budgets to produce per-strategy cost-accuracy curves. We pre-register that bisection and noise-tolerant group testing reach ≥90% of exhaustive accuracy at ≤25% of its replay cost, that group testing overtakes bisection above a measurable oracle-flip rate, and we directly measure where recovery-induced non-monotonicity breaks the guarantee.
