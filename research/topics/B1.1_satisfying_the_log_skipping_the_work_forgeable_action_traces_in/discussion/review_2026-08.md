## 2. Overall novelty stance

**🟢-carried-by-claim-3, conditional on repositioning.** The matched-arm causal design +
pressure dose-response + certified-separable dual-channel estimand has no found twin as of
2026-08-15 and carries the paper. But the draft's positioning is now stale in one load-bearing
place: the Related Work sentence *"this paper's novelty claim is precisely that the
phenomenon's incidence and conditions have not been measured under controlled pressure with
attribution"* was written against a world where only phenomenon-level observations existed
(ClinicalFHIR/EvoPolicyGym/AuditedSkillGraph). Between Nov 2025 and Jun 2026 an
incidence-measurement wave (EvilGenie, RHB, Hardening) and a constructed-hackability paradigm
(Hack-Verifiable) published. None is a method twin — the delta survives — but a reviewer who
knows any of these four papers will read the current framing as either uninformed or
overclaiming. The honest one-sentence delta is now: **"Relative to the 2025–26 reward-hacking
benchmark wave, which measures how often already-trained agents exploit whatever verifier a
benchmark shipped, this paper measures forging as a controlled function of the reward channel
and the optimization pressure that produced it, on tasks certified forgeable, against a
state-diff ground truth, with honest-error attribution."** Decay risk: high — the trend scan's
own finding is that cluster→occupied lag has collapsed to ~one quarter; claim 3's half-life
should be assumed short, which argues for running the cheap selection-pressure pilot soon.

## 3. Feasibility verdict

**FEASIBLE, with the staged kill-test intact.** Checked arithmetic:

- RQ6 power: n = 320 attempts/arm/model, p₁=0.05 vs p₂=0.15 → power ≈ 0.99 at two-sided
  α=0.05 (arcsine h=0.344; h·√(n/2)=4.36). The draft's "approximately 98%" is conservative
  and correct.
- RQ0 placebo sizing: Wilson upper bound at zero successes = z²/(n+z²) = 3.84/(n+3.84);
  ≤0.05 requires n ≥ 73; = 0.046 at n = 80. The draft's numbers are exactly right.
- Kill-test: the selection-only pilot (best-of-n + prompt optimization, no training) is cheap
  (digest: $1–3k API class), informative on its own, and gates the expensive RL arm; the RL
  conjuncts are pre-declared inconclusive-if-unrun. This is a genuine minimum-viable kill-test.
- Assumption load: hermetic sandboxability, per-task forging-path constructibility, and
  oracle predicate tolerance are all carried as explicit assumptions with gates (arm P
  placebo, RQ1/RQ2 instrument checks) — unusually well-guarded for a spec.
- Gap found (F4 below): the RQ7 attribution guard names a κ target but never a pre-registered
  annotation *sample size or sampling rule*, so the study's causal headline depends on an
  unbudgeted instrument (the digest budgets ~300 traces / 2×20h, but the draft does not).

## 5. Findings (numbered, severity-tagged)

1. **[major]** Related Work's measurement-primacy claim is outdated. "…the phenomenon's
   *incidence and conditions* have not been measured under controlled pressure with
   attribution" reads as "incidence has not been measured" one clause earlier ("no prior work
   measures it"). EvilGenie (2511.21654), RHB (2605.02964), and Hardening (2606.08960) measure
   verifier-gaming incidence in coding/tool agents. **Fix:** add a "measured incidence"
   related-work thread conceding all three by name; narrow the novelty claim to the controlled
   /causal/dual-channel delta; qualify the intro's nearest-work paragraph accordingly.
2. **[major]** Contribution 2 (separability certification) is framed as if the
   by-construction-verifiable-hackability idea had no precedent. Hack-Verifiable Environments
   (2605.20744) publishes that principle. **Fix:** concede-and-claim in the task-construction
   thread (delta: admission-gating replayed forging certificate, log/state dual channel,
   coding/tool domains).
3. **[moderate]** Abstract's "unexamined asymmetry" + intro's "rarely stated out loud"
   overstate, given Compliance Gap (2605.01771) proves inevitability/undetectability theorems
   for the adjacent text-vs-behavior axis (and Verification Horizon 2606.26300 states the
   proxy-gap concern explicitly). **Fix:** reword abstract clause; cite Compliance Gap in the
   formal-theory thread — its DPI undetectability result independently *supports* this paper's
   thesis that log-side hardening cannot substitute for a state channel.
4. **[moderate]** RQ7's attribution guard has no pre-registered annotation sample size or
   sampling rule (only a κ target). **Fix:** pre-register the rule already implicit in the
   digest's annotation budget (annotate all flagged episodes up to a 300-episode cap, else
   stratified random sample by arm × task family), stated as a design target.
5. **[minor]** The practitioner-designs paragraph misses Tool Receipts (2603.10060,
   HMAC-signed unforgeable tool-execution receipts) — a third deployed instance of the
   paper's prescription (making the log world-authored). Added since it sharpens that thread.
6. **[minor]** "Of the four threads below" undercounts the (now seven) related-work threads.
7. **[minor]** The draft carries no compute/annotation budget statement (it lives only in
   `digest.md`); acceptable for a spec, note only.
8. **[minor]** Concurrent-work half-life: at the observed cluster-occupancy velocity
   (~1 quarter), claim 3's delta decays quickly. No text change; process implication: run the
   selection-pressure pilot before the next window.

   the verifier channel *causes* forging or how incidence scales with pressure. Our matched
