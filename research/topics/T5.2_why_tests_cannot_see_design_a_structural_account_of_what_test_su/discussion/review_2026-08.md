## 2. Feasibility / soundness findings (se-paper-reviewer lens)

| ID | Severity | Finding |
|---|---|---|
| F1 | **[major]** | **Temporal kill-criterion tautology.** As drafted, admission to the TMP category requires the project's trace-order rule checker to flag the mutant (V(m)=1), and the extended kill criterion counted a mutant as "caught" if "an independent trace-order monitor flags the swapped execution." If the kill-side monitor is the same instrument (or same rule set) as the admission-side checker — and the draft never separated them; its "Insight" sentence even argued the kill-side check *should* be suite-independent — then every admitted TMP mutant is killed by construction and DMSR_TMP is pinned at 0: the category's headline number becomes uninformative. The circularity the draft guarded against (deriving the check from the suite) is the wrong direction; the actual failure is admission/kill instrument identity. **Fix applied:** instrument-separation rule — the external trace-order checker is reserved exclusively for admission-side ground truth and never counts as a kill; K_T for TMP is extended only with order-sensitive observations expressible within the suite's own execution (ordered-mock verification, sequence assertions at the suite's existing observation points), with the tautology named explicitly in the text. |
| F2 | **[moderate]** | **Related-work staleness / missing nearest neighbor.** The draft cites nothing from 2026 and does not mention arXiv:2604.05955 ("Does Pass Rate Tell the Whole Story?", Apr 2026) — the field's direct measurement that test-passing agent patches widely violate design constraints, already flagged in `portfolio_2026-08.md` as a near-twin for the sibling T5.1. A reviewer will name it immediately ("isn't this already shown?"). The trace-level procedural-compliance cluster (AgentLTL, arXiv:2607.02599) is likewise unconceded, contrary to trend_scan_2026-08's explicit instruction to the T5 cluster. **Fix applied:** concede-and-claim positioning added to Introduction and Related Work — concede the observational compliance-rate finding and the trace-level cluster by name, claim the suite-side, causally-identified expressivity estimand as the delta. Both ids verified against the live arXiv API this pass. |
| F3 | **[moderate]** | **RQ6 power arithmetic.** RQ6's success condition is an *equivalence-style* claim (kill-probability gap < 0.05 between matched groups), but the draft framed it as an ordinary threshold with no equivalence test and no power statement. At the pre-registered n ≥ 150 mutants/category/system, a per-system two-proportion 95% CI half-width is ≈ ±0.10 at worst case — a per-system cell can never confirm "gap < 0.05." Pooled across ≥ 12 systems (n ≥ 1800/group/category) the worst-case half-width is ≈ ±0.033, which fits inside the margin. **Fix applied:** RQ6 restated as a TOST equivalence test with margin 0.05, confirmatory only at the pooled mixed-effects level; per-system contrasts demoted to descriptive; the arithmetic stated in the text. |
| F4 | [minor] | **RQ3/RQ5 threshold inconsistency.** RQ3 sets the layering-category success floor at ≥ 50 admitted mutants/system, but RQ5 requires ≥ 150 per category per system (9 of 12 systems) for *all* categories — so a LAY yield of 50–149 passes RQ3 and fails RQ5 simultaneously. Opportunistically harmonized with one clause in RQ5 (LAY held to its own RQ3 floor); logged here as minor. |
