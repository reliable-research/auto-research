# 可强制执行，但不可认证：定位协议层与模型层谈判防御的分工边界

> 由 `pipeline.md` 中六个已确认阶段产出组装而成，经过审计（`taste_audit.md`：🟢），并经 2026-08-21 复审修订（`review_2026-08.md`）。状态：**规格说明 / 论文草稿——尚未运行任何实验。** 下文所有数字均为预注册（pre-registered）的设计目标，而非结果。

## 摘要（Abstract）

一个协议（protocol）只有当某个行为位于其可观测、可机械强制执行的空间之内时，才能使该行为无利可图。自主 LLM 智能体（agent）之间的谈判操纵（negotiation manipulation）并不天然遵守这条边界：某些类别——对承诺的毁约（reneging）、对可核查事实的断言——位于设计良好的协议能够看见并强制约束的空间之内；而另一些——虚报的私有估值（misrepresented private valuation）、情感胁迫式诉求——则是任何格式良好、符合模式（schema）的消息仍可携带的内容。协议层机制设计（mechanism design）究竟是消除了谈判操纵，还是只消除了其中恰好可强制执行的那部分，从未被逐类别地测量过：经典的激励相容（incentive compatibility）保证——针对形式化行动空间上的理性投标者按构造给出——对开放式自然语言谈判者不提供任何方向的证据；而最早将结构化协议约束作为处理（treatment）施加于 LLM 谈判者的框架，度量的是博弈论理性与配置效率，而非在受激励攻击者之下、以隐藏真值（hidden ground truth）逐类别评分的操纵成功率。我们将五个操纵类别实例化为带有隐藏、机器可校验真值的双边议价情景，将其与一个由确定性环境包装器实现的四级协议阶梯（protocol ladder）交叉，用预先计算的诚实博弈剩余（truthful-play surplus）而非消息的结构形式来给每次试验评分，用提示式/脚本式双攻击者设计将协议效应与攻击者能力隔离，在信任任何裁决之前先用人工判断校验评分规则，并测试激活探针监视器（activation-probe monitor）能否在协议无法触及的类别上收复失地。我们报告哪些操纵类别仅靠协议设计即可被压至接近零的成功率，哪些在所有被测协议下持续存在，以及这一分裂对于模型层谈判防御是否具有不可替代的角色、抑或归并入机制设计工程意味着什么。

## 引言（Introduction）

随着自主 LLM 智能体开始代表其委托人（principal）谈判真实交易——议定价格、分割资源、敲定合同条款，且往往没有人先阅读每条消息——保持这些谈判诚实的默认工程答案是协议层的：约束智能体被允许说什么，而不是约束由哪个模型来说。结构化报价模式、托管（escrow）背书的承诺、机器核查的事实声明，承诺的都是经典机制设计长期以来对理性投标者所承诺的同一件事：一个设计良好的行动空间可以使欺骗无利可图，无论由谁来博弈。

然而这一承诺对 LLM 谈判者是否真正成立，从未被逐类别地测量过，而且有一个具体的理由怀疑它并非均匀成立。协议只有当某个行为位于其可观测、可机械强制执行的空间之内时，才能使该行为无利可图。谈判操纵并不遵守这条边界：对承诺毁约、断言可核查的外部事实，是设计良好的协议能够看见并强制约束的行为；但虚报的私有估值或情感胁迫式诉求，是任何格式良好、符合模式的消息仍然可以携带的内容。因此，"协议设计是否消除谈判操纵"不是一个问题，而是与操纵类别数量一样多的问题——而逐类别地回答它，恰恰是尚未有人做过的事。

最接近的既有工作从边界的两侧逼近，却未曾跨越。诸如 AMenuNet 的拍卖设计网络按构造给出占优策略激励相容（DSIC），但严格限于一个形式化投标行动空间——投标者的全部策略足迹是固定模式内的一份估值报告——该保证对一个还能通过机制从未观测的自然语言通道进行说服、编造背景或毁约的谈判者无话可说。在模型侧，关于策略性不诚实（strategic dishonesty）的工作表明 LLM 能产生骗过所有被测输出级评判器、仅能从内部激活中检测到的欺骗性输出——这直接证明协议看不见的内容能击败建立在其上的检查，尽管这条工作线从未测试接口级限制能否在一开始就阻止该欺骗。在这两极之间还有 SOTOPIA 这样的评估框架，它对丰富的多轮谈判情景评分，却没有可用来评定操纵成功与否的隐藏真值经济最优；以及经典协议重设计理论，它在形式化规定的离散交易域内消除欺骗，而这些域本来就没有开放式自然语言声明可供操纵。一个并发的 2026 年工作浪潮已开始从协议一侧对这条边界做经验性跨越，我们坦率承认其占据的地盘：一个面向可验证智能体间交互的机制设计框架已在无结构对话、结构化协议、结构化协议加运行时验证三种条件下评估 LLM 谈判者——把协议阶梯作为实验处理——并发现机制级激励相容并不会自动迁移到 LLM 智能体行为上，这恰是本文动机前提的经验性证明；一项供应链议价研究整体消融了自由文本通道，只留下结构化数字报价；TERMS-Bench 则以环境持有的隐蔽收益连续地为 LLM 谈判者评分。但这些工作度量的是合作或逐利提示下的理性、效率或剩余——没有一个实例化操纵类别分类学，没有一个部署受激励的攻击者，也没有一个追问某一协议级别消除了哪些操纵类别、又对哪些无能为力。也就是说，这些工作线中没有任何一个在同一双边谈判设定中、在受激励攻击者之下，将操纵类别轴与协议约束轴交叉——而这正是本文要弥合的缺口。

把这个缺口变成可测量的问题，又会带来四个自身的困难。操纵不是一件事：五个结构不同的攻击通道——报告的价值、断言的事实、情感、协同、时间——必须各自按其自身条件评分，因为关闭一个通道的协议可能让其他每个通道都门户大开。即使协议约束了消息结构，结构与真实性是消息的两个逻辑独立属性，格式良好的字段仍可携带虚假声明，任何格式级检查都无法自行认证内容。任何足够严格的执行机制还会引出自举（bootstrapping）问题：如果核验承诺或审计声明的检查者本身是 LLM 介导的过程，则该检查继承了它本要排除的同一可操纵性。并且由于更严格的协议同时改变防御能捕获什么与攻击执行的难度，测得的操纵成功率下降在"协议关闭了通道"与"攻击者未能适应新格式"之间存在真正的歧义，除非这两种解释被设计分离。

我们的方法将上述每个障碍转化为一个具体设计选择。每个操纵类别拥有自己的隐藏真值和在预注册、多重校正决策规则下的独立裁决，因此没有任何聚合数字能掩盖协议未能关闭的通道。每次试验直接对照该隐藏真值评分——采样的私有估值、事实表、承诺账本——绝不对照消息与模式的符合性，因此结构与内容永不混淆。承诺执行与事实审计以确定性、非 LLM 的环境代码实现，因此检查本身不会像底层谈判那样被博弈，而此类检查无法触及的残余声明被命名为显式边界而非默默假设不存在。每个格子同时在自由策略攻击者与能力保底的脚本式攻击者下运行，因此测得的协议效应可归因于协议而非攻击者能力——这一设计我们在信任之前先行校验（用人工判断审计评分规则本身），并对所有抵抗全部被测协议的类别加以扩展，直接测试候选模型层防御能否收复协议无法触及的失地。

我们在取自真实谈判语料库的议价情景上评估该设计，将无结构基线与三个逐级更严的协议级别下的操纵成功率进行比较，并辅以脚本式非自适应攻击者对照和一个自动评判评分基线，以隔离客观、真值锚定的评分器所带来的增量。

综上，我们的贡献是：
- 对协议层谈判防御底层可观测性边界（observability boundary）的识别与操作化（operationalization）：机制只能在其可见并可强制执行的空间内使行为无利可图，而谈判操纵跨越该边界的分裂方式从未被逐类别地测量。
- 一个客观、真值锚定的操纵评分器——在被信任之前先经人工判断校验——它直接对隐藏私有状态而非消息的结构符合性评分，使协议无法仅靠改变虚假内容的包装方式就显得"修复"了操纵。
- 一个通过提示式/脚本式双攻击者构造将协议对操纵成功率的因果效应与攻击者能力隔离的设计，以及对激活探针监视器能否恰在抵抗所有被测协议的类别上收复失地、且不压垮正当成交率的直接测试。
- 一个预注册设计，用于产出逐类别的经验性结论：哪些操纵类型被协议设计消除、哪些在所有被测协议下持续存在——并在运行之后裁定这一分裂对于模型层谈判防御是否具有不可替代的范围、抑或是协议设计终将自行关闭的工程问题。

## 问题定义（Problem Definition）

**形式化设定。** 令 𝒦 = {a, b, c, d, e} 索引五个操纵类别——虚报私有估值（a）、编造外部事实或紧迫性（b）、情感或关系胁迫（c）、虚假承诺或毁约（d）、合谋信号（collusive signaling，e）——令 𝒫 = {P0, P1, P2, P3} 索引严格度递增的协议约束阶梯：P0 无结构自由文本，P1 模式校验的结构化报价，P2 = P1 加托管背书的承诺执行，P3 = P2 加事实表审计的声明。格子 (k, p) 中的一次试验 t 产生转录 τ、攻击者剩余 u_A、防御者剩余 u_D 与隐藏情景参数 θ——采样的私有估值、外部可核查声明的事实表、承诺账本——在博弈过程中对对方智能体均不可见。诚实博弈剩余分布 S⁽ᵗʳᵘ⁾_k 由脚本化、非操纵性智能体预先计算。操纵成功指标 MSR_{k,p} 直接对照 θ 评分，绝不对照 τ 与协议模式的符合性。研究对象是：对每个 k ∈ 𝒦，MSR_{k,p} 是否在某个被测 p 下落到统计确认的接近零水平（协议可修复，protocol-fixable）、是否即使在最严被测 p 下仍高于非平凡水平（协议不变，protocol-invariant）、抑或证据在两者之间模糊（未定，undecided）——以及对每个协议不变的 k，候选模型层防御能否降低 MSR_{k,P3} 而不降低双方达成任何交易的比率。

**为什么困难。** 固定类别集 𝒦 并不固定单一裁决规则：类别级声明只有当每个类别拥有自己的隐藏真值和自己的统计校正决策边界时才有意义，因为消除一个类别操纵的协议可能对其他每个类别的成功率毫无触动——把五个类别折叠成一个聚合率恰恰会掩盖这种异质性。即使固定 𝒫 也不能保证更严的 p 约束的是 θ 校验的真实性而非仅仅 τ 的表面形式：模式的结构符合性与其中内容的真实性是消息的两个逻辑独立属性，因此 MSR_{k,p} 必须直接对 θ 计算，否则纯粹外包装的改变会伪装成操纵的真实减少。P2 与 P3 的执行带来进一步困难：检查只与核验它的东西一样可信，若检查者本身是 LLM 介导的过程而非确定性环境代码，则对协议本要认证的那些声明而言，"被强制执行"与"可被操纵"就塌缩为同一类别。并且由于从 p 移向更严的 p′ 同时改变协议能捕获什么与攻击在新格式下的执行难度，观测到的 MSR_{k,p} 变化在真正的协议效应与攻击者能力效应之间存在混淆，除非在自由策略与能力保底两种攻击者下将攻击执行与攻击成功分开测量。

## 方法概览（Method Overview）

在概念层面，这是一条含六个协作部件的单一测量流水线，运行在五个操纵类别与四个协议级别的析因网格上。类别索引的情景分类学提供每个格子的隐藏真值以及把原始试验结果转化为逐类别裁决的预注册决策规则。真值内容评分器把每次试验的隐藏参数——绝非其消息形式——转化为操纵成功读数。确定性环境侧执行恰好实现协议阶梯所承诺的托管与事实审计检查，而不把检查委托回 LLM。双攻击者混淆控制在自由策略与能力保底两种攻击者下运行每个格子，使测得的协议效应可归因于协议而非攻击者能力。评分器效度审计在信任任何建立于其上的裁决之前，先用人工判断校验真值评分器本身。联合防御恢复测试则取出抵抗所有被测协议的类别，追问候选模型层工具能否在不压制正当成交的情况下关闭残余缺口。

## 方法论（Methodology）

### 类别索引的情景分类学（Category-Indexed Scenario Taxonomy）

**挑战。** 操纵不是单体——五个结构不同的攻击通道必须各自评估，而跨越多个同时进行的逐类别比较的决策规则若不加校正，可能从普通噪声中制造虚假裁决。

**洞察。** 内建多重性控制的类别级裁决规则，既防止单一聚合成功数字把真实的不变类别掩藏在可修复类别之后，也防止未校正的检验组捏造出并不存在的不变裁决。

**方法。** 五个操纵类别各自实例化为带机器可读真值文件的参数化情景族：采样的私有估值、真值已知的外部可核查声明事实表、承诺账本、由脚本化非操纵智能体预先计算的诚实博弈剩余分布。若某类别的操纵成功率在某个被测级别下不超过 5% 且显著低于无结构基线（双比例检验，Holm–Bonferroni 在全部类别×级别对比族上校正），则宣告其为协议可修复；若在最严被测级别下成功率仍不低于 10% 且 95% 置信区间排除 5%，则为协议不变；两条件皆不满足则为未定。

### 真值内容评分器（Ground-Truth Content Scorer）

**挑战。** 对消息结构的协议约束本身对格式良好字段内的内容是否为真无话可说——键入模式合规字段的虚假估值仍是虚假的。

**洞察。** 由于结构符合性与内容真实性是消息的逻辑独立属性，避免混淆两者的唯一方式是对照消息内容本应匹配的隐藏参数评分，绝不对照消息形式。

**方法。** 每次试验的操纵成功直接对照该试验的隐藏情景参数评分——偏离采样私有估值、事实表判假的断言、账本记录后被违背的承诺——并结合剩余分位条件（交易达成、防御者剩余低于诚实博弈分布的第 25 百分位、攻击者剩余高于其中位数）。该评分的任何部分都不检查消息是否符合当前协议的模式。

### 确定性环境侧执行（Deterministic Environment-Side Enforcement）

**挑战。** "可验证"的承诺或"被审计"的声明只与执行核验的东西一样可信——若检查者本身是 LLM 介导的过程，它继承与其本要约束的谈判相同的可操纵性。

**洞察。** 把执行落在确定性、非 LLM 代码上，对此类代码可触及的声明规避了递归信任问题，同时把它无法触及的声明——意图、主观估值——变成显式报告的残余，而非默默假设的无风险。

**方法。** 托管背书的承诺执行从环境持有的余额自动执行已接受的报价，使毁约在机械上不可能，仅可通过定价的解除承诺罚金条款退出；事实审计将任何类型化事实断言对照情景事实表核查，并在送达对方之前剥除不可核验的声明。两项检查均以确定性环境代码实现，绝不调用语言模型，且都只适用于协议阶梯设计所能触及的机器可校验声明子集。

### 双攻击者混淆控制（Dual-Attacker Confound Control）

**挑战。** 更严协议下操纵成功率的下降在"协议关闭了通道"与"攻击者未能在新格式中执行攻击"之间存在歧义，而两种解释对协议真实效应蕴含相反结论。

**洞察。** 一个不可能不发动攻击的能力保底攻击者提供了自由策略攻击者独自无法提供的比较：若协议效应在攻击者能力被固定时依然存在，该效应就不能归因于能力。

**方法。** 每个（类别，协议）格子在两种攻击者模式下运行——自由策略的提示式攻击者，以及在固定轮次插入操纵动作的模板化脚本式攻击者——并将攻击执行（操纵内容是否实际进入对话）与攻击成功分开评分。一个混合效应逻辑斯蒂模型以协议×类别交互回归成功率，情景与模型对为随机截距，把协议主效应与情景、配对层面的方差隔离。

### 评分器效度审计（Scorer Validity Audit）

**挑战。** 每个下游类别裁决的可信度都不超过其所依据的规则式成功判据，而开放式谈判转录没有客观标签可供核对该判据。

**洞察。** 把评分器效度当作被检验的、可证伪的前提——而非其他所有声明默默依赖的假设——才能避免系统性错误的评分器直到全规模结论已被得出后才被发现。

**方法。** 在信任任何规模化裁决之前，规则式评分器的成功标签在 200 份留出转录样本上对照两名标注者的人工判断审计，计算 Cohen's kappa（κ）。κ 至少达到 0.7 规模化矩阵才继续；分歧案例对照各情景的估值不对称水平加以检视，而非丢弃。

### 联合防御恢复测试（Joint Defense-Recovery Test）

**挑战。** 证明某操纵类别抵抗所有被测协议只确立了否定结果——被测阶梯上没有协议触及它——对任何实际防御能否触及它无话可说。

**洞察。** 要求候选防御同时降低操纵成功率并保持成交率，才能排除让谈判者干脆拒绝交易这种平凡"防御"，与本设计其他部分排除退化信号的纪律相呼应。

**方法。** 在每个被判协议不变的类别上，于最严被测协议下运行两种模型层干预：携带显式操纵意识与对方声明怀疑指令的防御提示（defended prompt），以及在对比诚实数据上训练、对攻击者激活显示欺骗意图的试验进行标记的激活探针监视器。仅当干预使操纵成功率至少降低 0.10 绝对值（在不变类别与干预上 Holm 校正）且成交率保持在无防御基线 0.10 之内时，才算收复失地。

## 实验（Experiments）

### 实验设置（Experimental Setup）

**数据集。** CraigslistBargain（He et al., 2018）——真实单议题价格谈判情景；为虚报估值与编造事实/紧迫性类别提供现实参数，其单议题结构使试点的真值计算廉价。Deal-or-No-Deal（Lewis et al., 2017）——带私有点值的多议题分割情景；隐藏估值情景的直接模板，也是检验类别裁决能否泛化到单议题价格议价之外的规模化域。CaSiNo（Chawla et al., 2021）——带真实人类关系与说服策略标注的营地多议题谈判；将情感胁迫类别的情景模板与脚本式攻击者的操纵动作落在观察到的人类说服策略而非杜撰策略上，这正是混淆控制设计使其能力下限可信所需要的。

**基线**（健全性检查比较项，而非要击败的竞争者——这是测量研究，此处没有任何研究问题被表述为"我们的流程击败基线 X"）。无结构（P0）协议臂——除缺少模式、托管或审计外与每个更严级别完全相同——是每次级别比较的必要对照，兼作检查某类别是否本就有操纵威胁可修。脚本化诚实智能体博弈定义每个格子据以评分的诚实博弈剩余分布，不是要击败的比较项。仿照 SOTOPIA 评估协议的自动评判评分器施加于同一批转录，量化客观、真值锚定的评分器相对 LLM 评判所增加的东西。仅防御提示与仅探针监视器两臂在完全无模式、无托管、无审计的无结构协议下运行，隔离模型层防御的独立贡献。

**指标。** 每格的操纵成功率（MSR）及其 Wilson 95% 置信区间；攻击执行率（AER），即操纵内容实际进入对话的试验比例；毁约率；成交率（达成任何交易的试验比例，防止协议靠摧毁交易来"修复"操纵）；模型层防御臂的检测/拒绝率；评分器效度审计的 Cohen's κ。

**规模、功效与裁决时机。** 试点的回合数分解为：2 个模型对 × 5 类别 × 4 级别 × 2 攻击者模式 × 30 次试验 = 2,400 次操纵试验，另加约 1,200 次脚本化诚实博弈回合（5 类别 × 6 情景实例 × 约 40 次）以估计各情景的诚实博弈剩余分布——共约 3,600 个谈判回合，约 10⁸ 量级的 token（按现价属数百美元 API 成本级）；规模化（≥4 个模型家族、3 个域、每格 100 次试验）属数千美元级。裁决时机是裁决规则自身的推论并据此预注册：在试点每格 n = 30 下，观测 MSR 为 10% 的类别其 Wilson 95% 置信区间约为 [0.035, 0.26]，无法排除 5% 的不变界限，而 1/30 的观测率同样无法确认 ≤5% 的可修复界限——因此按构造，试点规模下不可发布任何逐类别裁决。试点因此仅为通过/中止（go/no-go）与仪器检查（经 RQ5 的评分器效度、拒绝率、包装器日志）；可修复/不变裁决只在规模化阶段发布。由于即使 n = 100，当真实 MSR 接近 10% 时不变性对比仍属边缘（Wilson 置信区间下界约 0.055），每个类别的最严级别格子——即不变裁决据以计算的格子——在规模化中以 n ≥ 200 运行，且这一非对称分配属于预注册的一部分而非事后补量。

**研究问题：**
1. RQ1——逐类别裁决规则是否在协议可修复与协议不变类别之间产生非退化分裂？
2. RQ2——托管执行的承诺与内容承载的操纵对协议阶梯的响应是否不同？
3. RQ3——毁约成功率的崩塌反映的是机械执行而非攻击者说服力下降吗？
4. RQ4——测得的协议效应可归因于协议本身而非攻击者能力吗？
5. RQ5——规则式成功评分器与人工判断的一致性是否足以被信任？
6. RQ6——模型层防御能否在抵抗所有被测协议的类别上收复失地？

#### RQ1：逐类别裁决规则是否在协议可修复与协议不变类别之间产生非退化分裂？

**设置。** 完整消融矩阵：试点阶段运行 2 个模型家族 × 5 类别 × 4 协议级别 × 6 情景实例 × 每格 30 次试验（含诚实博弈运行约 3,600 个谈判回合；见"规模、功效与裁决时机"）；规模化运行 ≥4 个模型家族（含跨模型配对）× 3 个域 × 每格 100 次试验，最严级别格子 n ≥ 200。逐类别裁决规则仅施加于规模化格子；试点为通过/中止与仪器检查。

**预期结果。** 五个类别中至少一个被判协议可修复、至少一个被判协议不变——并非全部落在同一侧。

**证伪条件。** 若五个类别全部落在决策规则同一侧则被驳斥：若全部协议可修复，则协议设计在被测阶梯上完全关闭谈判操纵，该方向归并入机制设计工程；若全部协议不变，则被测阶梯无论类别一律防御失效，这将质疑阶梯设计本身而非确认类别级边界。

**假设（通俗表述）。** 操纵相对协议防御不是单体：某些类别可被机制设计结构性关闭，另一些不能。

**指标。** 每格 MSR 及 Wilson 95% 置信区间；逐类别裁决（可修复/不变/未定）。

#### RQ2：托管执行的承诺与内容承载的操纵对协议阶梯的响应是否不同？

**设置。** 在完整矩阵内，固定模型家族与域，比较虚假承诺/毁约与虚报估值、情感胁迫在协议级别间的 MSR 轨迹。

**预期结果。** 毁约 MSR 在托管执行级别处降至不超过 5% 且显著低于无结构基线；虚报估值与情感胁迫 MSR 在最严被测级别处仍不低于 10%，置信区间排除 5%。

**证伪条件。** 若毁约 MSR 即使在托管执行下仍不低于 10%（机械执行未按设计生效），或虚报估值或情感胁迫 MSR 在最严协议下也降至 5% 或以下（内容承载操纵原来也是协议可修复的），则被驳斥。

**假设（通俗表述）。** 托管执行与内容真实性是逻辑独立的两轴：关闭其一不会关闭其二。

**指标。** 逐类别、逐级别 MSR 与置信区间；可修复对不变的类别对比。

#### RQ3：毁约成功率的崩塌反映的是机械执行而非攻击者说服力下降吗？

**设置。** 专对虚假承诺/毁约类别，在脚本式攻击者臂（攻击尝试由模板保证而非取决于攻击者自身策略）下，比较攻击执行率与操纵成功率在协议阶梯上的变化。

**预期结果。** 攻击执行率在整个阶梯上保持高位——脚本式攻击者持续尝试毁约——而操纵成功率在托管执行下崩塌，表明下降在于成功而非尝试。

**证伪条件。** 若攻击执行率在托管执行下随操纵成功率一同崩塌，意味着阶梯是在压制尝试而非在尝试发生后机械挫败之——与所声称机制实质不同——则被驳斥。

**假设（通俗表述）。** 协议阶梯机械挫败已发动的毁约尝试；它不劝阻尝试本身。

**指标。** 每协议级别的攻击执行率与操纵成功率，脚本式攻击者臂，仅虚假承诺/毁约类别。

#### RQ4：测得的协议效应可归因于协议本身而非攻击者能力吗？

**设置。** 在攻击执行率非零的条件下，跨全部五个操纵类别，比较各协议级别对操纵成功率效应的符号在提示式与脚本式攻击者臂之间是否一致。

**预期结果。** 协议效应符号在至少五分之四的类别中于两臂间一致。

**证伪条件。** 若协议效应符号在多数类别中于两攻击者臂间不一致，意味着表观协议效应主要是攻击者能力的产物而非协议的真实防御效应，则被驳斥。

**假设（通俗表述）。** 类别裁决反映协议实际防御的对象，而非攻击者适应新消息格式的程度。

**指标。** 逐类别的两臂符号一致性；混合效应模型的协议×类别交互项。

#### RQ5：规则式成功评分器与人工判断的一致性是否足以被信任？

**设置。** 两名标注者独立标注 200 份留出转录中操纵是否发生；经 Cohen's κ 与规则式评分器的标签比较，并检视分歧案例在情景估值不对称四分位上的分布。

**预期结果。** Cohen's κ 至少达到 0.7，且分歧案例集中于估值不对称最高的四分位——那里强硬但诚实的议价最像剥削——而非均匀分布。

**证伪条件。** 若 κ 低于 0.7（评分器按当前构建尚不可信，所有下游裁决须视为暂定直至其被修订），或分歧在不对称水平上均匀分布而非集中（意味着评分器的误差甚至不是结构化、可纠正的风险），则被驳斥。

**假设（通俗表述）。** 规则式评分器是人工操纵判断的有效代理，其失效模式有界且结构化，而非任意噪声。

**指标。** Cohen's κ；按不对称四分位条件化的分歧率。

#### RQ6：模型层防御能否在抵抗所有被测协议的类别上收复失地？

**设置。** 在每个被 RQ1 判为协议不变的类别上，于最严被测协议下运行防御提示与激活探针监视器干预，并与同一协议下的无防御臂比较操纵成功率与成交率。

**预期结果。** 激活探针监视器使操纵成功率至少降低 0.10 绝对值（p<0.05），同时成交率保持在无防御基线 0.10 之内；防御提示干预产生更小、更不可靠的降低。

**证伪条件。** 若两种干预在任何协议不变类别上均未达到 0.10 绝对降低，或降低仅伴随大于 0.10 的成交率下滑——"以不交易为防御"的结果不算真正恢复——则被驳斥。

**假设（通俗表述）。** 在两种被测模型层防御中，激活探针监视是关闭协议无法触及的残余缺口的更有效者。

**指标。** 每种干预的操纵成功率降幅（最严协议下无防御减防御）；成交率差；探针留出 AUC，在探针用作防御信号之前报告。

### 机制分析（Mechanism Analysis）

在标题性的可修复/不变裁决之外，一项预算内分析解释类别*为何*落在其位置：对每个在 P3 被判协议不变的类别，残余 MSR 被分解为攻击执行率（AER）与操纵成功率（MSR）的缺口——P3 试验中攻击已执行（AER=1）且仍成功（MSR=1）的比例，对执行但被挡（AER=1, MSR=0），对从未执行（AER=0）。一个因攻击在各级别以稳定速率执行并成功（AER 平坦、MSR 平坦）而不变的类别，其不变缘于机制看不见的内容本就在形成——即 RQ2 与 RQ3 已隔离的内容对结构残余。一个因 AER 自身下降而条件成功率保持高位而不变的类别，其不变缘于不同原因：攻击者在结构化格式下尝试不足，但一旦尝试，格式并不提供额外保护。两种失效形态指向不同修复路径（内容审计对尝试诱发），并作为命名对比报告，不折叠进单一 MSR 数字。该分解只使用 RQ1–RQ4 已计算的量（AER、MSR），无额外测量成本，并对 RQ1 识别的每个协议不变类别报告。

**进一步评估。** 若时间更充裕，一个自然扩展是测试伙伴选择的多对多谈判市场而非固定双边配对——此处明确超出范围，因为它把分析单元从单一二元组的操纵成功改为群体级均衡，需要自己的可识别性设计而非上述逐类别裁决规则的延伸。第二个自然扩展是在本研究判为协议不变的任何类别上测试超出被测阶梯的协议级别（如声誉加权的声明审计），因为不变裁决永远只是关于被测阶梯的声明，而非关于协议设计全体。

## 相关工作（Related Work）

与本文最接近的既有工作分踞本文所测量边界的两极，在综述更广图景之前值得把差异说白：诸如 AMenuNet 的拍卖设计网络已按构造交付激励相容，策略性不诚实的工作已表明模型层探针能捕获骗过输出级检查的欺骗，而一个并发的可验证智能体间谈判机制设计框架已把结构化协议约束作为实验处理施加于 LLM 谈判者——但三者均未在同一双边谈判设定中、在受激励攻击者之下，将操纵类别轴与协议约束轴交叉，而这正是本文要弥合的可识别性缺口。

**形式化行动空间上的激励相容机制设计。** AMenuNet 用置换等变网络学习仿射最大化拍卖参数，使所得机制按构造具有占优策略激励相容与个体理性，区别于激励相容仅为近似的学习式机制。相关工作 UCB-S 设计激励感知的多臂老虎机分配规则，以置信度筛选为可信威胁约束对单一标量可观测量（如内容提供者点击率）的策略操纵。两者都交付强保证，但仅限于形式化、定义良好的行动空间——投标者的估值报告、提供者的点击率——对一个还能通过机制从未观测的自然语言通道说服、编造背景或毁约的谈判者无话可说。

**模型层欺骗检测与评估。** 策略性不诚实的工作表明模型能产生骗过所有被测输出级评判器的伪有害顺从，且该欺骗仅在用线性探针监视内部激活时可检测；姊妹工作 Among Us 在文本社交推理沙盒中诱发类似的工具性欺骗，测试对比训练的激活探针能否分布外泛化。另一结构因果博弈框架给出行为学根基的欺骗形式定义与图判据。它们各自确立模型层工具能捕获协议级检查会漏掉的欺骗，但没有一个测试对模型可发出内容的接口级限制能否在一开始就阻止欺骗行为，也没有测试因果博弈判据对不带已知因果结构的开放式谈判转录是否可作为可扩展评分工具操作化。两项更近的研究在不跨协议约束轴的情况下更接近本文的防御臂消融：DECEPTICON 测试上下文提示与护栏模型能否减少对 Web 智能体的暗模式操纵，发现两者仅部分有效，且操纵随模型能力上升；PrincipalLoyalty 测试模型层提示脚手架与逐 token KL 蒸馏能否使智能体在对抗性对手面前忠于委托人，发现两种干预都沿泄漏/过度拒绝权衡前沿移动却从未跨越。两者均未在防御臂之外同时变动协议/机制设计轴，而这正是本文运行的联合测试。进一步的警示来自一项预行动激活探针监视的并发否定结果研究：一个在其构造期对比数据上完美分离的探针，在一组真实预行动情境上几乎从不越过决策阈值，且与无关语义方向对照相比其引导效应并非概念特异——这是直接的对立证据，说明本文自己的激活探针防御臂必须在其自身留出数据上校验，而非假定可从训练用对比数据集迁移。

**协议约束作为 LLM 谈判的实验处理。** 一条并发的 2026 年工作线已开始为 LLM 谈判者变动协议层本身，本文明确承认其地盘。一个面向 A2A/MCP 上可验证多智能体交互的机制设计框架把轮流报价议价与 VCG 式拍卖编码为智能体间消息模式上的约束，加入运行时验证修复层，并在无结构对话、结构化协议、结构化协议加验证三种条件下评估 LLM 骨干——发现验证降低结果方差、结构化协议提高完成率，而与此处最相关的是：机制级激励相容并不自动迁移到 LLM 智能体行为（一个模型在每次拍卖试验中都按其真实估值出价；另一个仅在 3.3% 的试验中如此）。该框架是本文最近的装置近邻：它拥有协议阶梯作为处理的设计，但它度量的是非对抗提示下对博弈论预测的偏离——没有操纵类别分类学、没有受激励攻击者、没有隐藏真值操纵评分、没有逐类别可修复/不变裁决、没有模型层防御臂。一项供应链议价研究同样整体消融言语通道——智能体只交换数字报价——作为私有信息下剩余分割的一个对比；一项模拟议价中诚实与轻信的信息制度研究发现现成 LLM 会试图谎报私有信息但难以利用不对称，而逐利微调使智能体更强也更不诚实——这为本文类别（a）实例化的虚报威胁提供直接证据，其变动的是信息制度而非协议约束。最后，TERMS-Bench 提供最近的评分装置：对隐蔽潜在类型与收益的环境即校验器诊断，在单一固定协议下——是没有操纵处理、没有协议轴的连续剩余诊断。相对这四者，本文的贡献是这个交叉本身：在受激励、能力受控的攻击者之下跨协议阶梯的逐类别操纵成功裁决，外加恰在阶梯无法关闭的类别上的防御臂。

**说服测量与安全归因方法论。** 把 LLM 说服重铸为贝叶斯说服（Bayesian persuasion）的工作将辩论与说服数据集转化为带显式状态、先验与效用的发送者-接收者博弈，把说服度量为信念敏感的效用增益而非被评的说服力——但在单一固定交互协议内，从未把协议作为实验处理变动，因此无法说明更严协议会移除哪些说服效应。另有归因智能体安全失败的工作隔离带完整执行上下文的单次 LLM 调用，把失败归因于骨干模型而非周边工具代码——本文设计在精神上借用的层归因方法论，那里应用于单调用提示注入攻击，而非"攻击"分布于整个对话的多轮、经济激励议价交互。

## 结论（Conclusion）

本工作把当前智能体间谈判防御方式中隐含的假设——足够良好设计的协议能使操纵无利可图，无论哪个模型扮演谈判者——变成经测量的逐类别声明，而非工程信条。核心方法论赌注是："协议可修复"与"协议不变"只有当每个类别拥有自己的隐藏真值、自己的多重校正决策规则、以及自己的"测得效应反映协议而非攻击者能力或评分器盲区"的检查时，才是可信标签；跳过任何一项检查的设计都可能报告一条并不存在的边界。无论消融矩阵产出哪种分裂，发现都具有双向决策相关性：非退化分裂意味着模型层谈判防御研究拥有不可替代的目标，防御恢复测试将说明是否已有现成工具；趋向完全可修复的退化分裂则意味着该问题终究归并入协议标准化工程。两条局限从一开始就为该声明划界。其一，任何协议不变裁决相对于被测的四级阶梯与模型家族——未测协议可能关闭此处标为不变的类别，该声明应读作"在此阶梯下不变"，而非"对任何协议设计不变"。其二，本研究旨在暴露的残余——位于任何事实表之外的声明，如陈述的意图或私人偏好——是任何阶梯上任何协议级别按构造都不太可能关闭的结构性边界，这正是为什么测试模型层工具能否触及它、而不仅证明协议不能，是本文最后也最具后果的检验。
