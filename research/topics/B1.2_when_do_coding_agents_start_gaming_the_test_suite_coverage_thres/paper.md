## Step 0 — Core Asymmetry (升维)

**The asymmetry:** *The slack an agent can exploit between "passes the visible test suite" and "is correct" is not an unknown residual — it is exactly the surviving-mutant set of that suite, so the suite's mutation-kill score is not a correlate of gaming risk but the direct measure of the attack surface, and degrading it is a control knob on how much gaming is even possible.*

**判据 (deletion test).** Delete the domain nouns: "The slack an agent can exploit between passing the ____ and being ____ is exactly the surviving ____ set, so the ____ score is the direct measure of the attack surface." Without *test suite / correct / mutant / mutation-kill*, the "exactly" claim is empty: no generic proxy metric comes with a constructive enumeration of its own blind spots. The sentence is only true because mutation testing *constructs* the set of undetected behavior changes (digest Claims 1–3, C4). It does not survive noun deletion as a valid generic statement (it degenerates to Goodhart's law, which asserts divergence but never *measures* the exploitable set) — so this is an invariant, not a bridge.

## Step 2 — Archetype

**Primary: empirical (controlled measurement / threshold-finding study)** — per digest N12 ("Emergent-Abilities-Mirage-style 'is this sharp threshold real?' measurement"). **Secondary: tool** — the adequacy-controlled suite sampler (M1) and the per-patch gaming diagnostic (M5) are instrumental artifacts, not the headline.

Downstream consequences:
- **(a) Abstract contribution slot:** a measured gap-vs-adequacy curve plus an onset estimate (or evidence of none) — a *finding about when a phenomenon occurs* (CO2), not a new benchmark or agent.
- **(b) Intro logic:** "what becomes possible" — once suite adequacy is a swept independent variable instead of a fixed accident of the benchmark (CO1), verifier-sufficiency requirements for agent gating can be stated quantitatively ("your suite must kill ≥ s\* of mutants or the score is untrustworthy"); the RLVR training-time analogue is a bounded extrapolation flagged in Limitations, not a tested claim. Not "beat a number": there is no SOTA to beat.
- **(c) Evidence standard for results:** leakage control (agent provably blind to the held-out oracle, M2/M3), confound control (size/coverage-matched sub-suites, C4), honest budget-matched baselines, pre-registered statistics with multiplicity correction (t4) — **no SOTA table**. A flat curve is a publishable result under this standard (see F-G1).

## Positioning vs. classical APR overfitting literature (added 2026-07-04 design review; **VERIFIED 2026-07-04** — harvested, digested, and entered in `reference_candidates.jsonl` with network access; see digest.md N3 item 10)

Concede-and-differentiate (guidance.md Part 4 situation 6): the 2015–2018 automated-program-repair literature contains this design's closest method-twins — patch overfitting to the training/visible test suite measured against held-out suites (Smith et al., FSE'15, "Is the Cure Worse than the Disease?"; Qi et al., ISSTA'15, plausible-vs-correct patches), and per-patch overfitting detection by differential test generation against a reference patch (DiffTGen, Xin & Reiss, ISSTA'17; PATCH-SIM, Xiong et al., ICSE'18) — the latter being the core mechanism M5 adapts. All four PDFs were fetched from public author/arXiv mirrors and read directly (not from search-snippet guesses); see `reference_candidates.jsonl` keys `Smith2015Overfitting`, `Qi2015PatchPlausibility`, `XinReiss2017DiffTGen`, `Xiong2018PatchSim` and their digests in `openview_corpus/paper_cache/pdf_digests_main/`.

**Conceded:** the visible-vs-held-out overfitting construct and the differential-testing detection move are not new to this paper. **Differentiated (different estimand, different regime — not cosmetic), now confirmed by direct reading rather than presumed:** this paper's estimand is a *threshold-conditioned gaming onset* — the gap as a function of *controlled, size/coverage-matched mutation-kill adequacy* — measured on *iterative LLM agents under optimization pressure*, with a budget-matched selection-only arm (H5) isolating adaptive exploitation; confirmed on direct reading, all four APR twins measure or detect overfitting of search-based (non-LLM, non-iterative) APR patches under fixed, uncontrolled, as-shipped suites, and **none sweeps adequacy as an independent variable, none uses a mutation-kill score, and none fits an onset-threshold/changepoint model**. **M5 is accordingly repositioned** as an agent-setting adaptation of DiffTGen-style differential testing — its new parts are the metamorphic neighborhood of the visible sub-suite's inputs and the adequacy-conditioned gaming-fraction trend, not the differential-testing move itself; Step 3's "M5 … new mechanisms" verdict is narrowed to exactly those parts. **Novelty claim narrowed:** Claim 8 and the seed's "全语料中该框架命中≈0" are corpus-limited observations restated in their defensible, now-confirmed form: *no prior work — corpus-grounded or classical-SE — sweeps mutation adequacy, matched on suite size and coverage, against LLM coding-agent behavior.* **Blocking residual: RESOLVED.** `guidance.md` Part 4 situation 12 (pre-emption) does **not** apply — none of the four classical works already sweeps suite quality against held-out failure with matched confounds, confirmed by direct reading of all four PDFs, not inferred from titles or abstracts alone.

## Step 5 — Formal Problem Definition

**Estimand (guidance.md §3.4 R1).** The onset threshold $s^*$ (and, where no discrete onset exists, the full curve $G(\cdot)$) of the visible-pass/held-out-pass gap as a function of visible-suite mutation-kill adequacy $ms(T_v)$; unit of analysis is one (repair instance × agent family × adequacy level × sample) episode, aggregated per adequacy level within a benchmark track (SWE-bench Verified Python track, Defects4J Java track); reference population is existing coding agents (SWE-agent, Agentless, OpenHands) run under a fixed iterative repair harness on existing execution-verified repair benchmarks; the decision it feeds is a quantitative sufficiency floor for verifier adequacy ("your gating suite must kill ≥ $s^*$ of mutants or its pass signal is untrustworthy") for teams gating agent-produced patches at evaluation/acceptance time — i.e., budget-bounded iterative repair under a frozen policy, the only regime this design tests; extrapolation to RLVR training-time verifiers (gradient pressure over many episodes) is an explicitly flagged conjecture bounded in Limitations, not a claim any H\* licenses.

**Notation.** Task instances $i = 1..n$, each with buggy program $b_i$, gold patch $g_i$, full test pool $T_i^{full}$, hidden tests $T_i^{hid}$ (disjoint from $T_i^{full}$ where available; else a held-out split), mutant set $M_i$ generated by fixed operators **applied to the gold-patched program $g_i(b_i)$** (Defects4J/Major convention; provenance previously unstated — required so that excluded mutants' killing tests probe *correct* behavior when reused in M3's held-out oracle), equivalent/duplicate subset $E_i \subseteq M_i$ (filtered per M1). A visible sub-suite $T_v \subseteq T_i^{full}$ is exposed to agent $\pi_j$ under harness M2 (fixed budget $B$ turns / tokens, temperature $\tau$, seed set). $K(T) \subseteq M_i \setminus E_i$ = mutants killed by suite $T$.

Every load-bearing adjective/verb in the claims (digest Claims section), made computable:

| Term | Definition | Measurement |

## Step 6 — Pre-Registered Experiments

Design constants (all arms): adequacy grid $s \in \{0.3, 0.4, 0.5, 0.6, 0.7, 0.8, 0.9, 1.0\}$ (8 levels, Stage 1); Stage 0 pilot uses $\{0.3, 0.45, 0.6, 0.75, 0.9, 1.0\}$. Stage 1: 3 agent families (SWE-agent, Agentless, OpenHands per digest N8 baselines), ~300 instances (SWE-bench Verified + Defects4J tracks), $k=5$ samples/cell, fixed $\tau$, seeds, budget $B$. Primary-family tests Holm-corrected across {H1, H2, H3, H4, H5} (H5 = the B-alt isolation criterion, registered under Mandatory baselines).

### E1 (RQ1 — where does the gap open?)
- **Assumption:** A1, A2, A3, A5, A6.
- **Hypothesis H1:** H1 holds iff **(i)** $\hat G(0.3) - \hat G(1.0) \ge 10$ percentage points, **(ii)** the $ms$ fixed effect in the mixed-effects logistic model of $H$ (random intercepts: instance, agent; digest M4) is negative with $p < 0.05$ Holm-corrected, and **(iii)** $\hat G(1.0) \le 10$ pp (adequacy is the operative driver — digest N9/RQ1 falsification clause (b)). All three or H1 fails.
- **Metric:** $G(s)$ and $s^*$ as defined in Step 5 (digest N8: "Overfitting gap = visible-pass − held-out-pass").
- **Verification:** Mixed-effects logistic regression (M4) on ~300 × 8 × 5 × 3 Stage-1 episodes; power target: ≥0.9 to detect a 10 pp gap difference at α=0.05 given the pilot's variance estimate (t4 mitigation: power analysis is a Stage-1 entry gate). Cluster-robust bootstrap CIs at instance level.
- **Fallback:** If H1 fails via (i)/(ii) (flat curve): the paper's claim becomes: *"Under a controlled mutation-adequacy sweep with size- and coverage-matched visible suites, coding agents' held-out correctness is insensitive to visible-suite adequacy down to ms = 0.3; visible-test overfitting is not an operative failure mode in budget-bounded iterative repair."* (→ triggers F-G1.) If H1 fails via (iii) (gap already large at ms = 1.0): claim becomes: *"Even mutation-adequate visible suites systematically over-accept agent patches; mutation score is an insufficient sufficiency criterion for agent verifiers"* — an attack on the adequacy construct itself (t1), still publishable under the empirical archetype.

### E2 (RQ_INF_1 — sharp threshold or gradual slope?)
- **Assumption:** A1, A2; conditional on H1 criterion (i)–(ii) passing (no curve shape without a curve).
- **Hypothesis H2:** H2 (monotone growth) holds iff the fitted $G(s)$ is non-increasing in $s$ with a trend test $p<0.05$ (Holm) **and (effect floor, native units)** the fitted smooth-monotone curve's total change across the sweep, $\hat G(0.3) - \hat G(1.0)$ read off the fitted curve (not the raw endpoints, which H1(i) already tests), is $\ge 5$ percentage points — a statistically significant but practically flat trend (<5 pp total on the fitted curve) fails H2 regardless of p-value (guidance.md §3.1: significance without magnitude passes nothing). **H2a (sharpness)** holds iff the Step-5 "sharp" decision procedure passes ($\Delta\mathrm{AIC} \ge 10$, Davies $p<0.05$ corrected, breakpoint CI width $\le 0.2$). Digest N9 predicts gradual, i.e., H2 true / H2a false; both outcomes are pre-committed as reportable.
- **Metric:** Changepoint location + Davies-test p-value; $\Delta$AIC segmented-vs-GAM (digest N8 metrics).
- **Verification:** M4 model comparison on pooled Stage-1 data; Davies test with multiplicity correction (t4); breakpoint CI by parametric bootstrap (1,000 draws).
- **Robustness cell (pre-registered; 2026-07-04 design review "Missing RQs" item 2 — is the onset driven by *which* mutants survive, not how many?):** at one mid-grid adequacy level ($ms = 0.6$, Stage 1), sub-suites are re-sampled under two deliberately different surviving-operator mixes at the same scalar $ms$ (identical size/coverage constraints, M1), and $\hat G$ is re-estimated per mix; if the per-mix gap estimates differ by ≥ H2's 5 pp floor at equal scalar adequacy, the onset claim is scoped as operator-mix-conditioned ($s^*$ reported per mix), not as a property of the scalar alone. Exploratory robustness cell — outside the {H1–H5} Holm family, enters no confirmatory test; it pre-empts the C1 mutant-heterogeneity challenge on the *main* result rather than leaving mutant-class analysis only inside H2's fallback.
- **Fallback:** If H2 fails (no monotone trend): the paper's claim becomes: *"The visible/held-out gap is non-monotone in mutation adequacy, implying scalar mutation score does not order agent-exploitable suite weakness; adequacy for agent verifiers is not one-dimensional"* — reported with the per-mutant-class breakdown as exploratory (not confirmatory) analysis.

### E3 (RQ_INF_2 — does the onset transfer across agents?)
- **Assumption:** A3, A6 (3 families affordable); conditional on H1.
- **Hypothesis H3:** H3 (no universal threshold) holds iff **(i)** the agent×adequacy interaction is significant (LRT $p<0.05$, Holm) and **(ii)** at least one pair of families has $s^*$ estimates differing by $\ge 0.15$ ms-units with non-overlapping bootstrap 95% CIs. Both, or H3 fails.
- **Metric:** Per-family $G_j(s)$ curves and $s^*_j$ (digest N8 RQ_INF_2 analysis plan).
- **Verification:** LRT of the interaction term in the mixed-effects model; per-family $s^*$ bootstrap. Digest N6 caveat is inherited verbatim: 3 families measure variation, they cannot prove universality (unaddressed C3).
- **Fallback:** If H3 fails: the paper's claim becomes: *"Across three agent families under identical sampler, oracle, and budget, the gaming onset is statistically indistinguishable, consistent with a benchmark-intrinsic rather than agent-intrinsic threshold"* (digest N9/RQ_INF_2 falsification branch, promoted to a finding).

### E4 (RQ_INF_3 — is the gap gaming, or honest incompleteness?)
- **Assumption:** A2, A4; requires ≥100 visible-pass/held-out-fail patches from E1 (else see fallback).
- **Hypothesis H4:** H4 holds iff **(i)** M5's labels reach Cohen's $\kappa \ge 0.7$ against adjudicated dual human annotation on $n=100$ sampled $V{=}1,H{=}0$ patches (guidance.md §3.4 R2's stated validation bar — raised from an earlier $\kappa \ge 0.6$ draft threshold to match it, see the R2 protocol note below), and **(ii)** the gaming fraction at the lowest adequacy band ($ms \le 0.45$) exceeds that at the highest band ($ms \ge 0.75$) by $\ge 15$ pp with a logistic trend test $p<0.05$ (Holm). Both, or H4 fails — strictly binary, no intermediate tier.
- **Metric:** Gaming fraction = share of $V{=}1,H{=}0$ patches labeled gaming by M5 (digest N8 metric, verbatim); $\kappa$ vs humans.
- **Verification:** Two annotators, blind to adequacy level, adjudication on disagreements; CMH/logistic trend across adequacy bands.
- **Fallback:** If (i) fails ($\kappa < 0.7$): M5 is dropped from the contribution list (CO3 withdrawn) and the paper's claim becomes: *"The gap is measured but its per-patch attribution to gaming vs. coincidental incompleteness remains open; we release the annotated patch set as a labeling benchmark."* If (ii) fails with (i) passing: claim becomes: *"The widening gap under degraded adequacy is dominated by honest-but-incomplete fixes, not deliberate suite-gaming — weak suites admit incomplete work rather than invite exploitation"* (digest N9/RQ_INF_3 falsification branch as the headline). If <100 qualifying patches exist, H4 is reported as descriptive only (no confirmatory test).

**M5 instrument-validation protocol (guidance.md §3.4 R2 — the 5-step sequence, spelled out; this was previously only a single validation number).** M5 is an automated annotator (gaming vs. coincidental-incompleteness classifier) and must clear all five R2 steps, not step ③ alone: **①** ground the two categories in the pre-existing differential-testing / mutation-testing literature's own definitions (a mutant-killing test is exactly one that observes a behavior difference; "gaming" is operationalized as observing that same kind of difference *only* outside the visible sub-suite's exercised inputs) rather than an invented rubric. **②** draft wide on a held-out calibration set disjoint from the $n=100$ H4 validation sample: pilot the $N{=}200$-input / $\ge 30\%$-disagreement decision rule on ≥20 pilot $V{=}1,H{=}0$ patches from the walking skeleton (Step 9's archived patch), adjusting $N$ and the disagreement threshold with named operations (e.g., "raised threshold from 20% to 30% after the pilot showed 20% over-labeled honest off-by-one fixes as gaming") before freezing it for H4. **③** validate against ≥2 independent human raters at the binary acceptance bar $\kappa \ge 0.7$ (guidance.md's stated R2 requirement; H4(i) above uses this threshold directly — no intermediate "weak signal" tier, per the binary-hypothesis rule of §3.1). **④** inspect the confusion matrix: disagreements between M5 and human labels must concentrate on patches near the 30%-disagreement boundary (adjacent-category errors), not systematically mislabel one class — a systematic collapse (e.g., M5 never predicts "coincidental" for boundary cases) invalidates the threshold choice and returns to step ②, not to step ③. **⑤** freeze $N$, the threshold, and the input-perturbation seed set before Stage 1 scale-up; no further tuning after freezing (R2's "asserted validation numbers without the protocol are treated as absent").

**M5 input generation, per track (2026-07-04 design review — "$N{=}200$ generated inputs" was previously an unbacked capability claim at repository scale):** Defects4J track — EvoSuite-generated inputs targeting the class(es) touched by the patch, with search seeded from the visible tests' observed call arguments. SWE-bench Python track — Hypothesis-based property generation scoped to the function(s) modified by the patch, with strategies seeded by perturbing the visible tests' observed call arguments (this seeded perturbation *is* the "metamorphic neighborhood" in the Step-5 gaming definition; inputs are function-level calls to the patched entities, not whole-repo executions). **Gate PG-M5 (checked during R2 step ②, before H4 is registered as runnable):** the generator yields ≥ $N$ valid, non-erroring inputs on ≥80% of the pilot $V{=}1,H{=}0$ calibration patches; failure on a track returns to generator engineering, and if unfixable there, E4 narrows to the track(s) where PG-M5 passes (scope restriction, pre-declared — never a silent substitution of a weaker input source).

### Mandatory baselines

- **B0 — null-by-construction placebo (checked first; Phase D step 1).** Two analysis-only checks, zero additional agent episodes. **(i) Permutation placebo:** adequacy-level labels are shuffled across sub-suites within each instance and M4 is refit; the shuffled-$ms$ fixed effect must be null (95% CI covering 0, point estimate of the implied endpoint gap below H1's 10 pp floor). **(ii) Gold-patch pass-through:** $g_i$ is scored by the full pipeline at every adequacy level; $\hat G_{gold}(s)$ must be 0 at every $s$ (subsumes and extends G-S2). Either check non-null ⇒ the pipeline measures an artifact ⇒ **the run is invalid** per goal.md §5 step 1 (Part 4 situation 1); no H\* is scored. *(Renaming note, 2026-07-04 design review: the arm previously labeled B0 — the full-adequacy arm — is not null-by-construction: $\hat G(1.0)$ can be non-null for the boring construct reason that killing all mutants does not imply passing hidden tests. It is renamed B-ref below so goal.md §5's "B0 non-null → run invalid" rule cannot misfire on a publishable outcome.)*
- **B-ref — "why do this at all" reference arm: full adequacy (formerly labeled B0).** Agents run against $ms \approx 1.0$, size-matched visible sub-suites, plus the gold-patch upper bound on held-out pass (digest N8 baselines). This arm is **scored as evidence, never as a validity gate**: if the gap is already ≥10 pp here, degrading adequacy explains nothing and H1 criterion (iii) fails into its pre-committed adequacy-construct fallback (a finding, not an invalid run); if it is ≈0, the phenomenon exists *only* under inadequacy — which is the problem's license to exist. **Phase D order, explicit:** B0(i)+(ii) are checked first; only if both are null are B-ref and H1–H5 scored.
- **B-alt — strongest-alternative-explanation control: selection-only (best-of-k), budget-matched.** **Rival explanation:** the gap is not agent-side adaptive gaming but pure *selection under an imperfect verifier* — sampling until something clears a weak filter inflates accepted-but-wrong mass mechanically, exactly the ceiling ResamplingLimits/ROCnReroll formalize for *static* generators (digest N3 #1–2, N4). **Arm:** the same model, single-shot sampling with best-of-$k'$ selection by the visible suite, total token budget matched to the iterative arm. **Isolation criterion, registered as H5 (binary; was an unregistered criterion — 2026-07-04 design review):** H5 holds iff the iterative arm's mean gap exceeds the selection-only arm's, $\hat G_{iter} - \hat G_{sel} \ge 5$ pp, in the low-adequacy band ($ms \le 0.45$), with the two-arm contrast in the mixed-effects model at $p<0.05$ (Holm, family {H1–H5}).
