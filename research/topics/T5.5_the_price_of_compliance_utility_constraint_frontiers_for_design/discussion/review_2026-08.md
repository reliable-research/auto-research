## 5. Feasibility findings (se-paper-reviewer lens)

| ID | Severity | Finding |
|---|---|---|
| F1 | **[moderate]** | **Related-work staleness/overbreadth.** The claim that constraint-following benchmarks measure satisfaction "with no independent functional-correctness oracle... and cost never appears" is false for the code-specific wave (CIFE 2512.17387, IFEvalCode 2507.22462, MultiCodeIF 2507.00699, RACE 2407.11470 — correctness+compliance scored jointly). A subarea reviewer names any of these on first read. |
| F2 | **[moderate]** | **Intro premise staleness.** "Remains unmeasured" is no longer clean: SUSTAINSCORE (2601.22047) directly measures constraint-insertion interference with task solving, including code generation. The paper's actual gap (shape + cost + design-rule class) survives, but must be stated as the delta over that result, not as a virgin field. |
| F3 | **[moderate]** | **κ-audit power arithmetic broken.** A stratified 100-sample pool split across ~20 rules leaves ~5 flagged instances per rule; a per-rule Cohen's κ ≥ 0.8 drop decision is statistically meaningless at n≈5 (κ's CI at n=5 spans most of [−1,1]). The drop rule as written would fire (or fail to fire) on noise. Fix: per-rule minimum flagged-instance quota (≥20), drawing additional generations until met. |
| F4 | **[moderate]** | **Sweep resolution and budget unstated.** The dual-criterion shape test's power depends entirely on the number of strength levels, which the draft never specifies ("no active rules through all rule packs" could be 3 levels); Davies-type breakpoint tests are near-powerless below ~6–7 levels. No total-attempt or cost arithmetic appears anywhere, for a study whose own subject is cost. Fix: pre-register minimum ladder length (≥7 levels incl. L0), grid dimensions, and order-of-magnitude generation budget as design targets. |
| F5 | [minor] | Placebo "semantic inertness" is asserted, not checked — inert text can still shift behavior idiosyncratically; a manipulation check (violation rate under placebo ≈ unconstrained) would license it. Logged only. |
| F6 | [minor] | Architecture-conformance-checking citation debt (Murphy et al.-style reflexion models, DSM/Sangal, ArchUnit/import-linter literature) remains open, honestly disclosed in the draft. | F7 | [minor] | The draft/tex carry no citation apparatus at all (descriptive references only, no refs.bib). Consistent with the topic's established convention; revisions below add verified arXiv ids inline in parentheses rather than introducing a bib pipeline. Logged. |
